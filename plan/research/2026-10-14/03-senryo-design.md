## 3. Motion, sound, haptics

**Motion** (`scale.ts` `MOTION`/`SPRING`, wrapped by `theme/motion.ts` for Reanimated 4, `ReduceMotion.System` everywhere). Default ease `cubic-bezier(0.2,0.8,0.2,1)`; press 100/160 ms; selection 170; number change 160; sheet enter 480 / exit 240 on the iOS drawer curve `(0.32,0.72,0,1)`; stagger 40 ms, items rise 10 pt over 320 ms; page push 320; onboarding scene 850; chart reveal 750. Springs (mass 1, damping 30-40): selector 260, detail 240, fan 420, dock active 500, ruler snap 500, sheet release 320 (slight overshoot), dock bubble 420. Overshoot curve `(0.34,1.56,0.64,1)`. Reduced motion becomes a 100 ms crossfade.

**Feedback** (`M/apps/mobile/src/feedback/*`). One call site `fire(event, {sound?, cue?, profit?, ladder?})` (`fire.ts:44`): the haptic always fires if enabled; then sound. Haptic words (`haptics.ts`): tick = selection, press = light impact, snap = rigid, confirm = soft, filled/win/mega = success notification, warn, fail = error notification, loss = medium impact, close = medium, surge = heavy, slump = soft. Rule (`sound.ts:6-12`): "No sound for ticks or navigation — haptics own those." Sounds: six UI WAVs (scene, onboarding, deposit, send, unlock, error; ElevenLabs-generated, original) plus 36 synthesized cues in `packages/tokens/src/sound.ts` (one definition rendered to WAV on phone by `scripts/gen-sounds.mjs` and live via Web Audio on web, `apps/web/src/lib/feedback/sound.ts`). Mix levels `SOUND_MIX` 0.07-0.55, master 0.9; pool of 2 players per cue; verdict cues duck the music; all failures swallowed; toggles and volumes in MMKV. For Kawase map: tap/toggle/sheetOpen/sheetClose to UI; `open` = order placed; `success` = money confirmed; `deposit` = money arrived (fire("filled",{sound:"deposit"})); `send` = transfer sent; `error`; `unlock` = agent approval granted. IDEA: add `agentStep` (soft tick as each tool call lands) and `agentDone`.
