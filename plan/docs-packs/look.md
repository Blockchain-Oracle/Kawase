# Docs pack: "look" lane (Senryo kit port, Skia/Reanimated, fonts, audio, sheets, URL drawers, 21st twins, tokens)

Written 2026-10-14. `node_modules` is NOT installed in this checkout, so nothing was checked against Kawase's own `.d.ts`. Signatures come from vendor docs (Context7), the Skia 2.6.2 / Reanimated 4.5.1 types in Senryo's `node_modules` (same versions), and the repo source. UNVERIFIED marks the rest.

## 1. Versions
- Pinned, no install: reanimated 4.5.1, worklets 0.10.1, Skia 2.6.2 (depends on `canvaskit-wasm` 0.41.0), gesture-handler ~2.32.0, `@gorhom/bottom-sheet` ^5.2.14 (peer reanimated `>=3.16 || >=4.0.0-`), expo-font ~57.0.4, expo-audio ~57.0.5, expo-haptics ~57.0.3, expo-router ~57.0.24, uniwind 1.12.0, react-native-web pinned 0.21.2 (0.21.3 breaks uniwind, spike 08).
- Install: `cd apps/mobile && npx expo install @expo-google-fonts/inter @expo-google-fonts/roboto-condensed` (both 0.4.2, files verified on jsdelivr: `inter/600SemiBold/Inter_600SemiBold.ttf`, `roboto-condensed/900Black/RobotoCondensed_900Black.ttf`). Web only: `pnpm --filter @kawase/ui-web add @number-flow/react` (0.6.2, React 18/19). Add it through the workspace catalog like the other versions.
- Fonts need a native rebuild (`expo run:ios`), not an OTA update.

## 2. Reanimated 4.5 / worklets 0.10
- Worklet helpers moved: `runOnJS` is deprecated, use `import { scheduleOnRN, scheduleOnUI } from "react-native-worklets"`. Arguments are passed after the function: `scheduleOnRN(fn, a, b)`, not `runOnJS(fn)(a)`. Senryo's `Sheet.tsx` already uses it, so ports are copy-safe.
- Babel: `babel-preset-expo` adds the worklets plugin. Do not add `react-native-reanimated/plugin`; there is no `babel.config.js` in `apps/mobile` and none is needed (UNVERIFIED for 57, but Senryo has the same setup).
- `app.json` has `experiments.reactCompiler: true`. Reanimated's docs say to use `sv.get()` / `sv.set(v)` instead of `sv.value` in code the compiler sees. Senryo uses `.value`; when porting, switch render-path reads and writes to get/set (reads inside `useAnimatedStyle` worklets are fine either way).
- Layout animations: `<Animated.View layout={LinearTransition.duration(200).easing(EASE)} entering={FadeInDown.duration(320)} />`, list reorder with `<Animated.FlatList itemLayoutAnimation={LinearTransition} />` (single column only, `numColumns` must be 1). `springify()` is native-only; on web it is ignored.
- Reduced motion: every animation defaults to `ReduceMotion.System`. For a replacement (crossfade, not travel): `const reduce = useReducedMotion(); entering={reduce ? FadeIn.duration(100) : FadeInDown}`. Pass `reduceMotion: ReduceMotion.System` in spring configs as Senryo's `theme/motion.ts` does.
- Springs take `mass/stiffness/damping/overshootClamping/energyThreshold`, never `duration` together with them. Senryo's `SPRING`/`TIMING`/`EASE` live in `theme/motion.ts` and read `packages/tokens/src/scale.ts`. Kawase's equivalent source is `packages/config/src/motion.ts` (`MOTION`): extend it with Senryo's values (press 100/160, sheet 480/240 on `(0.32,0.72,0,1)`, stagger 40) and build a `theme/motion.ts` wrapper from it.
- Perf: drive live text with a read-only `TextInput` + `useAnimatedProps` (Senryo `LiveText`), never `setState` per tick.

## 3. Skia 2.6: LiveOdometer, sparklines, and web
Native: copy `LiveOdometer.tsx` + `RollingFigure.tsx`. They record a `Picture` on the UI thread (`Skia.PictureRecorder().beginRecording(rect)` inside `useDerivedValue`, `finishRecordingAsPicture()`, render `<Picture picture={pic} />`) and take a font from `useFont(require("../../assets/fonts/RobotoCondensed-Black.ttf"), size)`. `useFont` returns `SkFont | null`, so draw nothing until it resolves. Skia loads the file directly, so the font name and the expo-font plugin do not matter for Skia; use a static TTF (Senryo instanced a variable font to wght 900 with fontTools; the npm `RobotoCondensed_900Black.ttf` is already static). Use `matchFont`/system fonts only for Latin axis labels.

Web: Skia on web is CanvasKit WASM (2.9 MB gzipped, WebGL, async, not server-renderable). Kawase prerenders (`web.output: "server"`), and the sibling desktop pack rejected CanvasKit. **Decision: do not load CanvasKit.** Make `.web.tsx` twins and let Metro pick them:
- `LiveOdometer.web.tsx` and `RollingFigure.web.tsx`: `@number-flow/react` in `packages/ui-web` (`<NumberFlow value={n} format={{style:"currency",currency:"USD"}} trend={0} />`; it respects `prefers-reduced-motion`).
- `Sparkline.web.tsx`: `react-native-svg` `<Path>` from the same geometry (already used by `ui-native` `area-chart.tsx`). Share one `sparkGeometry(points,w,h)` function between the Skia and SVG versions.
- If a Skia feature is ever needed on web: `npx setup-skia-web` copies `canvaskit.wasm` to `public/` (rerun after each Skia upgrade), then wrap in `<WithSkiaWeb getComponent={() => import("./X")} fallback={...} />` from `@shopify/react-native-skia/lib/module/web`, or `LoadSkiaWeb({ locateFile: f => \`https://cdn.jsdelivr.net/npm/canvaskit-wasm@0.41.0/bin/full/${f}\` })`. The CDN version must match. In dev, Skia components must live outside `src/app/` or the router evaluates them before CanvasKit loads.
- Gotcha: import Skia only from `.tsx` native files; a plain `import "@shopify/react-native-skia"` in shared web code breaks the prerender.

## 4. Fonts: Inter + Roboto Condensed Black
- Native (embedded at build time): the `expo-font` plugin entry in `apps/mobile/app.json` already has an `ios.fonts` path list and an `android.fonts` list with `fontFamily` + `fontDefinitions` + `weight`. Replace Manrope/Space Grotesk/JetBrains with: Inter 400/500/600/700 and Roboto Condensed 900. Android: `{"fontFamily":"Roboto Condensed","fontDefinitions":[{"path":"./node_modules/@expo-google-fonts/roboto-condensed/900Black/RobotoCondensed_900Black.ttf","weight":900}]}`. iOS reads the family from the file; Expo recommends the file be named after its PostScript name. The Google files are named `Inter_600SemiBold.ttf`, so the internal name is UNVERIFIED: check once in Font Book/fontdrop.info and use that string in tokens. Safest rule (Uniwind docs): one `--font-*` token per face, single name, no fallback list.
- Tokens: edit `fonts` in `tokens.json` (`display`, `body`, `mono`; add `googleFontsAxes` entries `Inter: wght@400..700`, `Roboto Condensed: wght@900`). `build.mjs` generates `--font-sans/--font-display` for native and the web stacks with the Noto script fallbacks (RN has no per-glyph fallback, so Arabic/Hindi/Bengali/Chinese keep using system fonts on native).
- Web: config plugins do not run on web. `+html.tsx` already links `tokens.fonts.googleFontsHref`, so changing `tokens.json` is enough; add `font-display: swap`-friendly `<link rel="preload">` for Roboto Condensed only if the hero number flashes. Self-hosting via `@font-face` in `public/` is the privacy/offline alternative.
- Money numbers: `fontVariant: ["tabular-nums","lining-nums"]` (Inter supports both).

## 5. expo-audio and expo-haptics
- `kawase/apps/mobile/src/feedback/feedback.ts` already has the pool pattern: `createAudioPlayer(asset, { keepAudioSessionActive: true })` cached per cue, `AudioOwnership` lock against LiveKit, `releaseSession()`. Extend that module; do not copy Senryo's `sound.ts` over it.
- Senryo's recipe to add: `setAudioModeAsync({ playsInSilentMode: false, interruptionMode: "mixWithOthers", shouldPlayInBackground: false })` once at launch. The expo-audio default is `playsInSilentMode: true`, so UI cues only obey the ringer switch if you set false. Preload: create the players at launch (`downloadFirst: true` also pre-downloads remote files; unneeded for bundled assets). Replay: `await p.seekTo(0); p.play()`. Pool of 2 per hot cue: alternate two players so a rapid second cue does not wait for `seekTo`. Skip when `AppState.currentState !== "active"`, swallow all errors.
- Web: browsers refuse play before a user gesture, and an inactive session refuses later plays (Kawase's `releaseSession` already skips web). Wrap in try/catch.
- Haptics map (Senryo `haptics.ts`): tick `selectionAsync()`; press `impactAsync(Light)`; snap `impactAsync(Rigid)`; confirm `impactAsync(Soft)`; success `notificationAsync(Success)`; warn `Warning`; fail `Error`; loss/close `Medium`; surge `Heavy`. Rule: no sound for ticks or navigation, haptics own those. Haptics are no-ops on desktop browsers.

## 6. Sheet host above a hiding dock
Kawase has `@gorhom/bottom-sheet` only in `packages/ui-native/src/components/sheet.tsx` (`BottomSheetModal`, provider in `_layout.tsx`, centred dialog when `useWide`).
- **Port Senryo's own host** (`components/sheet/{Sheet,SheetHost,SheetRoute,constants}`: `Gesture.Pan` + `Gesture.Native` + Reanimated `withSpring/withTiming`, `scheduleOnRN(close)`, detents 0.62/0.88/1, close at 25% or 900 pt/s, upward drag /6, `useAnimatedKeyboard`). Reason: it needs the parent page to step back to 0.96 and the dock to hide through a holder set (`SHEET_HOLD` in `dock-context`), which Gorhom does not give. Kawase's dock is `src/dock/dock-tab-bar.tsx`; add a `DockContext` with `hide(key)/show(key)`.
- Gorhom 5 alternative (keep for small dialogs): `<BottomSheetModal ref snapPoints={["62%","88%","100%"]} enablePanDownToClose backdropComponent={...} onChange={(i)=>...}>`; `present()`/`dismiss()`. Its views take hex colours, not classNames (use `useCSSVariable("--color-card")` from uniwind). Gorhom documents web mobile support but via Reanimated's web rules; treat desktop web as UNVERIFIED and use the dialog branch there.
- Third-party views ignore `className` until wrapped once at module level: `withUniwind(SafeAreaView)`. Do not wrap `react-native` or Reanimated components.

## 7. Expo Router web drawers held in the URL
- Documented path (verified): a route with `presentation: Platform.select({ web: "transparentModal", default: "modal" })`, `headerShown: false`, `animation: Platform.select({ web: "none" })`; the previous route stays visible behind it. Write `WebModal.web.tsx` (backdrop, Escape calls `router.back()`, dismiss = `router.canGoBack() ? router.back() : router.replace("/")`) and `WebModal.native.tsx` that returns `children`. `formSheet`/`modal` render as normal stack routes on web.
- Senryo's pattern (`?d=receive`, Back closes): in Expo Router read `useLocalSearchParams<{d?: string}>()` in a root `DrawerHost`, open with `router.push({ pathname, params: { d: "receive" } })`, close with `router.back()`. Whether pushing the same pathname with new params creates a history entry is UNVERIFIED; `router.setParams` explicitly does not push. If Back must close, use dedicated `/d/[name]` transparentModal routes (documented) instead.
- Keep drawers lazy: `React.lazy` per drawer name, preload on idle (Senryo `DrawerHost.tsx`). Hydration: anything that depends on `window` must be applied by CSS class, not by rendering different text (spike 08).

## 8. 21st components into `packages/ui-web`, and native twins
- `components.json` in `packages/ui-web` uses aliases `@kawase/ui-web/*` (not `@/`), so run installs from that directory: `cd packages/ui-web && 21st add <user>/<slug> --print` (prints `npx shadcn@latest add "https://21st.dev/r/<user>/<slug>?api_key=$API_KEY_21ST"`; the key stays in `.env`, never echo it), then run it without `--print`. Without the key the raw URL returns 403. `21st get <id>` prints code but not helper files; `add` fetches them.
- Review pass every time: token colours instead of fixed hex; bare `border` needs a colour; framer-motion 13 types (`Variants`); fixed copy. Web deps present: motion 13, radix-ui, lucide, hugeicons, cva. Missing: `@number-flow/react`, `gsap`.
- Twin rule (spike 08): shadcn writes `components/ui/button.tsx`, the same path React Native Reusables uses, so web code stays in `packages/ui-web`; import it from a `Foo.web.tsx` file next to the native `Foo.tsx`. 21st components are web-only; the native twin is hand-built using it as the visual spec: layout-id pill → translated `Animated.View`; framer sheets → section 6; SVG charts → Skia (native) / SVG (web); shimmer → Reanimated opacity; slide-to-confirm #29304 → `Gesture.Pan` (Senryo `trade/SlideToConfirm.tsx`, replace the slider in `crosschain/move-ticket.tsx`).

## 9. Tokens pipeline (`packages/ui-tokens`)
`tokens.json` → `node build.mjs && node check-contrast.mjs` → `native.css` (Uniwind `@theme` + `@variant light|dark|testnet|testnet-dark`), `web.css` (shadcn `:root/.dark` + `[data-network=testnet]`), `tokens.ts`.
- `build.mjs` throws if any theme lacks a token. A new token (`up`, `down`, `accent-fill`, `fill-edge`, `raised-2`, `sheet-handle`) must be added to light, dark and both testnet layers.
- Radius, spacing, type roles and motion are not in the pipeline (radius is one number). Add them to `tokens.json` and emit `--radius-*`, or keep type roles in `packages/config`.
- Native code that needs colours as strings (Skia, Gorhom): `useCSSVariable("--color-primary")` from `uniwind` (returns hex on native). `Uniwind.setTheme()` switches themes at runtime; new themes need `extraThemes` in `metro.config.js`.
- Gotcha: Uniwind's native `--font-*` takes one family name, no fallbacks.

## 10. Money-path defaults and perf knobs
- Cues and haptics never block or throw into a money flow. Success cue only after confirmed state, with a stable id so a remount cannot replay it (existing `completed` set).
- Hold/slide confirms: commit at 90% and haptic on each detent; never auto-confirm on release without velocity check.
- Keep per-tick work off React: shared values + `TextInput` props, Skia `Picture` on the UI thread. Mount sheets lazily. Skeletons pulse 1200 ms.
