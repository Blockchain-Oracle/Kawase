## Summary (10 bullets)

1. Mastra weekly workshop with Anthony Colani (Circle). This is the most complete public walkthrough of the **Circle Agent Stack**.
2. Stats cited: about 70k active paying agents, more than 165M x402 transactions, average payment about $0.25; 99% of x402 transactions settle in USDC.
3. Agent Stack components: Agent Marketplace (discovery of machine-callable paid services), Agent Wallets (policy-bound), Nanopayments (batched, gas-free, down to $0.000001), Circle CLI (deterministic command surface), Circle Skills (instructions for the agent).
4. Division of labour: the framework (Mastra) orchestrates, handling reasoning, memory, tracing and human-in-the-loop, while the Agent Stack provides the money rails.
5. **Wallet policies are the real control**: max per transaction, rolling daily/weekly/monthly limits, recipient and contract allow/block lists. The agent cannot change its own policy; only a human can, through the CLI. A prompt gives guidance; the policy gives enforcement.
6. Demo policy: max $0.05 per transaction and $0.15 per rolling day. The agent had to ask for approval and stay under the cap.
7. Nanopayments flow: request, 402 with price, the wallet signs an authorization for the exact amount, Circle verifies and debits the Gateway balance, the service returns data immediately, and settlement is batched onchain later (one fee for thousands of payments).
8. Demo task: a 20-minute partner brief. The agent searches the marketplace, avoids buying redundant sources, prices options, asks for approval and pays in USDC. Traced in Mastra Studio.
9. Q&A notes: marketplace quality and ratings are a known open question; policies are the defence against rogue agents.
10. Closing: "Arc is going to be launching on September 16th" (said 2026-09-09; verify mainnet status separately). Circle grants are run by Anthony. Start at agents.circle.com. A Mastra template is forthcoming.
