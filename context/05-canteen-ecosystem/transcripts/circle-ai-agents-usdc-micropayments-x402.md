## Summary (10 bullets)

1. Anthony Colani (Circle, Director of Ecosystem Growth) live demo of an agent that creates its own wallet, funds it, and pays for an x402 API.
2. Problem: card fees (a flat fee plus bps) make a 1-cent API call cost up to 30x its revenue. Agents have no accounts, cards or API keys.
3. x402 revives HTTP 402: the server replies 402 with payment requirements, the client signs an authorization, retries with an X-PAYMENT header, and the facilitator verifies and settles.
4. Components: a LangChain agent (GPT-4 mini), an Express API with the x402 middleware npm package, Circle Developer-Controlled Wallets (MPC; keys never exposed), and a facilitator (in the demo, Coinbase's free Base facilitator).
5. Gotcha: create the agent wallet with account type **EOA** (generic EOA), which the Circle signing APIs require.
6. Agent tools: wallet creation, wallet funding (Circle faucet API), a risk-profile tool (paid API), and a decoy weather tool to show correct tool selection.
7. The server middleware only needs the recipient address, price, network and facilitator URL. You can point it at your own facilitator.
8. Flow shown end to end: request, 402, sign through the Circle signing API, retry, facilitator settles onchain, 200 with data.
9. Use case shown: paying for a wallet risk-profile report. This maps directly to RFB 5 (compliance agent pays for screening data per call).
10. Code was promised as open source. The Arc-native equivalent is `circlefin/arc-x402-circle-wallets` (RFB 4 sample in the Tameion slides).
