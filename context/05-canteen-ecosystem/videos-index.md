## How to add more transcripts
```bash
yt-dlp --skip-download --write-auto-subs --write-subs --sub-langs "en,en-orig" --sub-format vtt -o '<dir>/%(id)s' <url>
# if you get "Sign in to confirm you're not a bot" / 429: wait, or add --cookies-from-browser chrome
```
The VTT→text cleaner used here: `.firecrawl/canteen/vtt2txt.py` (run inside the directory of .vtt files; then `sed -i "" "s/&nbsp;/ /g"`). It strips timing and tags, collapses rolling-caption duplicates, and replaces `&nbsp;`.
