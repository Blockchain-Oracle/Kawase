        ▼                                          ▼

## عقل واحد

تخدم `agentTurn()` في `packages/agent` **الدردشة** و**الصوت** بالطريقة نفسها. يرسل عامل الصوت ما سمعه إلى الدورة نفسها،
وبالأدوات والحدود وسلسلة المحادثة نفسها. النموذج (OpenAI `gpt-5.6-luna` تلقائياً، ويُختار عبر سجل النماذج) **يقترح**
فقط: لا تحصل أي أداة على شبكة أو عنوان أو علامة «موافقة». يحدد الكود المستلم، ويطبّق السياسة، ويبني المعاملة وينفذها.

## سياسة نقية ونوايا واضحة

- `packages/policy` دالة نقية تحول الحقائق إلى نتائج (أخطاء، حالات رفض، شروط مسبقة، طلبات توضيح، تحذيرات)
  بالإضافة إلى **المسار**: بدل الإنفاق أو توقيع المحفظة. تعمل عند إعداد البطاقة، ومرة أخرى عند الموافقة باستخدام
  حقائق جديدة، ومرة ثالثة عند التنفيذ.
- يعرّف `packages/intents` كل إجراء على أنه **مسودة** ذات إصدار ومُجزّأة باستخدام EIP-712
  (`SendDraft` و`SwapDraft` و`BridgeDraft` و`EarnDraft`). تحدد الموافقة الإصدار الدقيق الذي توافق عليه؛ وأي تغيير
  ينشئ إصداراً جديداً.
- **التحديد والاستئناف**: عندما يكون شيء ما مفقوداً (جهة اتصال أو عملة أو تسجيل دخول)، يستمر الإصلاح في النية نفسها
  بدلاً من البدء من جديد.

## مسارات الأموال

- **عمليات الإرسال باستخدام البدل**: حجز في سجل الإنفاق تحت قفل خاص بكل مستخدم، ثم تسترد محفظة وكيل Kawase
  (وهي محفظة يتحكم فيها المطور باستخدام Circle) تفويضك؛ ويُقارن سجل `Transfer` في الإيصال بالمسودة.
- **الإجراءات الموقعة بالمحفظة** (ما سبق حد البدل، وعمليات التبديل، والنقل، وتحقيق العائد): تبني واجهة API المعاملة
  الدقيقة — وبالنسبة إلى عمليات App Kit، تُلتقط استدعاءات الحزمة وتُفحص، ثم تُغلّف في دفعة ذاتية واحدة باستخدام
  EIP-7702 — ويوقّعها الجهاز باستخدام Face ID، ثم تتحقق واجهة API من البايتات الموقعة مقابل المسودة قبل بثها.
- **تُتتبّع عمليات النقل** في ثلاث مراحل: الحرق على Arc، وتصديق Circle، والإصدار على السلسلة الوجهة.
- تعمل **الأتمتة** في مشغّل واجهة API كل 30 ثانية: يُطالَب بكل تكرار مرة واحدة بالضبط، وتُعاد مراجعته باستخدام
  حقائق جديدة، ثم تُدفع الأموال عبر مسار الإرسال أو تحقيق العائد أو النقل نفسه، وبموجب المنحة الخاصة بالأتمتة.
- **ضمان عدم التكرار في كل مكان**: يُخزّن مفتاح عدم التكرار في Circle قبل الاتصال بـ Circle؛ وتُخزّن تجزئة
  المعاملات الخام قبل بثها؛ وتتحول النتائج غير الواضحة إلى `unknown_outcome`، ولا يُعاد إرسالها أبداً، بل يُعاد فحصها فقط.

## البيانات

يُعد **Postgres 17 مع Drizzle** مخزن البيانات الوحيد وناقل الرسائل الوحيد: تُكتب علبة الصادر في المعاملة نفسها
مع كل تغيير، ويُستخدم `pg_notify` لإرسال الأحداث عبر الأحداث المرسلة من الخادم، ويكون جدول الوارد مصدر الحقيقة
للإشعارات. تُخزّن الأموال بوحدات أساسية دقيقة (`numeric(78,0)` و`bigint` في TypeScript)، وتكون المعرّفات UUIDv7.

## المستودع الأحادي

| الجزء | ماهيته |
|---|---|
| `apps/api` | واجهة Hono البرمجية: المصادقة، وتدفق دردشة الوكيل، والنوايا والموافقات، والمشغّلات، وخطافات الويب |
| `apps/mobile` | Expo 57 / React Native 0.86: تطبيق iOS وAndroid والويب |

| `apps/landing` | العرض التعريفي وحزمة التحكيم |
| `packages/config` | كل الثوابت: الحدود، وسجل الإمكانات، واللغات، والصوت، والمهل الزمنية |
| `packages/policy`, `packages/intents` | محرك السياسات النقي ومسودات EIP-712 |
| `packages/integrations/*` | التفويضات (MetaMask Delegation Framework) وCircle App Kit |

## واجهة API العامة

تتوفر واجهة API على `https://kawase-api.84.46.247.92.sslip.io`. نقاط النهاية العامة التي لا تتطلب مصادقة:

| نقطة النهاية | ما تُعيده |
|---|---|
| `GET /health` | `{ ok, networks }` |
| `GET /capabilities` | سجل الإمكانات مع التجاوزات وقت التشغيل، لكل شبكة |
| `GET /public/stats` | أعداد إجمالية فقط (عمليات الإرسال المكتملة، وعمليات التبديل، وعمليات النقل، وحركات تحقيق العائد، وتشغيل الأتمتة، والحسابات) |

كل ما عدا ذلك يحتاج إلى جلسة (رمز bearer من التطبيق أو ملف تعريف ارتباط على الويب).

## الاستضافة

يعمل كل شيء على خادم **Coolify** خلف Traefik مع Let's Encrypt: واجهة API، وتطبيق الويب، وعامل الصوت، ووثائقنا
وهذا العرض التعريفي، بالإضافة إلى Postgres. كل خدمة هي Dockerfile يُبنى من جذر المستودع الأحادي؛ وتستمع الخدمات على `::`
(إذ تحل فحوصات صحة Coolify العنوان `localhost` إلى IPv6).

## اختبارات تثبت ذلك

تُشغّل الاختبارات على شبكة Arc التجريبية باستخدام معاملات حقيقية (`pnpm --filter @kawase/api test`): عمليات الإرسال (بالبدل
والموقعة بالمحفظة، والنقر المزدوج ← عملية إرسال واحدة، ورفض التواقيع التي تم العبث بها)، وعمليات التبديل، وعمليات النقل
(الحرق ← التصديق ← الإصدار)، وإيداعات وسحوبات تحقيق العائد، والأتمتة المجدولة، والحفظ التلقائي، والقواعد، والاسترداد
بعد العمليات المتوقفة. وتثبت حزمة التفويضات الحدود على السلسلة بشكل مستقل (`pnpm --filter @kawase/integrations-delegation test:arc-testnet`).
