## الشكل

[![Kawase architecture diagram: one app feeds a shared agent turn, voice runs through LiveKit, and the API connects to Postgres, Privy, Arc, and Circle](/media/architecture/architecture.png)](/media/architecture/architecture.png)

## عقل واحد

تخدم `agentTurn()` في `packages/agent` كلاً من **الدردشة** و**الصوت**: يرسل عامل الصوت ما سمعه إلى الدورة نفسها،
باستخدام الأدوات والحدود وسلسلة المحادثة نفسها. النموذج (OpenAI `gpt-5.6-luna` تلقائياً، ويُختار عبر سجل النماذج) لا
**يقترح** إلا الإجراءات: فلا توجد أداة تختار شبكة أو عنواناً أو علامة «موافقة». يحلّ الكود هوية المستلم، ويطبّق السياسة،
ويبني المعاملة وينفّذها.

## سياسة نقية ونوايا واضحة

- `packages/policy` دالة نقية تحوّل الحقائق إلى نتائج (أخطاء ورفض وشروط مسبقة وطلبات توضيح وتحذيرات)
  بالإضافة إلى **المسار**: حد الإنفاق أو توقيع المحفظة. تُشغّل عند إعداد البطاقة، ومرة أخرى عند الموافقة باستخدام
  حقائق جديدة، ومرة ثالثة عند التنفيذ.
- يعرّف `packages/intents` كل إجراء على أنه **مسودة** ذات إصدار ومجزأة باستخدام EIP-712
  (`SendDraft` و`SwapDraft` و`BridgeDraft` و`EarnDraft`). تحدد الموافقة الإصدار الدقيق الذي توافق عليه؛ وأي تغيير
  ينشئ إصداراً جديداً.
- **الحل والاستئناف**: عندما ينقص شيء ما (جهة اتصال أو عملة أو تسجيل دخول)، يتابع الإصلاح النية نفسها بدلاً من البدء من جديد.

## مسارات الأموال

- **الإرسال عبر حد الإنفاق**: حجز في دفتر الإنفاق ضمن قفل خاص بكل مستخدم، ثم تسترد محفظة وكيل Kawase (محفظة
  يتحكم فيها مطوّر لدى Circle) تفويضك؛ ويُقارن سجل `Transfer` في الإيصال بالمسودة.
- **الإجراءات الموقعة بالمحفظة** (المذكورة أعلاه، وما يتجاوز حد الإنفاق، والمقايضات، وعمليات النقل، وتحقيق العائد): تبني
  واجهة API المعاملة الدقيقة — وبالنسبة إلى عمليات App Kit، تُلتقط استدعاءات الحزمة وتُفحص، ثم تُغلّف في دفعة ذاتية
  واحدة باستخدام EIP-7702 — ويوقّعها الجهاز باستخدام Face ID، ثم تتحقق واجهة API من مطابقة البايتات الموقّعة للمسودة قبل بثها.
- **عمليات النقل** تُتتبّع عبر ثلاث مراحل: الحرق على Arc، وتصديق Circle، وإصدار الرموز على الشبكة الوجهة.
- تعمل **الأتمتة** في عامل التشغيل لدى واجهة API كل 30 ثانية: تتم المطالبة بكل استحقاق مرة واحدة بالضبط، وتُعاد
  المراجعة باستخدام حقائق جديدة، ثم تُدفع عبر مسار الإرسال أو تحقيق العائد أو النقل نفسه، وبموجب المنحة الخاصة بالأتمتة.
- **التعامل مع التكرار في كل مكان**: يُخزّن مفتاح منع التكرار الخاص بـ Circle قبل استدعاء Circle؛ وتُخزّن تجزئة
  المعاملات الخام قبل بثها؛ وتتحول النتائج الغامضة إلى `unknown_outcome` ولا يُعاد إرسالها أبداً، بل يُعاد التحقق منها فقط.

## البيانات

يُعد **Postgres 17 مع Drizzle** مخزن البيانات الوحيد وحافلة الرسائل الوحيدة: صندوق صادر يُكتب في المعاملة نفسها مع كل
تغيير، و`pg_notify` لبث الأحداث عبر الأحداث المرسلة من الخادم، وجدول صندوق وارد كمصدر الحقيقة للإشعارات. تُخزّن
الأموال بوحدات أساسية دقيقة (`numeric(78,0)` و`bigint` في TypeScript)، وتكون المعرّفات من نوع UUIDv7.

## المستودع الموحد

| الجزء | ماهيته |
|---|---|
| `apps/api` | واجهة Hono API: المصادقة، وتدفق دردشة الوكيل، والنوايا والموافقات، وعوامل التشغيل، وخطافات الويب |
| `apps/mobile` | Expo 57 / React Native 0.86: تطبيق iOS وAndroid والويب |
| `apps/voice-agent` | عامل LiveKit Agents (Node) |
| `apps/docs` | هذا الموقع (Fumadocs 16 وNext 16) |
| `apps/landing` | العرض التوضيحي وحزمة التحكيم |
| `packages/config` | كل الثوابت: الحدود، وسجل الإمكانات، واللغات المحلية، والصوت، والمهلات |
| `packages/policy`, `packages/intents` | محرك السياسة النقي ومسودات EIP-712 |
| `packages/integrations/*` | التفويضات (MetaMask Delegation Framework) وCircle App Kit |
| `packages/networks`, `packages/money` | شبكتا Arc والعناوين التي تم التحقق منها؛ وأنواع الأموال الدقيقة |
| `packages/identity` | شعارات حقيقية مع مصدرها |

## واجهة API العامة

تتوفر واجهة API على `https://api.getkawase.xyz`. نقاط النهاية العامة التي لا تتطلب مصادقة:

| نقطة النهاية | ما تُعيده |
|---|---|
| `GET /health` | `{ ok, networks }` |
| `GET /capabilities` | سجل الإمكانات مع التجاوزات أثناء التشغيل، لكل شبكة |
| `GET /public/stats` | أعداد إجمالية فقط (عمليات الإرسال والمقايضات وعمليات النقل وتحركات تحقيق العائد وعمليات تشغيل الأتمتة والحسابات المكتملة) |

كل ما عدا ذلك يحتاج إلى جلسة (رمز bearer من التطبيق أو ملف تعريف ارتباط على الويب).

## الاستضافة

يعمل كل شيء على خادم **Coolify** خلف Traefik مع Let's Encrypt: واجهة API، وتطبيق الويب، وعامل الصوت، وهذه الوثائق
والعرض التوضيحي، بالإضافة إلى Postgres. كل خدمة عبارة عن Dockerfile يُبنى من جذر المستودع الموحد؛ وتستمع الخدمات على `::`
(إذ تحل فحوصات صحة Coolify العنوان `localhost` إلى IPv6).

## الاختبارات التي تثبت ذلك

تُجرى الاختبارات على الشبكة التجريبية لـ Arc باستخدام معاملات حقيقية (`pnpm --filter @kawase/api test`): الإرسال (عبر حد الإنفاق
وبتوقيع المحفظة، والنقر المزدوج ← إرسال واحد، ورفض التوقيعات التي تم العبث بها)، والمقايضات، وعمليات النقل (الحرق ← التصديق ← الإصدار)،
وإيداعات وسحوبات تحقيق العائد، والأتمتة المجدولة، والحفظ التلقائي، والقواعد، والاسترداد بعد انقطاع عمليات التشغيل. وتثبت حزمة التفويض
الحدود على السلسلة بشكل مستقل (`pnpm --filter @kawase/integrations-delegation test:arc-testnet`).
