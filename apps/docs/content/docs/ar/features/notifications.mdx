يُعد **صندوق الوارد** في Kawase سجلاً لكل شيء: كل دفعة مستلمة، وكل طلب تم دفعه، وكل دفعة اكتملت، وكل أتمتة تم تخطيها، وكل تنبيه لقاعدة يصل إليه. ويؤدي الضغط على أي منها إلى فتح الشاشة المناسبة.

بالإضافة إلى صندوق الوارد، يمكن لـ Kawase إبلاغك عبر **الإشعارات الفورية** (على هاتفك) والبريد الإلكتروني. في الإعدادات ← الإشعارات، تختار ما يصلك لكل حدث ولكل قناة. الإعدادات الافتراضية:

| الحدث | الإشعارات الفورية | البريد الإلكتروني |
|---|---|---|
| استلام الأموال | مفعّلة | مفعّلة |
| تم دفع طلبك | مفعّلة | مفعّلة |
| اكتملت دفعتك | مفعّلة | غير مفعّلة |
| تم تخطي إحدى الأتمتة | مفعّلة | مفعّلة |
| تنبيه لقاعدة | مفعّلة | مفعّلة |

تؤجل **ساعات الهدوء**، وفق منطقتك الزمنية، الإشعارات الفورية حتى الصباح، بينما يستمر إرسال البريد الإلكتروني. ولا يمكن كتم أحداث الأمان مطلقًا.

يُرسل كل إشعار مرة واحدة كحد أقصى عبر كل قناة، حتى إذا أعاد Kawase المحاولة. وتأتي خدمة الإشعارات الفورية والبريد الإلكتروني مضمّنة في التطبيق والخادم. ويتم تفعيلها عند ربط حسابات مزوّدي الإشعارات الفورية (Apple وGoogle) والبريد الإلكتروني بالإصدار العام. أما صندوق الوارد فهو يعمل اليوم.
