## ثبّته

Kawase تطبيق ويب قابل للتثبيت. في Chrome أو Edge استخدم **تثبيت**، وفي Safari **إضافة إلى Dock** (Mac) أو **إضافة إلى الشاشة
الرئيسية** (iPhone). إذا انقطعت الشبكة، تقول ذلك صفحة دون اتصال بدل شاشة معطوبة. لا يخزّن Kawase الأرصدة مؤقتًا أبدًا، فلا يُعرض
شيء قديم على أنه مال حالي.
