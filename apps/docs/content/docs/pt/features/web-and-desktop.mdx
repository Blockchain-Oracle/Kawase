## Confirmar na web

Onde um celular pede Face ID, o app web envia um **código por email**: você digita os seis dígitos e o pagamento sai. A voz
também funciona: permita o microfone quando o navegador pedir. Se você recusar, o Kawase explica como permitir, e o teclado
está logo ali.

## Instalar

O Kawase é um app web instalável. No Chrome ou no Edge use **Instalar**; no Safari, **Adicionar ao Dock** (Mac) ou
**Adicionar à Tela de Início** (iPhone). Se a rede cair, uma página offline avisa em vez de uma tela quebrada. O Kawase nunca
guarda saldos em cache, então nada antigo aparece como dinheiro atual.

## O app para Mac

O Kawase para Mac está a caminho. Até lá, o app web roda em qualquer navegador no seu Mac, com voz. Veja
[getkawase.xyz/download](https://getkawase.xyz/download) para cada plataforma.
