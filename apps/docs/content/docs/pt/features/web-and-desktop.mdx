## No navegador

Abra [app.getkawase.xyz](https://app.getkawase.xyz). Você começa como **convidado**, e tudo funciona como no celular:
chat, cartões, Mercados, Voz e todas as telas.

- **Confirmar um pagamento**: um **código enviado por e-mail** substitui o Face ID.
- **Voz**: toque no orbe e permita o acesso ao microfone quando o navegador pedir. Se você recusar, o Kawase explica como permitir o acesso, e
  a digitação fica logo ali.
- **Instalar**: o Kawase é um app web instalável. No Chrome ou Edge, use **Instalar**. No Safari, use **Adicionar ao Dock** (Mac) ou
  **Adicionar à Tela de Início** (iPhone). Se a conexão cair, uma página offline informa o problema em vez de mostrar uma tela quebrada. O Kawase nunca
  armazena saldos em cache. Assim, um valor antigo nunca é mostrado como dinheiro atual.

## O app para desktop (Mac)

[Baixe o Kawase para Mac](https://getkawase.xyz/download/Kawase-mac.dmg) (Apple silicon, cerca de 2 MB), abra a imagem de disco
e arraste o Kawase para Aplicativos.

<Callout type="warn">
**Ainda não foi notarizado pela Apple: na primeira vez, clique com o botão direito no Kawase → Abrir.** No macOS 15 ou posterior, abra o app uma vez e depois acesse
**Ajustes do Sistema → Privacidade e Segurança** e escolha **Abrir Mesmo Assim**. Esta é uma versão de prévia, não uma versão assinada.
</Callout>

Ele é o app web ao vivo em uma janela nativa. Por isso, está **sempre na versão atual**, sem precisar atualizar:

- a barra de título usa as cores do Kawase e acompanha o modo claro ou escuro;
- copiar, colar e os menus comuns funcionam; ⌘+ e ⌘− ajustam o zoom;
- os **links `kawase://`** (iguais aos do celular) abrem a página correspondente na janela. Por exemplo, `kawase://r/…` abre
  um pedido de pagamento;
- as janelas de login abrem dentro do app, e qualquer outro site (um explorador, esta documentação) abre no navegador;
- a página **não tem acesso ao seu computador** além da janela em que é executada.

A Voz no app para desktop ainda não foi testada. Use o app web em um navegador ou o celular para usar a Voz.

As versões para Windows e Linux vêm do mesmo código-fonte (`apps/desktop`), mas ainda não foram compiladas.
