O Kawase fala os idiomas mais falados do mundo em todas as partes do app:

| Idioma | Nome no idioma | Direção |
|---|---|---|
| Inglês | English | da esquerda para a direita |
| Chinês | 中文 | da esquerda para a direita |
| Hindi | हिन्दी | da esquerda para a direita |
| Espanhol | Español | da esquerda para a direita |
| Francês | Français | da esquerda para a direita |
| Árabe | العربية | **da direita para a esquerda** |
| Bengali | বাংলা | da esquerda para a direita |
| Português | Português | da esquerda para a direita |
| Russo | Русский | da esquerda para a direita |
| Urdu | اردو | **da direita para a esquerda** |

- **Desde a primeira tela.** O seletor de idioma aparece no primeiro painel de introdução e em todas as telas seguintes. A troca é
  instantânea, incluindo a direção do texto.
- **Todas as frases em todos os idiomas.** Os dez catálogos do app estão completos. O agente responde no seu idioma e a
  [voz](./voice.mdx) entende e fala os dez idiomas.
- **Os valores continuam exatos.** Os números são formatados para o seu idioma, enquanto valores, endereços e códigos continuam da esquerda para a direita
  para que possam ser conferidos caractere por caractere.
- **Esta documentação** está disponível nos mesmos dez idiomas. Use o seletor de idioma na barra lateral.
