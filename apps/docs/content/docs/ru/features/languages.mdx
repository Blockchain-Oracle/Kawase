Kawase говорит на самых распространённых языках мира — во всех разделах приложения:

| Язык | Название на этом языке | Направление |
|---|---|---|
| Английский | English | слева направо |
| Китайский | 中文 | слева направо |
| Хинди | हिन्दी | слева направо |
| Испанский | Español | слева направо |
| Французский | Français | слева направо |
| Арабский | العربية | **справа налево** |
| Бенгальский | বাংলা | слева направо |
| Португальский | Português | слева направо |
| Русский | Русский | слева направо |
| Урду | اردو | **справа налево** |

- **С первого экрана.** Переключатель языка находится на первой панели знакомства с приложением и на всех последующих экранах. Изменения применяются
  сразу, включая направление письма.
- **Каждая строка на каждом языке.** Все десять языковых каталогов полностью переведены. Агент отвечает на вашем языке, а [голос](./voice.mdx) распознаёт речь и говорит на всех десяти языках.
- **Суммы остаются точными.** Числа форматируются с учётом вашего языка, а суммы, адреса и коды остаются написанными слева направо,
  чтобы их можно было проверить посимвольно.
- **Эта документация** доступна на тех же десяти языках. Переключить язык можно в боковой панели.
