## Единый мозг

`agentTurn()` в `packages/agent` одинаково обслуживает **чат** и **голос**: голосовой исполнитель отправляет то, что услышал, в тот же ход,
с теми же инструментами, лимитами и тредом. Модель (по умолчанию OpenAI `gpt-5.6-luna`, выбранная через реестр моделей) только
**предлагает** действия: ни один инструмент не получает сеть, адрес или флаг «подтвердить». Код определяет получателя, запускает
политику, создаёт транзакцию и выполняет её.

## Чистая политика и явные намерения

- `packages/policy` — чистая функция, которая преобразует факты в результаты: ошибки, отказы, предварительные условия, уточнения и предупреждения,
  а также **маршрут**: разрешение на списание или подпись кошелька. Она запускается при создании карточки, снова при подтверждении со свежими
  фактами и ещё раз при выполнении.
- `packages/intents` описывает каждое действие как версионируемый **черновик** с хешем EIP-712 (`SendDraft`, `SwapDraft`, `BridgeDraft`,
  `EarnDraft`). В подтверждении указывается точная версия, которую пользователь подтверждает. Любое изменение создаёт новую версию.
- **Определение и продолжение**: если чего-то не хватает — контакта, валюты или входа в аккаунт — исправление продолжает то же намерение,
  а не запускает процесс заново.

## Денежные операции

- **Отправка в рамках разрешения**: резервирование суммы в реестре расходов под блокировкой пользователя, затем агентский кошелёк Kawase
  (кошелёк Circle под управлением разработчика) использует вашу делегацию; лог `Transfer` в квитанции сравнивается с черновиком.
- **Действия с подписью кошелька** (выше лимита разрешения, обмены, мосты, доходность): api создаёт точную транзакцию — для операций App
  Kit вызовы набора перехватываются и проверяются, затем объединяются в один самостоятельный пакет EIP-7702; устройство подписывает
  его с помощью Face ID, а api проверяет подписанные байты по черновику перед отправкой в сеть.
- **Мосты** отслеживаются по трём этапам: сжигание в Arc, аттестация Circle и выпуск в целевой сети.
- **Автоматизации** запускаются в исполнителе api каждые 30 секунд: каждый запуск обрабатывается ровно один раз, повторно проверяется
  по свежим фактам и оплачивается через тот же путь отправки, доходности или моста с использованием собственного разрешения автоматизации.
- **Идемпотентность везде**: ключ идемпотентности Circle сохраняется до вызова Circle; хеши необработанных транзакций сохраняются до отправки
  в сеть; неоднозначные результаты получают статус `unknown_outcome` и только проверяются повторно, но никогда не отправляются ещё раз.

## Данные

**Postgres 17 с Drizzle** — единственное хранилище и единственная шина сообщений: outbox записывается в той же транзакции, что и каждое
изменение, `pg_notify` передаёт события через server-sent events, а таблица inbox служит источником истины для уведомлений. Деньги хранятся
в точных базовых единицах (`numeric(78,0)`, `bigint` в TypeScript); идентификаторы — UUIDv7.

## Монорепозиторий

| Часть | Что это |
|---|---|
| `apps/api` | API на Hono: аутентификация, поток чата с агентом, намерения и подтверждения, исполнители, вебхуки |
| `apps/mobile` | Expo 57 / React Native 0.86: приложение для iOS, Android и веба |
| `apps/voice-agent` | Рабочий процесс LiveKit Agents (Node) |
| `apps/docs` | этот сайт (Fumadocs 16, Next 16) |
| `apps/landing` | витрина и набор для судей |
| `packages/config` | все константы: лимиты, реестр возможностей, локали, голос, тайм-ауты |
| `packages/policy`, `packages/intents` | чистый движок политик и черновики EIP-712 |
| `packages/integrations/*` | делегации (MetaMask Delegation Framework), Circle App Kit |
| `packages/networks`, `packages/money` | две сети Arc и проверенные адреса; точные типы денег |
| `packages/identity` | настоящие логотипы с указанием источника |

## Публичный API

API доступен по адресу `https://kawase-api.84.46.247.92.sslip.io`. Публичные эндпоинты без аутентификации:

| Эндпоинт | Возвращает |
|---|---|
| `GET /health` | `{ ok, networks }` |
| `GET /capabilities` | реестр возможностей с переопределениями во время работы для каждой сети |
| `GET /public/stats` | только общие количества (завершённые отправки, обмены, операции через мост, операции доходности, запуски автоматизаций, аккаунты) |

Для всего остального нужна сессия: bearer-токен из приложения или cookie в вебе.

## Хостинг

Всё работает на сервере **Coolify** за Traefik с Let's Encrypt: api, веб-приложение, голосовой исполнитель, эта документация
и витрина, а также Postgres. Каждый сервис собирается из Dockerfile в корне монорепозитория; сервисы слушают `::`
(проверки состояния Coolify преобразуют `localhost` в IPv6).

## Тесты, которые это подтверждают

Тесты запускаются в тестовой сети Arc с настоящими транзакциями (`pnpm --filter @kawase/api test`): отправка денег (в рамках разрешения и с подписью кошелька,
двойное нажатие → одна отправка, подделанные подписи отклоняются), обмены, операции через мост (сжигание → аттестация → выпуск), пополнения
и вывод средств для доходности, запланированные автоматизации, автосбережение, правила и восстановление после прерванных запусков. Пакет делегаций
самостоятельно проверяет лимиты в блокчейне (`pnpm --filter @kawase/integrations-delegation test:arc-testnet`).
