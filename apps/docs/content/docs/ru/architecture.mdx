## Общая схема

[![Kawase architecture diagram: one app feeds a shared agent turn, voice runs through LiveKit, and the API executes through Arc and Circle](/media/architecture/architecture-v2.png)](/media/architecture/architecture-v2.png)

## Единый мозг

`agentTurn()` в `packages/agent` одинаково обслуживает **чат** и **голос**: голосовой воркер отправляет то, что услышал, в тот же ход,
с теми же инструментами, лимитами и веткой. Модель (по умолчанию OpenAI `gpt-5.6-luna`, выбранная через реестр моделей) только
**предлагает** действия: ни один инструмент не получает сеть, адрес или флаг «подтвердить». Код определяет получателя, запускает проверку политик, формирует транзакцию и выполняет её.

## Чистая политика и явные намерения

- `packages/policy` — чистая функция, которая преобразует факты в результаты (ошибки, отказы, предварительные условия, уточнения и предупреждения),
  а также определяет **маршрут**: лимит трат или подпись кошелька. Она запускается при создании карточки, ещё раз при подтверждении со свежими
  фактами и ещё раз во время выполнения.
- `packages/intents` описывает каждое действие как версионируемый **черновик** с хешем EIP-712 (`SendDraft`, `SwapDraft`, `BridgeDraft`,
  `EarnDraft`). В подтверждении указывается точная версия, которую оно разрешает. Любое изменение создаёт новую версию.
- **Определение и продолжение**: если чего-то не хватает (контакта, валюты или входа в аккаунт), исправление продолжает то же намерение,
  а не начинает всё заново.

## Денежные операции

- **Отправка с лимитом**: резервирование в реестре трат под блокировкой пользователя, после чего агентский кошелёк Kawase (кошелёк
  Circle под управлением разработчика) погашает вашу делегацию; лог `Transfer` в квитанции сравнивается с черновиком.
- **Действия с подписью кошелька** (выше лимита, обмены, мосты, доходность): API формирует точную транзакцию — для операций App
  Kit вызовы набора перехватываются и проверяются, затем объединяются в один self-batch EIP-7702; устройство подписывает
  его с помощью Face ID, а API проверяет подписанные байты на соответствие черновику перед отправкой в сеть.
- **Мосты** отслеживаются по трём этапам: сжигание в Arc, аттестация Circle и выпуск токенов в целевой сети.
- **Автоматизации** запускаются в исполнителе API каждые 30 секунд: каждое срабатывание принимается ровно один раз, повторно проверяется по свежим
  фактам и оплачивается через тот же путь отправки, доходности или моста с использованием отдельного разрешения автоматизации.
- **Идемпотентность везде**: ключ идемпотентности Circle сохраняется до вызова Circle; хеши сырых транзакций сохраняются
  до отправки; неоднозначные результаты получают статус `unknown_outcome` и только проверяются повторно — повторно не отправляются.

## Данные

**Postgres 17 с Drizzle** — единственное хранилище и единственная шина сообщений: outbox записывается в той же транзакции, что и каждое
изменение, `pg_notify` передаёт события через server-sent events, а таблица inbox служит источником истины для
уведомлений. Деньги хранятся в точных базовых единицах (`numeric(78,0)`, `bigint` в TypeScript); идентификаторы — UUIDv7.

## Монорепозиторий

| Часть | Что это |
|---|---|
| `apps/api` | API на Hono: аутентификация, поток чата с агентом, намерения и подтверждения, исполнители, вебхуки |
| `apps/mobile` | Expo 57 / React Native 0.86: приложение для iOS, Android и веба |
| `apps/voice-agent` | Воркер LiveKit Agents (Node) |
| `apps/docs` | этот сайт (Fumadocs 16, Next 16) |
| `apps/landing` | презентационный сайт и набор материалов для жюри |
| `packages/config` | все константы: лимиты, реестр возможностей, локали, голос, тайм-ауты |
| `packages/policy`, `packages/intents` | чистый движок политик и черновики EIP-712 |
| `packages/integrations/*` | делегации (MetaMask Delegation Framework), Circle App Kit |
| `packages/networks`, `packages/money` | две сети Arc и проверенные адреса; точные типы денег |
| `packages/identity` | настоящие логотипы с указанием источника |

## Публичный API

API доступен по адресу `https://api.getkawase.xyz`. Публичные конечные точки без аутентификации:

| Конечная точка | Возвращает |
|---|---|
| `GET /health` | `{ ok, networks }` |
| `GET /capabilities` | реестр возможностей с динамическими переопределениями для каждой сети |
| `GET /public/stats` | только общие счётчики (завершённые отправки, обмены, мосты, операции доходности, запуски автоматизаций, аккаунты) |

Для всего остального нужна сессия (токен bearer из приложения или cookie в вебе).

## Хостинг

Всё работает на сервере **Coolify** за Traefik с Let's Encrypt: API, веб-приложение, голосовой воркер, эта документация
и презентационный сайт, а также Postgres. Каждый сервис собирается из Dockerfile в корне монорепозитория; сервисы слушают `::`
(проверки состояния Coolify определяют `localhost` как IPv6).

## Тесты, которые это подтверждают

Тесты запускаются в тестовой сети Arc с настоящими транзакциями (`pnpm --filter @kawase/api test`): отправка (с лимитом и с подписью кошелька,
двойное нажатие → одна отправка, подделанные подписи отклоняются), обмены, мосты (сжигание → аттестация → выпуск), пополнения и
выводы доходности, запланированные автоматизации, автосбережение, правила и восстановление после прерванных операций. Пакет делегаций отдельно подтверждает
лимиты в блокчейне (`pnpm --filter @kawase/integrations-delegation test:arc-testnet`).
