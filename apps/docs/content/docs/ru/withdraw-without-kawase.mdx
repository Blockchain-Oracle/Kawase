Kawase никогда не хранит ваши деньги. Ваши USDC и EURC находятся **на вашем собственном аккаунте** в Arc, а выданные агенту разрешения ограничены и автоматически истекают. На этой странице объясняется, как вывести деньги — с помощью Kawase и без него.

<Status ids="export_wallet" />

## Пока Kawase работает: отправьте деньги

Самый быстрый способ вывести деньги — обычный платёж:

<Steps>
<Step>
### Выберите получателя
Адрес под вашим контролем в другом кошельке (MetaMask, Rabby, …) с добавленной сетью **Arc** или адрес для пополнения в бирже через **Arc**. Проверьте, что выбрана сеть Arc: отправка на адрес в другой сети — это не то же самое.
</Step>
<Step>
### Отправьте всё
Скажите: «отправь все мои USDC на 0x…» (вставьте адрес в это же сообщение) или воспользуйтесь экраном отправки. Для крупных сумм потребуется подтверждение через
Face ID. Повторите для EURC.
</Step>
<Step>
### Отзовите разрешения агента
Кошелёк и лимиты → **Отозвать** (нажмите и удерживайте). Отмените все автоматизации: каждая отмена отзывает разрешение в сети.
</Step>
</Steps>

USDC также можно отправить прямо **на ваш собственный адрес** в Base, Ethereum, Arbitrum, Optimism, Polygon или Avalanche с помощью
[моста](./features/bridge-and-withdraw.mdx).

## Проверьте всё в обозревателе

Kawase не нужен, чтобы посмотреть свои деньги. Откройте свой адрес в обозревателе блоков Arc:

- Основная сеть: `https://explorer.arc.io/address/<your address>`
- Тестовая сеть: `https://testnet.arcscan.app/address/<your address>`

Там можно увидеть:

- баланс **USDC** и **EURC** (в Arc USDC также используется как токен газа сети: это один баланс, который отображается и как нативная монета, и как токен USDC);
- все транзакции, включая платежи, которые агент выполнил в рамках выданного ему разрешения;
- **код** аккаунта: после настройки это `0xef0100`, за которым следует адрес `EIP7702StatelessDeleGator`. Это обновление EIP-7702; ваш аккаунт по-прежнему работает как обычный аккаунт.

В чеках Kawase есть ссылки на эти же страницы.

## Если Kawase исчезнет

- **Разрешения агента перестанут работать.** Ваше разрешение и разрешения автоматизаций можно использовать только из кошелька агента Kawase, и они истекают (разрешение — через 90 дней, каждая автоматизация — в указанную дату окончания).
- **Ваши деньги останутся на аккаунте.** Это обычный аккаунт в Arc, ключ от которого хранится для вас в Turnkey.
- **Экспорт кошелька (скоро).** В разделе Настройки → Аккаунт → Экспорт кошелька будет показан ключ вашего кошелька через защищённый экспорт Turnkey после подтверждения Face ID и ознакомления с предупреждениями. С его помощью вы сможете импортировать аккаунт в любой кошелёк с поддержкой Arc и перевести деньги без Kawase. Эта функция **пока недоступна**; пока что используйте описанные выше способы.

## Добавление Arc в другой кошелёк

| | Основная сеть | Тестовая сеть |
|---|---|---|
| Название сети | Arc | Arc Тестовая сеть |
| ID сети | `5042` | `5042002` |
| RPC | `https://rpc.mainnet.arc.io` | `https://rpc.testnet.arc.io` |
| Символ валюты | USDC | USDC |
| Обозреватель | `https://explorer.arc.io` | `https://explorer.testnet.arc.io` |

В некоторых кошельках баланс газа в пользовательских сетях обозначается как «ETH», но в Arc это USDC. Адрес токена USDC в обеих сетях —
`0x3600000000000000000000000000000000000000`; адрес EURC в основной сети —
`0xbEf5f6d51CB62b58e6A8f77868681825C6fe21c1`, а в тестовой сети —
`0x89B50855Aa3bE2F677cD6303Cec089B5F319D72a`.

## Удаление обновления EIP-7702 (необязательно)

Чтобы перевести деньги, отменять обновление не нужно. Если после экспорта вы хотите снова использовать обычный аккаунт, подпишите авторизацию EIP-7702 с нулевым адресом и отправьте её с самого аккаунта, например с помощью viem:

```ts
import { zeroAddress } from "viem";

const authorization = await walletClient.signAuthorization({ contractAddress: zeroAddress, executor: "self" });
await walletClient.sendTransaction({ to: walletClient.account.address, authorizationList: [authorization] });
```

После этого обозреватель не будет показывать код на вашем адресе.
