**Arc** — это сеть стейблкоинов Circle. USDC используется в ней для оплаты газа, поэтому комиссии оплачиваются в долларах, а транзакции завершаются менее чем за
секунду. Kawase поддерживает ровно две сети Arc.

| | Основная сеть Arc | Тестовая сеть Arc |
|---|---|---|
| Деньги | Настоящие деньги | Тестовые деньги без ценности |
| ID сети | `5042` | `5042002` |
| Обозреватель | `explorer.arc.io` | `testnet.arcscan.app` |
| Как получить деньги | Получайте их с любого кошелька или биржи, которые отправляют деньги в Arc; покупка через Apple Pay или карту появится позже | Встроенный кран (примерно 20 USDC + 20 EURC в день) |
| Доходность | Хранилища Morpho, представленные в App Kit от Circle | Тестовые хранилища Morpho в тестовой сети Arc |
| Направления для моста | Base, Ethereum, Arbitrum, Optimism, Polygon, Avalanche | Их тестовые сети (Base Sepolia, Ethereum Sepolia, …) |
| Маркетплейс x402 | Запланирован (каталог Circle доступен только в основной сети) | Недоступен |
| Лимиты по умолчанию | Ниже | В десять раз выше (настоящие деньги не подвергаются риску) |
| Где начинают новые аккаунты | | ✓ |

## Как Kawase разделяет сети

- **Переключение в одно нажатие** в обе стороны: см. [переключатель сети](./features/network-toggle.mdx).
- **Сеть показывается тремя способами**: плашкой в заголовке, полосой тестовой сети или надписью НАСТОЯЩИЕ ДЕНЬГИ, а также цветом сферы.
- **Выбор контролирует сервер.** Каждый платёж готовится для одной сети и проходит через неё до конца. Если сеть меняется в процессе, платёж останавливается и не переходит в другую сеть.
- **Один адрес кошелька в обеих сетях**, а балансы, история операций и лимиты хранятся отдельно для каждой сети.
