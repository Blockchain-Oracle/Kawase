**Arc** 是 Circle 的稳定币网络：USDC 是它的燃料代币，因此手续费以美元支付，交易可在不到一秒内完成。Kawase 支持两个 Arc 网络。

| | Arc 主网 | Arc 测试网 |
|---|---|---|
| 资金 | 真实资金 | 没有价值的测试币 |
| Chain ID | `5042` | `5042002` |
| 区块浏览器 | `explorer.arc.io` | `testnet.arcscan.app` |
| 获取资金 | 通过 Circle 的 Onramp 用银行卡购买；也可以从任何向 Arc 转账的钱包或交易所收款 | 应用内水龙头（每天约 20 USDC + 20 EURC）；Circle 的 Onramp 沙盒，支持测试卡 |
| 交易 | 交易任意代币，包括迷因币；使用 KyberSwap、App Kit 和 LI.FI 中最优的报价 | 仅支持 USDC ↔ EURC |
| 做多和做空 | 通过 Aave V4 使用 Kawase Margin | 不可用（Aave V4 仅支持主网） |
| 赚取收益与借款 | 通过 Aave V4 供应和借款；Circle 的 App Kit Earn 列出的 Morpho 金库 | Arc 测试网的模拟 Morpho 金库 |
| 跨链桥 | 通过 CCTP、Across 或 Relay，向 Base、Ethereum、Arbitrum、Optimism、Polygon、Avalanche 上的任何人转账；也可以跨链进出 Arc | 通过 CCTP 转到对应的测试网络（Base Sepolia、Ethereum Sepolia、……） |
| x402 市场 | Circle 的目录 | Kawase 自有的演示卖家（Circle 的目录仅支持主网） |
| 默认限额 | 较低 | 高十倍（不会有真实资金风险） |
| 新账户开始的网络 | | ✓ |

## Kawase 如何将两个网络分开

- **一键切换**，双向都可以：查看[网络切换](./features/network-toggle.mdx)。
- **网络会通过三种方式显示**：顶部的网络标签、测试网提示条或“真实资金”标签，以及 orb 的颜色。
- **由服务器控制网络选择。** 每笔付款都会针对一个网络准备，并在整个流程中保持在该网络上；如果中途切换网络，付款会停止，不会跨到另一个网络。
- **两个网络共用一个钱包地址**，但余额、活动记录和限额会分别按网络保存。
