Kawase 支持两个网络：**Arc 主网**中的资金是真实的，**Arc 测试网**中的资金不是真实的。标题栏中的**网络标签**
可以一次点击切换网络，双向都可以，就像切换深色模式一样。

- **新账户默认使用测试网**。如果缺少网络信息或无法读取，系统会默认使用测试网：这是更安全的选择。
- **首次切换到主网**时，会显示一条简短的“真实资金”确认提示；确认后，之后切换会立即完成。
- **始终清晰可见，不只依靠颜色。** 在测试网上，会显示“测试网 · 不是真实资金”提示条；在主网上，资金卡片会显示
  **真实资金**标签。网络标签会显示当前网络，语音圆球也会改变颜色（主网为青绿色，测试网为天蓝色）。
- **两个网络使用同一个钱包**：地址、联系人和设置都相同。余额和活动记录按网络分别显示。
- **由服务器决定网络。** 网络是服务器会话的一部分，不由 AI 模型选择；每笔付款都会携带准备时使用的网络，网络不匹配时会停止付款。

如果某项功能只在一个网络上提供——比如测试网的水龙头、主网的 x402 市场——Kawase 会说明情况，并提供切换选项，而不是直接失败。完整对比请参阅[网络](../networks.mdx)。
