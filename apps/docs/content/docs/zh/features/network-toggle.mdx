Kawase 运行在两个网络上：**Arc 主网**，钱是真的；**Arc 测试网**，钱不是真的。首页顶部的**网络开关**轻点一下就能在两者之间
切换，双向都可以，就像切换深色模式。

## 始终可见，从不只靠颜色

- **开关**在首页以及设置 → 网络中写明当前网络。
- **在测试网上**，打开的页面会带一条横幅：“**测试网 · 不是真实资金**”（见[转账](./send-receive-request.mdx)）。

## 它如何运作

- **新账户从测试网开始**，任何缺失或无法读取的设置都会回到测试网：这是安全的方向。
- **第一次切换到主网**时会请你确认那里的钱是真的；之后就是立即切换。访客可以浏览两个网络；主网上的资金需要账户。
- **你的钱包在两个网络上是同一个**：一个地址，相同的联系人和设置。余额和动态按网络分开。
- **草稿留在创建它的网络上**。你正在查看的内容会留在它被创建的网络上；切回去才能批准。
- **由服务器决定**。网络是你在服务器上的会话的一部分，从不由 AI 模型选择；每笔付款都带着它准备时所在的网络，不一致就会被
  拦下。

当某个功能只存在于一个网络上（测试网的水龙头、主网的做多和做空），Kawase 会说明并提供切换，而不是直接失败。完整对比见
[网络](../networks.mdx)。
