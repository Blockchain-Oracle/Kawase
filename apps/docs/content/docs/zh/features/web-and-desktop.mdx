## 在浏览器中

打开 [app.getkawase.xyz](https://app.getkawase.xyz)。你会以**游客**身份开始，所有功能都和手机上一样：
聊天、卡片、市场、语音和每个页面。

- **确认付款**：使用**邮箱验证码**代替 Face ID。
- **语音**：点击圆球，并在浏览器询问时允许使用麦克风。如果你拒绝，Kawase 会告诉你如何允许使用麦克风，
  旁边也可以直接输入文字。
- **安装**：Kawase 是可安装的网页应用。在 Chrome 或 Edge 中使用**安装**，在 Safari 中选择**添加到程序坞**（Mac）或
  **添加到主屏幕**（iPhone）。如果网络中断，页面会显示离线提示，而不是出现损坏的页面。Kawase 从不
  缓存余额，因此不会把旧数据显示成当前资金。

## 桌面应用（Mac）

[下载 Mac 版 Kawase](https://getkawase.xyz/download/Kawase-mac.dmg)（Apple silicon，约 2 MB），打开磁盘映像，
然后将 Kawase 拖到“应用程序”中。

<Callout type="warn">
**目前还没有通过 Apple 公证：第一次打开时，请右键点击 Kawase → 打开。** 在 macOS 15 及更高版本中，先打开一次，然后前往
**系统设置 → 隐私与安全性**，选择**仍要打开**。这是预览版本，不是已签名的正式版本。
</Callout>

它是在原生窗口中运行的网页应用，因此**始终是当前版本**，无需更新：

- 标题栏会使用 Kawase 的颜色，并跟随你的浅色或深色模式；
- 复制、粘贴和常用菜单都可以正常使用；⌘+ 和 ⌘− 可缩放；
- **`kawase://` 链接**（和手机上一样）会在窗口中打开对应页面，例如 `kawase://r/…` 会打开
  收款请求；
- 登录窗口会在应用内打开，其他网站（区块浏览器、本文档等）会在浏览器中打开；
- 除了应用运行所在的窗口外，页面**无法访问你的电脑**。

桌面应用中的语音功能还未测试；如需使用语音，请在浏览器中打开网页应用，或使用手机。

Windows 和 Linux 版本使用相同的源代码（`apps/desktop`）；目前还没有构建。
