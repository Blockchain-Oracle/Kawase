## 在网页上确认

手机上要求 Face ID 的地方，网页版会发送一个**邮件验证码**：输入六位数字，付款就会发出。语音也能用：浏览器询问时允许使用麦克风。
如果你拒绝，Kawase 会告诉你怎么开启，键盘就在旁边。

## 安装

Kawase 是一个可安装的网页应用。在 Chrome 或 Edge 中使用**安装**，在 Safari 中使用**添加到程序坞**（Mac）或**添加到主屏幕**
（iPhone）。如果网络断开，会显示一个离线页面说明情况，而不是一个坏掉的页面。Kawase 从不缓存余额，所以旧数据绝不会被当作当前资金
显示。
