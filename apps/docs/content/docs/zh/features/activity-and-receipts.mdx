**动态**（底部栏中的脉搏图标）是一个列表，列出所有资金变动：转账和收款、兑换的两端、跨链、储蓄、仓位、自动化运行、已付的
收款请求、水龙头领取和练习运行。它读起来就像钱包：转入是 **+20 USDC**，转出是 **−5 USDC**。

每一行都写明它的状态：完成、进行中、待你处理、已跳过及原因，或练习。**监控中**列出接下来要运行的事（一笔定时发送，带一个
倒计时圆环）；**待你处理**是等你操作的事；**发现**是 Kawase 替你注意到的事，比如闲置的资金。

## 收据

轻点任意一行。每笔交易都打开**同一张收据**：转账、收款、兑换（“你通过 KyberSwap 兑换了……”）或跨链。在电脑上，收据会改为在列表旁边打开（见[网页版和桌面版](./web-and-desktop.mdx)）。

## 这是怎么发生的

**原因**是一笔变动背后的决策记录：它来自哪个请求（你的话、一项自动化、一条规则），检查了什么，哪条规则让它立即执行或让它
等待，以及你如何回应。对于从未上链的运行，它会说明是什么阻止了它。

## 收到的钱

**收到**的钱的收据会显示**发送方**并提供**保存**，把付款中的地址保存为联系人，这样下次回款就会准确地发到这个地址。见
[联系人](./contacts-and-handles.mdx)。

## 收件箱和每周报告

首页上的铃铛就是**收件箱**：每笔收款、已付请求、完成的付款和被跳过的自动化都会出现在那里，并打开对应的收据
（[通知](./notifications.mdx)）。在动态中你还可以阅读**本周报告**，以及**导出**你的历史记录。
