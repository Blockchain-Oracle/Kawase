**x402** 是一种开放标准，可使用稳定币为网页请求付款：服务返回“需要付款 402”，客户端使用 USDC 付款并获得结果。Kawase 会用它**为你购买答案**：网页搜索和新闻、预测市场赔率、DefiLlama 收益率和价格、股票价格，以及数据补充服务。这些服务来自 Arc 上 **Circle 的 x402 目录**。

## 你的代理钱包

购买不会直接从你的主钱包扣款。Kawase 会为你设置一个独立的**代理钱包**，它只能使用你存入的资金：

- 从你的 Kawase 钱包中按预设金额**充值**。首次充值时，需要使用 Face ID 签署一份**有上限的服务市场授权**；之后在该上限内充值无需再次确认。
- 余额会分为两部分：一部分放在 **Circle Gateway** 中，用于即时小额付款，大多数卖家都支持；另一部分作为**备用余额**，用于支持普通 USDC（EIP-3009）付款的卖家。当普通 USDC 购买所需的备用余额不足时，Kawase 会自动从 Gateway 补充。
- **退回我的钱包**可随时将两部分余额全部转回。

前往“设置”→ **代理钱包**，即可查看余额、今天的支出、钱包地址，以及完整的购买和资金转移记录。

## 你设定的预算

- **每天的预算**和**单次付款上限**；
- **超过上限时先询问我**：购买会在聊天中等待你在确认卡片上同意；
- Kawase 可以购买的**类别**；
- **已屏蔽的卖家**：点按任意购买记录即可屏蔽对应卖家。

收紧限制会立即生效；放宽限制需要使用 Face ID 确认。购买被拒时，Kawase 会说明是哪条规则阻止了它。

## 每笔购买都有收据

聊天中会显示 Kawase 找到的内容（卖家的标识、返回的内容和价格）。付款后还会显示收据，例如：“已向 … 支付 0.002
USDC”。卖家的回答会标记为**未经核实**。Kawase 会将外部文本视为数据，绝不会把它当作指令。如果回答试图告诉 Kawase 要做什么，Kawase 也会明确说明这一点。

## 网络

- **主网**：Circle 的目录中有约 2,100 个 Arc 上的服务，支持通过两种支付方式付款。
- **测试网**：Circle 的目录中没有测试网服务，因此 Kawase 会运行自己的演示卖家（`seller.getkawase.xyz`），让你使用测试币完整体验整个流程。
