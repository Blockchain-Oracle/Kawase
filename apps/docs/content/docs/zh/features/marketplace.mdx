**x402** 是一种开放标准，可使用稳定币支付网页请求：服务返回“402 Payment Required”
和价格，客户端使用 USDC 付款并获取结果。Kawase 计划让代理代表你从 Circle 的 x402 目录中**查找并支付服务**
，并严格控制在预算范围内：

- 一个独立的市场钱包，余额就是最高限额；
- 每次调用、每个会话和每天的限额，由你设定；
- 每笔购买都会显示价格、服务和结果。

Circle 的目录只列出主网服务，因此市场计划在**主网**上推出，不支持测试网。目前仍在**开发中**，应用内还无法使用。
