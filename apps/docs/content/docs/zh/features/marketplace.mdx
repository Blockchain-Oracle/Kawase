**x402** 是一种开放标准，支持使用稳定币为网页请求付费：服务返回“需要支付 402”，
客户端使用 USDC 付款后获取结果。Kawase 使用它来**为你购买答案**：网页搜索和新闻、
预测市场赔率、DefiLlama 收益率和价格、股票价格、数据补充，均来自 Arc 上 **Circle 的 x402 目录**。

## 你的代理钱包

购买不会直接从你的主钱包扣款。Kawase 会为你提供一个独立的**代理钱包**，只能
使用你存入其中的资金：

- 从你的 Kawase 钱包中按预设金额**充值**。首次充值时，需要使用 Face ID 签署一份**有上限的服务市场授权**；
  在这个上限内，之后充值无需再次确认。你也可以通过 Circle 的 Onramp，使用 **Apple Pay 或银行卡**直接充值到代理钱包。
- 余额会分成两部分：一部分放在 **Circle Gateway** 中，用于纳米支付（大多数卖家都接受）；另一部分**放在钱包中**，
  用于接受普通 USDC（EIP-3009）的卖家。当普通 USDC 购买需要更多余额时，Kawase 会自动从 Gateway 中补充。
- **退回我的钱包**可随时将两部分余额都转回去。

设置 → **代理钱包**会显示余额、今天的支出、地址，以及完整的购买和资金转移记录。

## 你设置的预算

- **每日预算**和**单次上限**；
- 超过上限时**先询问我**：购买会在聊天中的确认卡片上等待你的同意；
- Kawase 可以购买的**类别**；
- **已屏蔽的卖家**：点击任意一笔购买即可屏蔽其卖家。

收紧限制会立即生效；放宽限制需要使用 Face ID 确认。拒绝购买时，会说明是哪条规则阻止了它。

## 每笔购买都有收据

聊天会显示 Kawase 找到的内容（卖家的标识、返回的内容和价格）。付款后，还会显示收据：“已向 … 支付 0.002
USDC”。卖家的答案会标记为**未核验**。x402 目前还没有退款标准：如果付款后调用失败，收据会说明卖家已保留这笔款项；Circle 报告付款失败时，则会标记为**未扣款**。Kawase 会把外部文本当作数据，而不是指令；如果答案试图告诉它该做什么，Kawase 也会明确说明这一点。

## 网络

- **主网**：Circle 的目录（Arc 上约有 2,100 个服务），支持通过两种通道付款。
- **测试网**：Circle 的目录中没有测试网服务，因此 Kawase 会运行自己的演示卖家（`seller.getkawase.xyz`），
  让你使用测试币完整体验整个流程。
