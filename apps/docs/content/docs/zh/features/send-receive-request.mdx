## 转账

说出或输入收款人和金额——“给 Alex 转 20 美元”“给 @mira 付 5 欧元”——也可以使用转账页面。Kawase 会：

1. **查找收款人**：已保存的联系人、Kawase `@handle`，或你自己输入的 `0x…` 地址。代理只能使用来自你联系人的地址，或在你自己的消息中逐字出现的地址。
2. **选择你持有的货币**；如果无法判断，就询问你。
3. **一次检查所有信息**：你的余额、限额、是否是首次向该地址付款、地址是否与某位联系人相似（仿冒地址），以及联系人的地址最近是否发生过变化。
4. **显示付款卡片**，其中包含准确的金额、货币、收款人和网络。

接下来会发生以下两种情况之一：

| 情况 | 你需要做什么 |
|---|---|
| USDC，在当天剩余限额内，且收款人是你之前付过款的人，或你在本次请求中指定的人 | 什么都不用做。转账会立即完成，Kawase 会告知你。 |
| 超出限额、任何 EURC 付款、首次向新地址付款且金额超过阈值，或遇到仿冒地址 | 使用 Face ID 确认（Android 上使用指纹或屏幕锁，网页端使用电子邮件验证码）。 |

只有当网络回执显示准确的转账记录时，付款才会标记为**已支付**。如果结果不明确，卡片会显示“仍在检查”，Kawase 会继续查询；它绝不会重复转账。

## 收款

你的钱包在两个网络上使用**同一个地址**。打开收款页面即可查看地址和二维码。Kawase 的监测程序会发现到账的付款，它们会显示在活动记录和收件箱中，还可以唤醒你的[自动化](./automations.mdx)。

## 收款请求

说“向 Sam 收 15 美元作为晚餐费”，或打开收款请求页面。Kawase 会创建一笔使用 USDC 或 EURC 的**收款请求**，并生成可分享的链接。付款人可以在网页应用中打开链接；当收到 Kawase 付款或匹配的普通转账时，请求会标记为已支付。
