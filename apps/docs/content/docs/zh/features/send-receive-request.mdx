## 转账

说出或输入收款人和金额（“给 Alex 转 20 美元”“给 @mira 支付 5 欧元”），也可以使用转账页面。你可以发送**在 Arc 上持有的任意代币**。Kawase 会：

1. **查找收款人**：已保存的联系人、Kawase `@handle`、你自己输入的 `0x…` 地址，或你扫描的**二维码**。代理只能使用来自联系人、你扫描的二维码，或你自己逐字输入的地址。
2. **选择你持有的代币**；如果不明确，会询问你。
3. **每次付款都检查收款人**：代币合约地址或冒充已保存联系人的地址会被拒绝；如果地址是合约而不是钱包，会发出提醒；如果代币发行方有屏蔽名单，也会进行检查；如果是你自己的地址，会明确标注。系统还会检查你的余额、限额，以及联系人的地址最近是否发生变化。
4. **显示付款卡片**，其中会列出准确的金额、代币、收款人和网络。

接下来会发生以下两种情况之一：

| 情况 | 你需要做什么 |
|---|---|
| 对该代币来说，金额在今天剩余的限额内，且收款人是你以前付过的人，或你在这次请求中明确说出了对方 | 什么都不用做。款项会立即发出，Kawase 会告诉你。 |
| 超过限额、使用限额外的代币、发送到新地址，或地址看起来像冒牌地址 | 使用 Face ID 确认（Android 上可使用指纹或屏幕锁，网页端使用邮件验证码）。 |

向刚添加的地址付款时，系统可能会建议先发送一笔**测试金额**。只有当网络回执显示准确的转账记录时，付款才会标记为**已支付**。如果结果不明确，卡片会显示“仍在检查”，Kawase 会继续查询；它绝不会重复发送。

**对方的钱包在另一条链上？**确认页面会提供相应选项：USDC 会打开[跨链卡片](./bridge-and-withdraw.mdx)，金额和收款人保持不变；其他代币则会先提供兑换为 USDC 的选项。

## 扫码付款

在快捷操作菜单、转账页面或聊天页顶部点击**扫描**。扫描器可以读取：

- 裸地址，或带金额和代币的付款链接（EIP-681）：转账页面会自动填好信息，并执行通常的检查；
- Kawase 收款请求或账单链接：打开对应的付款页面。

如果二维码对应 Arc 的另一个网络、其他链，或收款请求已关闭，系统会说明原因；在有帮助时，还会提供切换网络的选项。你也可以直接粘贴二维码内容。

## 收款和充值

你的钱包在**两个网络上使用同一个地址**，可以接收**Arc 上的任意代币**。**充值**会汇总所有可用方式：

- **用银行卡购买**（[购买](./buy.mdx)）；
- **从交易所转入**：显示交易所的标志和交易所自己的操作步骤（Coinbase 通过 Base，再转入 Arc）；
- **从其他链转入**：在其他链上转到你地址的 USDC，可免 gas 转入 Arc；
- **收款**：显示你的地址和二维码；
- **在测试网上领取测试 USDC**。

收到的资金会显示在活动记录和收件箱中，也可以触发你的[自动化](./automations.mdx)，并提供**将发送方保存为联系人**的选项。

## 收款请求和分摊

说“向 Sam 收 15 美元作为晚餐费”，或打开收款请求页面。Kawase 会创建一个使用 Arc 上任意代币的**收款请求**，并生成可分享的链接。付款人可以在任何浏览器中打开链接；当收到 Kawase 付款或匹配的普通转账时，请求会标记为已支付。

**分摊账单**：“和 Amina、Tunde 平分 30 美元的晚餐费”。你可以平均分摊，也可以手动分配金额，还可以选择是否包含自己。每个人都会收到自己的收款请求和链接，进度卡片会显示谁已经付款。

## 收据和链接

- **分享已完成付款的收据**，可以分享为图片卡片（网页端也可以分享带区块浏览器链接的文本）。
- 每项操作都有自己的链接（`/i/…`）。通知会打开对应的卡片；退出登录后打开链接，登录后会回到该卡片。如果卡片因某些问题被阻止，而你随后解决了问题（登录、完成设置、调整限额或充值），系统会自动再次检查。
