Kawase 在整个应用中支持全球使用最广泛的十种语言：

| 语言 | 该语言中的名称 | 文字方向 |
|---|---|---|
| 英语 | English | 从左到右 |
| 中文 | 中文 | 从左到右 |
| 印地语 | हिन्दी | 从左到右 |
| 西班牙语 | Español | 从左到右 |
| 法语 | Français | 从左到右 |
| 阿拉伯语 | العربية | **从右到左** |
| 孟加拉语 | বাংলা | 从左到右 |
| 葡萄牙语 | Português | 从左到右 |
| 俄语 | Русский | 从左到右 |
| 乌尔都语 | اردو | **从右到左** |

- **首屏即可切换。** 语言选项位于首个引导面板上，之后的每个页面也都有；切换会立即生效，包括文字方向。
- **每种语言都完整支持。** 应用的十种语言内容均已完整翻译；智能助手会使用你的语言回复，[语音](./voice.mdx)也支持听懂并说出这十种语言。
- **金额保持准确。** 数字会按照你的语言格式显示，但金额、地址和代码会保持从左到右，方便你逐个字符核对。
- **这些文档**也提供这十种语言版本（使用侧边栏中的语言切换功能）。
