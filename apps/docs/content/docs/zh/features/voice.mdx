点按底部栏中的圆球，然后说话。页面会变模糊，圆球升起并开始聆听；它会显示听到的内容，用语音回答，
并像聊天一样在屏幕上显示相同的**卡片**。

- **同一个对话。** 你用语音说的话会出现在聊天记录中，输入文字也能从你上次停下的地方继续。
- **始终先显示听到的内容**，然后才会进行任何确认。
- **说“是”不能批准付款。** 语音转账会先准备好，并显示在卡片上，等你点按并通过 Face ID
  （Android 上则使用指纹或屏幕锁）——即使没有超出你的每日限额，也必须这样操作。
- **圆球会显示网络状态**：主网上显示青柠色，测试网上显示天蓝色。

## 语言和语音

Kawase 使用 ElevenLabs Scribe v2（实时）听懂全部十种语言。它使用 ElevenLabs Flash v2.5 用英语、
西班牙语、法语、葡萄牙语、俄语、中文、印地语和阿拉伯语回答；孟加拉语和乌尔都语则使用 OpenAI 的语音模型，因为
Flash v2.5 不支持这两种语言。

## 工作原理

手机通过 WebRTC 加入 LiveKit 房间。Kawase 的语音工作程序会将语音转换为文字，运行**与聊天相同的代理处理流程
**（使用相同的工具、相同的限制和相同的对话线程），并在卡片显示到屏幕上的同时读出回答。
