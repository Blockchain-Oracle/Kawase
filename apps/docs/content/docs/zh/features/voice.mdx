点按底部栏中的圆球，然后开始说话。页面会变模糊，圆球升起并开始聆听；它会显示听到的内容，用语音回答，
并像聊天一样在屏幕上显示相同的**卡片**。

- **一次对话。** 你说过的话会保留在聊天线程中，输入文字也能接着聊。
- **双方都有字幕**：Kawase 听到的内容，以及它正在说的话。
- **说“是”不会批准付款。** 语音转账会先准备在卡片上，等你点按并通过 Face ID
  （Android 上则是指纹或屏幕锁）确认——即使还在你的每日额度内，也一样。
- **一键静音**：静音时不会听到或发送任何内容。你也始终可以**改用输入**。
- **圆球会显示网络**：主网为青柠色，测试网为天蓝色。

## 网页端

网页应用也支持语音：浏览器询问时，请允许使用麦克风。如果你拒绝授权，或设备没有麦克风，
Kawase 仍会保持连接，告诉你如何允许使用麦克风，输入框就在旁边。Kawase 的语音仍会播放。

## 设置 → 语音

- **Kawase 的声音**：六种声音可选。
- **说话速度**：舒缓、正常或快速。
- **Kawase 先说话**：打开语音后，它会立即向你问候；关闭后，它会等你先开口。

下次开始说话时，设置才会生效。

## 工作原理

手机或浏览器会通过 WebRTC 加入 LiveKit 房间，Kawase 的语音工作进程也会加入同一个房间。每个资金或
账户请求都会交给**与聊天相同的代理处理流程**（相同的工具、限制和线程）；回答以语音播放的同时，卡片也会显示
在你的屏幕上。在说出金额、资产、@handles 或网络前，工作进程会将它们与工具返回的结果进行核对，并在不一致时
更正。如果实时语音无法启动，Kawase 会改用“聆听 → 回答 → 说话”的流程，背后仍由同一个代理处理。LiveKit 不会录制对话。
