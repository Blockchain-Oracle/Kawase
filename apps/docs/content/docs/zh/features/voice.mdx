## 和 Kawase 对话

轻点底栏中间的光球（电脑上是侧边栏里的**和 Kawase 说话**），然后开口。Kawase 会向你打招呼、倾听、出声回答，并在屏幕上显示和
聊天一样的**卡片**。

- **同一个对话**。你用语音说的话会出现在聊天对话里，开始打字就能接着上次继续。
- **双方都有字幕**：Kawase 听到了什么，以及它正在说什么。
- **口头说“好”永远不会批准付款**。语音发起的转账会在卡片上准备好，等你轻点并通过 Face ID（Android 上是指纹或锁屏，网页上是
  邮件验证码）。
- **改为打字**始终只需轻点一下，**静音**会让任何内容都不被听到或发送。

## 一边用应用一边继续对话

顶部的向下箭头（或点击外部、Esc 或返回）会把对话收成页面顶部的一个**黑色小岛**，无论你打开哪个页面：实时的光球、Kawase
正在做什么和它最新说的话、静音和结束。需要你处理的卡片会在当前页面上滑出，屏幕边缘的一圈光晕表示语音正在进行。轻点小岛即可
重新打开完整视图；只有**结束**才会结束对话。

## 在网页上

网页版也能用语音：浏览器询问时允许使用麦克风。如果你拒绝了，或者没有麦克风，Kawase 会保持连接，告诉你怎么开启，键盘就在旁边。
Kawase 自己的声音照常播放。

轻点某个声音旁的扬声器：Kawase 会直接在这里用这个声音向你问好，不需要麦克风。改动会在你下次开始对话时生效。

## 工作原理

手机或浏览器通过 WebRTC 加入一个 LiveKit 房间，Kawase 的语音代理也加入同一个房间。每个与资金或账户有关的请求都会交给**和聊天
相同的代理轮次**（同样的工具、同样的限额、同一个对话）；回答被说出来的同时，卡片会出现在你的屏幕上。在说出金额、资产、@handle
或网络之前，语音代理会把它们和工具返回的结果核对，并纠正不一致之处。如果实时语音无法启动，Kawase 会退回到“听 → 答 → 说”的流程，
背后仍是同一个代理。LiveKit 不会录下对话。
