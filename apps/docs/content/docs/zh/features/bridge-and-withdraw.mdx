向 Kawase 发出请求（“在 Base 上给 Alex 转 20 美元”、“把我在 Base 上的 USDC 转到 Arc”），它会在你面前显示一张**转账卡片**，并打开全屏的**跨链转账**页面。它可以在 Arc 与 **Base、Ethereum、Arbitrum、
Optimism、Polygon 或 Avalanche** 之间转移 USDC。

## 从 Arc 转出，转给任何人

收款人可以是**你自己**、**联系人**、**@handle** 或任何 **0x 地址**。Kawase 会向三个服务商获取实时
报价：

- **Circle CCTP**：Circle 在 Arc 上销毁 USDC，并在另一个网络上铸造 USDC；
- **Across** 和 **Relay**：求解器在另一端支付，然后从你的存款中获得偿还。

它们会按**扣除费用后的到账金额**排序。如果到账金额相同，则优先选择速度更快的服务商。最多会显示三条路线，包括
服务商标识、到账金额、费用和预计时间。系统会为你选择最佳路线，你也可以点击其他路线。

在请求你的钱包确认之前，Kawase 会生成所选服务商的交易并**检查交易**：对于 Across，它会解码存款信息（付款人、
收款人、代币、金额、最低金额、目标网络，以及没有额外消息）；对于 Relay，它会检查授权，以及存入 Relay 列出的
存款合约；对于 CCTP，则会检查 Circle 自己的调用。交易会从你的钱包发起模拟，然后你滑动并使用 Face ID 确认，
以**一笔交易**发送。

## 转入 Arc

如果你在另一个网络上、同一个地址中持有 USDC，Kawase 会找到这些余额（显示各网络的余额，并选择金额最大的余额），
并通过 **Relay 的 permit** 将其转入 Arc：只需签名一次，**无需在该网络支付 gas**。在你签名之前，系统会检查
permit（你的地址、金额、Relay 合约，以及该网络上的 USDC）。

## 跟踪转账

每笔转账都会被跟踪：**已签名 → 已发送 → 转账中 → 已到账**，并提供区块浏览器链接。Kawase 会通过收据检查
钱包实际转出的金额，然后通过服务商自己的状态信息确认到账情况（Across 存款状态、Relay 请求状态或 Circle 的
attestation）。如果服务商改为**退款**，卡片会清楚地显示这一点。资金绝不会被发送两次。

## 在测试网上

Arc 测试网仅使用 **CCTP**；Across 和 Relay 服务于 Arc 主网。转入 Arc 仅支持主网。

## 随时提现（即将推出）

目前，你可以将 USDC 或 EURC 转账到 **Arc 上的任何地址**，包括交易所的 Arc 充值地址；也可以将 USDC 转账给上述
六个网络上的任何人。我们正在开发一个适用于所有资产和目标地址的统一 **提现**页面。

如果你想完全不使用 Kawase 提现，请查看[不使用 Kawase 提现](../withdraw-without-kawase.mdx)。
