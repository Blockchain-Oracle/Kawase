## 跨链，一步一步

从 **+** 打开**跨链**（或兑换页的跨链标签），或直接说：“在 Base 上给 Alex 转 20 美元”“把 1 美元转到 Base”。

<Walkthrough>
  <WalkStep title="选择一条链" src="bridge/chains">
    Base、Ethereum、Arbitrum、Optimism、Polygon 或 Avalanche，各有自己的标志。

    <Pin box="4 72.5 92 24">钱要到达的地方</Pin>
  </WalkStep>
  <WalkStep title="转给谁、转多少" src="bridge/ticket">
    收款人可以是**你自己**（另一条链上的同一地址）、**联系人**、**@用户名**或任意 **0x 地址**。选择 USDC 或 EURC 以及金额。

    <Pin box="4 16.5 41 8">从 Arc 转出</Pin>

    <Pin box="55 16.5 41 8">到你选的链</Pin>

    <Pin box="5 29 90 6.5">你自己、联系人、@用户名或地址</Pin>

    <Pin box="4 45.5 40 5">转移什么</Pin>
  </WalkStep>
  <WalkStep title="路线" src="bridge/review">
    向 **Circle CCTP、Across、Relay、LI.FI、deBridge、Socket 和 Gas.zip** 请求实时报价。按**扣除费用后的到账金额**排序，持平
    时更快的优先；最优的会被选中，你也可以点选其他的。在请求你的钱包之前，Kawase 会构建所选路线并**检查**（谁付款、谁收款、代币、
    金额、最低值、目的地），然后从你的钱包模拟执行。

    <Pin at="60 15.3">到账多少，到哪条链</Pin>

    <Pin box="5 28 90 13">胜出的跨链桥、你收到的金额及费用</Pin>

    <Pin box="5 66.5 90 7.5">滑动转出</Pin>
  </WalkStep>
  <WalkStep title="已送达" src="bridge/tracking">
    每次转移都会被跟进：**已签名 → 已发送 → 到账中 → 已送达**，并附两条链上的浏览器链接。Kawase 会核对离开你钱包的金额，再通过
    跨链桥自己的状态确认到账（Circle 的证明、Across 的存款状态、Relay 的请求状态）。如果跨链桥改为**退款**，卡片会明确说明。
    绝不会重复发送。

    <Pin box="8 21.5 84 9">到账多少，经由哪座桥</Pin>

    <Pin box="8 30.5 84 12">在两条链上查看</Pin>
  </WalkStep>
</Walkthrough>

**对方的钱包在另一条链上？** [转账](./send-receive-request.mdx)的核对页会用同样的金额和收款人提供跨链选项。

## 把 USDC 带到 Arc

如果你在另一个网络的同一地址上有 USDC，**充值 → 从其他链转入**会找到它（余额最大的优先），用 **Relay 的许可签名**把它带到
Arc：只需一次签名，**无需该网络的 gas**。签名前会检查许可内容（你的地址、金额、Relay 的合约和该网络的 USDC）。仅限主网。这笔转移在你签名前也会先**在链上模拟**。

## 提现

**取出**把一个、多个或全部代币从 Kawase 转出，只需确认一次。

<Walkthrough>
  <WalkStep title="取什么、取到哪里" src="bridge/withdraw">
    选择代币或点**全部**；每种代币可**原样**转出，或**换成现金**（先兑换成 USDC）。然后选择去处：**交易所**（Kraken、Bybit、
    OKX、Binance、Bitget、KuCoin，或经由 Base 的 Coinbase）、你在 Arc 或其他链上的**其他钱包**，或经由交易所到**你的银行**。
    Kawase 知道每家交易所接受哪些资产和网络，会在你发出它不会入账的资产之前提醒你。

    <Pin at="67 34.8">全部，或选择代币</Pin>

    <Pin box="4 50.5 92 22.5">交易所，各有自己的步骤</Pin>

    <Pin box="4 79.5 92 7.5">你在任意链上的其他钱包</Pin>

    <Pin box="4 87.5 92 7">经由交易所到你的银行</Pin>
  </WalkStep>
  <WalkStep title="一次确认，覆盖每一项" src="limits/exit-kit">
    Kawase 为每种代币规划一项（Arc 上的转账、跨链，或先兑换）。**一次 Face ID 覆盖所有项**，每一步发出前都会再次检查。每一项
    都有跟踪；如果中途停下，**完成它**会从停下的地方继续。下方是**退出工具包**：暂停 Kawase、收回所有权限，然后把钱转出。

    <Pin box="4 57.5 92 14">退出工具包</Pin>

    <Pin box="4 75.5 92 6">暂停 Kawase 自动做的一切</Pin>

    <Pin box="4 87.5 92 6.5">把我的钱转出：全部取出</Pin>
  </WalkStep>
</Walkthrough>

提现去处会保存在**联系人 → 我的常用去处**。交易所涉及真实资金，因此在 Arc 主网上开放；在测试网上，提现会转到你自己的钱包。
如果完全不通过 Kawase 取出你的钱，请看[不通过 Kawase 提现](../withdraw-without-kawase.mdx)。

## 在测试网上

Arc Testnet 通过 **Circle CCTP** 跨链（其他桥回复不在该网络上），可到同样六条链的测试网。把 USDC 带到 Arc 和交易所仅限主网。
