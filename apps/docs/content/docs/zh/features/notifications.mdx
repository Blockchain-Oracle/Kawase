Kawase 的**收件箱**会记录所有动态：每笔收到的款项、已支付的收款请求、已完成的转账、跳过的自动化和规则提醒都会出现在这里。点按通知即可打开对应页面。

除了收件箱，Kawase 还可以通过**推送**（在手机上）和**邮件**通知你。在“设置 → 通知”中，你可以按事件和渠道选择要接收的通知。默认设置如下：

| 事件 | 推送 | 邮件 |
|---|---|---|
| 收到款项 | 开 | 开 |
| 收款请求已支付 | 开 | 开 |
| 转账已完成 | 开 | 关 |
| 自动化已跳过 | 开 | 开 |
| 规则提醒 | 开 | 开 |

你所在时区的**免打扰时段**会将推送通知延迟到早上，邮件仍会正常发送。安全事件永远无法静音。

每条通知在每个渠道最多发送一次，即使 Kawase 重试也是如此。推送和邮件发送功能已集成到应用和服务器中。正式发布时，连接推送（Apple 和 Google）及邮件服务商账号后，这些功能就会启用。收件箱现在已经可以使用。
