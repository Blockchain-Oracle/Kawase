Kawase 只在钱有变动、或它替你做了什么时通知你。别的一概不打扰。

<Flow>
  <FlowStep icon="bell" title="发生了某件事">收到款项、收款请求已付款、一次运行被跳过。</FlowStep>
  <FlowStep icon="inbox" title="收件箱" tone="accent">始终如此：每个事件，只一次。</FlowStep>

## 收件箱

首页上的铃铛打开**收件箱**：每一笔收到的付款、已付款的收款请求、完成的转账、被跳过的自动化和规则提醒，按时间从新到旧，每条都能
打开它的收据。**全部标为已读**会清除小红点。

## 设置 → 通知

<Shot src="notifications/settings" alt="通知：在网页上通过邮件和收件箱通知；一个邮件区块；以及通知哪些事，每个事件一个开关，从收到款项到代币毕业。">
  <Pin box="4 15.5 92 7.5">在网页上：邮件和收件箱</Pin>

  <Pin box="4 46 92 54">通知哪些事，按事件设置</Pin>
</Shot>

按事件、按渠道，你来选择收到什么：**收到款项**、**有人请你付款**、**收款请求已付款**、**转账已完成**、**自动化被跳过**、
**规则提醒**、**新的登录**、**设备退出登录**、未平仓位的**健康度提醒**、**止盈与止损**，以及**代币毕业**。

- **在手机上**：推送和邮件。
- **在网页上**：收件箱和邮件（网页版没有推送）。
- **免打扰时段**按你自己的时区计算，期间推送会等到时段结束；收件箱和邮件照常收到全部内容。

邮件通知即将上线：设置页面会这样说明，你的选择会一直保留到上线。Kawase 的邮件附有和应用里一样的[收据](./activity-and-receipts.mdx)。
每条通知在每个渠道最多送达一次，即使 Kawase 重试也一样。
