Kawase 计划通过 **Circle 的 Onramp Kit** 提供购买功能：使用借记卡、Apple Pay 或 Google Pay 付款，直接在 Arc 上的 Kawase 钱包中收到 USDC 或 EURC。Kawase 的服务器会创建购买会话，并在安全的浏览器窗口中打开；只有在链上确认收到资金后，Kawase 才会将购买标记为完成。

如需使用 Apple Pay 购买其他代币，计划是先购买 USDC，再通过一次授权完成兑换。所有费用都会在付款前显示。

此功能**即将推出**，目前还无法在应用中使用。在此之前，你可以在测试网上使用免费的[测试币水龙头](../getting-started.mdx#4-get-test-money)；在主网上，你可以从任何支持向 Arc 转账的钱包或交易所接收 USDC。
