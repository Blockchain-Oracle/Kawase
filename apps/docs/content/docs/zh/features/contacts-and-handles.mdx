## 联系人

联系人是一个姓名（以及昵称），关联一个或多个地址。Kawase 会使用联系人来理解“转账给 Alex”，并保护你：

- **地址变更会被暂缓。** 当联系人的地址发生变化时，新地址会等待 **24 小时**，之后才能向其转账。在此期间，该联系人会被冻结。地址变更是盗取转账资金的常见手段。
- **疑似相似的地址会被标记。** 如果某个地址的前四位和后四位与某位联系人的地址相同，就会被视为疑似相似地址：Kawase 会暂停操作，并要求验证 Face ID。
- **转账记录** 会按地址和网络分别建立信任度：向某个地址首次转账时，检查会比再次转账更严格。

如果你提到的人还不在 Kawase 中，Kawase 会请你保存对方，然后继续完成同一笔转账——你不必重新开始。

### 添加联系人

- **保存转账人**：收到某人的转账后，会显示 **将转账人保存为联系人**，并使用这笔转账中的地址。
- **从手机导入**：联系人 → 导入仅会读取**你手机上的**姓名和电子邮件。**查找 Kawase 用户**只会发送经过哈希处理的电子邮件，绝不会发送姓名、电子邮件或电话号码本身；允许被查找的人会通过其 @handle 一键添加，你也可以邀请其他人。其他人能否通过这种方式找到你，可以在同一页面中设置。

## @handle

`@handle` 是一个可选的公开名称，别人可以通过它向你转账，例如：“向 @abu 转账 10”。规则如下：

- 由 3 到 20 个字符组成：小写字母、数字和下划线。
- 不区分大小写且不能重复；可能冒充 Kawase、Arc、Circle 或工作人员的名称会被保留。
- 你可以在注册时选择（也可以跳过），之后可在设置中更改。

@handle 会解析为对方的 Kawase 钱包地址。如果对方还没有设置钱包，Kawase 会直接告诉你，而不会擅自猜测。
