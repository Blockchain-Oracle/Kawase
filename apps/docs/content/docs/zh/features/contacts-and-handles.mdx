## 联系人

联系人是一个姓名（以及昵称）和一个或多个地址。Kawase 通过联系人理解“转账给 Alex”，并保护你：

- **地址变更会暂缓处理。** 当联系人的地址发生变化时，新地址会等待 **24 小时**，之后才能向其转账。在此期间，该联系人会被冻结。地址变更是盗取转账资金的常见手段。
- **相似地址会被标记。** 如果某个地址的前四个和后四个字符与某位联系人的地址相同，它会被视为相似地址：Kawase 会暂停操作，并要求你使用 Face ID。
- **付款记录** 会按地址和网络分别建立信任度：向某个地址首次付款时，Kawase 会比重复付款更加谨慎。

如果你提到的人不在 Kawase 的联系人中，Kawase 会请你保存对方，然后继续完成这笔转账——你不必重新开始。

## @用户名

`@handle` 是一种可选的公开名称，别人可以通过它向你付款，例如：“向 @abu 转账 10”。规则如下：

- 3 到 20 个字符：只能使用小写字母、数字和下划线。
- 不区分大小写，必须唯一；可能冒充 Kawase、Arc、Circle 或工作人员的名称会被保留，不能使用。
- 你可以在初始设置时选择用户名，也可以跳过，之后还能在设置中更改。

用户名会解析为对方的 Kawase 钱包地址。如果对方还没有设置钱包，Kawase 会告诉你，而不是猜测地址。
