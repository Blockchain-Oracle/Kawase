## 你的 @用户名

`@用户名` 是一个可选的公开名字，别人可以用它付款给你：“给 @maya 转 10”。你在登录后立即选择（也可以跳过），之后可在
**设置 → 用户名**中修改。

<Shot src="start/handle" alt="选择用户名：已输入 @ines，标为可用，下方是继续和暂时跳过。" zoom="17 47 12" lens="68 58">
  <Pin box="5 37 90 7.5">输入时即时检查</Pin>

  <Pin box="5 84 90 7">保留它，或暂时跳过</Pin>
</Shot>

- 3 到 20 个字符：小写字母、数字和下划线。
- 不区分大小写且唯一；会冒充 Kawase、Arc、Circle 或工作人员的名字已被保留。
- 用户名指向对方的 Kawase 钱包。如果对方还没有设置钱包，Kawase 会直接告诉你，而不是去猜。

## 保存联系人

联系人是一个名字（和昵称）加上一个或多个地址。Kawase 靠联系人理解“转给 Sam”，也靠它们保护你。

### 从手机导入

**联系人 → 导入**只在**你的手机上**读取名字和邮箱。**查找谁在用 Kawase** 只发送哈希后的邮箱，从不发送名字、邮箱或号码本身；
允许被找到的人可以一键按 @用户名添加，其他人可以邀请。别人能否以这种方式找到你，是同一页上的一个开关。

## 联系人如何保护你

- **地址变更会被暂缓。** 联系人的地址变更后，新地址要等 **24 小时**才能收款，期间该联系人被冻结。更改地址是盗取付款的经典手法。
- **仿冒地址会被标出。** 前四位和后四位与某个联系人地址相同的地址会被视为仿冒：Kawase 会停下来请你确认。
- **历史记录建立信任**，按地址、按网络分别计算：第一次付款给某个地址比重复付款更谨慎，可以先发一笔[测试金额](./send-receive-request.mdx)。
