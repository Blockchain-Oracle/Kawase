## 运行规则

- **只运行一次。** 如果 Kawase 的服务器在运行中途重启，这次运行会以同一个 id 恢复，绝不会付两次款。
- **提醒。** 每周和每月的运行会提前一天提醒，钱包余额不足时会额外提示。
- **跳过并说明原因。** 无法进行的运行会被跳过，并在收件箱说明原因；因余额不足而跳过的，会在有钱到账时重试一次。

## 规则和储蓄

- **保留并储蓄**（自动储蓄）：在钱包里留一笔随时可用；其余在你自己的[金库储蓄](./earn-and-borrow.mdx)中赚取收益，钱不够时会转回来。
- **把付款凑整**：把每笔付款的零头存起来。
- **超出部分储蓄**和**低余额提醒**：在余额越过某条线时执行或提醒你，每越过一次只触发一次。
- 在聊天中还能做更多：“当我的余额超过 500 时，把超过 400 的部分跨链到我的 Base 地址”，或在有钱到账、代币价格越过某个水平时执行。

## 先练习

新建的自动化可以从**练习**开始：每次运行都是在 Arc 上对确切转账的模拟，记录为“**本会发生**”。资金不会变动。满意后再**开启**。
随时可以问“如果现在运行会发生什么？”

## 等你处理

自动化从不自行兑换，也从不超出它的授权或你的规则付款。当一次运行走到这样的步骤时，它会在**等你处理**中等待（收件箱和自动化页，开启
通知时还会推送）。批准后会打开你手动操作时完全相同的转账或兑换，并重新检查。未回复的事项 12 小时后提醒，24 小时后过期。

## 管理它们

在自动化页或聊天中：列出、**暂停**、**恢复**、**跳过下一次**、**编辑**和**取消**。减少额度立即生效；增加额度会签署新的授权，同时撤销
旧的。**取消**还会在链上撤销授权，所以权限是真正消失了，而不只是被隐藏。
