智能代理无需询问即可执行的所有操作，都写在 **设置 → 钱包与限额** 中。其中大部分由 Arc 直接执行限制。本页面介绍你可以在那里更改的设置。背后的模型请参阅[安全页面](../safety.mdx)。

## 每种代币的额度

**权限凭证**会显示每种代币的以下信息：Arc 执行的限额（你签署的授权）、Kawase 自己设置的更低上限、今天剩余的额度，以及任何临时提高的额度。

- **添加代币**：添加你持有的任意代币，或粘贴地址。系统会在链上检查。
- **调低**数值后会立即保存。
- **调高**数值时，你会看到 **现在 → 之后**：一次批准即可同时签署新的链上授权和撤销旧授权，因此不会同时存在两笔有效授权。

## Kawase 自己会检查什么

除了链上的限额，Kawase 还会执行自己的规则：

- **单笔转账**上限；
- **新收款人**：添加某人后的最初几小时内，智能代理每次只能向对方转出少量资金；
- **仅限允许列表**：智能代理只会向列表中的联系人付款；
- **临时提高额度**：暂时提高一段时间，之后会自动恢复。

## 暂停全部

一个开关即可关闭智能代理**无需询问**执行的所有操作。你用 Face ID 批准的付款仍可正常进行，因此暂停期间，你依然可以把资金转出。暂停后，每个页面上方都会显示一条提示。

## 风险拨盘

**防护 · 平衡 · 自主**：

- **防护**：每笔付款都要等你确认，聊天中的操作也一样。
- **平衡**：在你的额度内，输入的转账请求会立即执行。
- **自主**：Kawase 可以在你的限额内，根据自己的建议执行操作，然后通知你。

## 练习模式

开启练习模式后，Kawase 会在 Arc 上使用你的地址，按照你的要求运行**完全相同的交易**进行模拟，并显示链上的结果：**“本会转出”**。**不会有任何资金移动。**练习模式也适用于自动化。兑换、跨链、储蓄操作和保证金订单会在签署前被拒绝，因此 PRACTICE 提示条不会掩盖真实付款。

## 退出工具包

如果你觉得哪里不对：先**暂停**，然后通过**按住以撤销**，用**一次 Face ID**（一笔交易）撤销网络上的所有权限，最后**转出资金**。授权已被撤销的自动化会结束。

## 需要你处理

有些步骤自动化永远不能单独执行：**每次兑换**、**超过授权额度的付款**，或被你的**允许列表**或**冷却时间**拦下的操作。它们会出现在收件箱和自动化中的**需要你处理**里；如果你设置了通知，也会收到推送通知。你可以在任何地方回复一次：第二次回复时，系统会发现它已经处理过，并告诉你处理的时间和位置。批准后，系统会打开你手动执行时会使用的转账或兑换流程，并再次检查。未回复的项目会在 **12 小时**后提醒，并在 **24 小时**后过期。

## 活动记录与原因

**活动记录**会集中显示所有代币的转入和转出：转账、收款、包含两条资金流向的兑换、跨链、储蓄、保证金、自动化运行、已支付的收款请求、水龙头和练习运行。每一行都会显示当前状态（检查中、已跳过及原因、练习中、等待中）。筛选项包括：**全部 · 转入 · 转出 · 交易 · 自动化 · 需要你处理**，最后一项还会显示数量。

点击某一行可查看凭证（金额、时间、网络、对方、交易），然后点击**原因**：查看这次决策的记录；如果某次运行从未上链，还可以查看是什么阻止了它，以及你是如何回复的。在活动记录中，你还可以查看**本周报告**，并将历史记录导出为 CSV 或 beancount。

## 从聊天中操作

你可以询问：“我的限额是多少？”、“暂停全部操作”、“将拨盘设为防护”、“将我的 USDC 额度提高到 50”或“撤销全部权限”。每个回答都会显示为一张卡片，你可以直接在卡片上批准更改。
