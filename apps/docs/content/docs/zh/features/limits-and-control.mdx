Kawase 不问你就能做的一切，都在一个**每周预算**之内，由你的钱包签名，由 Arc 本身执行。在预算内，Kawase 不必每次都问你；
其他一切都会等你处理。背后的模型见[安全页面](../safety.mdx)。

## 你的每周预算

设置好钱包后你马上就会开启它（[快速上手](../getting-started.mdx)）；之后它在**设置 → 每周预算**里。

    和跨链平台；**你不在时**是你不在应用里时可以运行的内容（只付给你保存的联系人，每人有上限；在你的金库之间转入转出；只把 USDC
    转到你自己在 Base 上的地址）。

    <Pin box="4 42 92 5.5">它可以使用的平台</Pin>

    <Pin box="4 75 92 6">最坏情况，一句话说清</Pin>

    一样）、**平衡**（在预算内，打字的请求立即执行）或**自主**（它可以在你的限额内根据自己的建议行动，然后告诉你）。**练习模式**

调低一个数字会立即保存。调高则会给你看这次改动，并请你的钱包签署新预算，这也会关闭旧预算：两个预算绝不会同时生效。**长按以
撤销全部**会在一笔交易里收回 Arc 上的所有权限。

## 什么总会询问你

即使在预算内，下面这些也会等你，卡片上写明原因，旁边就是解决办法：

- **首次向此人付款**，或**新的目的地**；
- **开仓**，或任何**超过单笔限额**、**超过本周剩余额度**的操作；
- **不在你的预算范围内**的类别或平台；
- Kawase 不担保的代币、**无法核实价格**的，或**比市场价差**的；
- Kawase **已暂停**、处于**谨慎**模式或**练习**中时的任何操作。

批准一次只覆盖那一个操作；预算本身只有在你修改时才会改变。

## 练习模式

开启练习后，Kawase 会从你自己的地址在 Arc 上以模拟方式运行**你要求的那笔交易**，并显示“**本来会发送**”以及链上的结果。
**什么都不会动**。自动化也会在练习中运行，服务市场的购买会以实时价格回答“将支付”。

## 代币规则

**代币规则**决定 Kawase 可以替你买哪些代币，为未验证代币设置每笔和每天的上限，以及你能接受的最大价格影响；见
[交易任意代币](./swap-and-trade.mdx)。

## 等你处理

有些步骤自动化永远不能独自完成：**每一笔兑换**、超过其授权的付款，或被你的规则拦下的付款。它们会在**等你处理**中等你，在收件箱
和自动化里都能看到，开启通知的地方还会有推送。在任何地方回答一次即可；批准会打开你手动操作时的那笔转账或兑换，并重新检查。
未回答的事项会在 **12 小时**后提醒，**24 小时**后过期。

## 退出工具包

如果感觉不对：先**全部暂停**，再**长按以撤销**所有权限，然后**把我的钱转出**，它会为全部资产打开[取出](./bridge-and-withdraw.mdx)。
它在取出页面的底部。

## 动态和原因

每一笔资金变动都在[动态](./activity-and-receipts.mdx)里，每张收据都有**这是怎么发生的**：它来自哪个请求、检查了什么，以及是哪条
规则放行了它或让它等待。

## 在聊天中

问“我的限额是多少？”、“全部暂停”、“把档位调到谨慎”或“撤销全部”。每个回答都是一张卡片，改动在卡片上批准。
