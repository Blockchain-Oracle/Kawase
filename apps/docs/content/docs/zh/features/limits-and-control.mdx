代理无需询问就能执行的所有操作，都写在 **设置 → 钱包与限额** 中，而且大多数限制由 Arc 自己执行。
本页介绍你可以在那里更改的内容。背后的模型见[安全页面](../safety.mdx)。

## 每种代币的额度

**授权凭证**会显示每种代币的以下信息：Arc 执行的限额（你签署的授权）、Kawase 自己设置的更低上限、
今天剩余的额度，以及任何临时提高的额度。

- **添加代币**：添加你持有的任何代币，或粘贴一个地址，系统会在链上检查。
- **调低**：数字会立即保存。
- **调高**：你会看到 **现在 → 调高后**：一次确认会同时签署新的链上授权，并撤销旧授权，
  因此不会同时存在两份有效授权。

## Kawase 自己会检查什么

除了链上的限额，Kawase 还会执行自己的规则：

- **单笔付款**上限；
- **新收款人**：添加某人后的最初几小时内，该地址不会启用额度和自动化；
  但你自己发起的付款仍会执行，并会建议使用测试金额；
- **仅限允许列表**：代理只会向列表中的联系人付款；
- **临时提高额度**：暂时提高一段时间，然后自动恢复。

## 刹车

有些请求即使没有超出你的限额，也比较异常，系统会暂停并说明原因：向**新联系人**转出超过一半余额、
一笔**价格影响**超过你设置值的交易，或**杠杆超过 5×**。卡片会显示刹车面板；
是否继续由你决定，确认后操作会继续。触发刹车的自动化会改为等待，并出现在“需要你处理”中。

## 代币规则

**钱包与限额 → 代币规则**用于设置 Kawase 可以代你购买哪些代币：**仅限已验证代币**，
或包括热门代币但显示警告；还可以设置未验证代币的单笔和每日交易上限，并查看今天的使用量；
以及设置你能接受的最高价格影响。仿冒代币和高风险代币始终会被拦截。收紧规则会立即生效；
放宽规则需要 Face ID 和你钱包的签名。

## 全部暂停

一个开关就能关闭代理**无需询问即可执行的所有操作**：任何付款都不会使用额度（每笔都会等待你的
Face ID），所有自动化运行都会跳过，代理也不会在市场中购买任何东西。你自己发起的操作仍可正常执行，
包括兑换、跨链和提现，因此你随时都能把资金转出。暂停期间，每个页面上方都会显示提示条。

## 风险档位

**谨慎 · 平衡 · 自主**：

- **谨慎**：每笔付款都要等待你的确认，聊天中发起的付款也一样。
- **平衡**：在你的额度内，输入文字发起的请求会立即执行。
- **自主**：Kawase 可以根据自己的建议，在你的限额内自行操作，然后告诉你结果。

## 练习模式

开启练习模式后，Kawase 会在 Arc 上从你的地址发起你所要求的**完全相同的交易**进行模拟，
并显示链上的结果以及**“本来会转出”**。**不会有任何资金移动。**练习模式也适用于自动化；
市场购买会显示**“本来会支付”**，并提供实时价格，但不会实际付款。兑换、跨链、储蓄操作和保证金订单
会在签署前被拒绝，因此“练习”提示条不会掩盖真实付款。

## 退出方案

如果发现不对劲：先**暂停**，然后按住**撤销所有权限**，用**一次 Face ID**（一笔交易）撤销网络上的
所有权限；接着**转出资金**，这会打开[提现](./bridge-and-withdraw.mdx#withdraw)，处理全部资金。
授权被撤销的自动化会结束。

## 需要你处理

有些步骤自动化永远不能单独执行：**每一笔兑换**、**超过其授权额度**的付款，或被你的**允许列表**
或**冷却时间**拦下的付款。它们会在“需要你处理”中等待，并显示在收件箱和自动化页面里；
如果你设置了通知，还会收到推送通知。你可以在任意位置处理一次：第二次处理时，系统会发现它已经处理过，
并告诉你何时、在哪里完成。确认后会打开你手动进行的相同转账或兑换，并再次检查条件。未处理的项目会在
**12 小时**后提醒你，并在**24 小时**后过期。

## 活动与原因

**活动**会汇总所有代币的转入和转出：转账、收款、包含两边记录的兑换、跨链、储蓄、保证金、
自动化运行、已支付的收款请求、水龙头和练习运行。每一行都会显示当前状态（检查中、已跳过及原因、
练习中、等待中）。筛选项：**全部 · 转入 · 转出 · 交易 · 自动化 · 需要你处理**，最后一项会显示数量。

点击某一行可以查看凭证（金额、时间、网络、对方、交易），然后点击**原因**：查看背后的决策记录；
如果某次运行没有到达链上，则可以查看它被什么拦下，以及你如何处理。从“活动”中，你还可以查看
**本周报告**，并将历史记录**导出**为 CSV 或 beancount。

## 在聊天中

你可以询问“我的限额是多少？”、“暂停所有操作”、“把风险档位设为谨慎”、“把我的 USDC 额度提高到 50”，
或“撤销所有权限”。每次回答都会以卡片显示，所有更改都可以直接在卡片上确认。
