## 通过 Morpho 金库赚取收益（现已支持）

你可以说“存入 50 美元”，也可以打开“赚取收益”页面。Kawase 会列出 Arc 上可通过 Circle 的 App Kit
Earn 使用的 **Morpho 金库**（在测试网上则是 Arc 测试网的模拟金库），并显示易懂的名称和收益率，还可以：

- 将 USDC **存入**你选择的金库；如果你没有指定，系统会选择当前最佳的金库，并根据金库自己的预览结果检查最低金库份额数量。
- 将任意金额**提取**回你的钱包，到账金额至少达到页面显示的金额。
- 显示你的**持仓**，数据实时读取自链上的金库（Kawase 不会保存这些数据）。

每次存入或提取都只需进行**一次 Face ID**，并作为一笔交易发送。[自动储蓄](./automations.mdx#auto-save) 会使用相同的金库，自动帮你补足储蓄金额。

## 更多收益和借款（即将推出）

计划会比较所有接受你资产的来源，包括 **Aave V4**、直接使用 Morpho 金库和其他方式，并显示收益率、当前可提取的金额、规模和风险，同时隐藏你无法退出的来源。计划支持以抵押品借出 **USDC** 或 **EURC**（例如在 Aave V4 上），并提供健康度指标、还款和增加抵押品操作，以及在收件箱中发送清算提醒。这两项功能都**即将推出**。
