## 赚取收益的选项

“我的 200 美元可以在哪里赚取收益？”Kawase 会通过**实时数据**，比较所有可以接收你资产的来源：

- **Aave V4** 供应：当前利率、市场现在可以支付的金额，以及市场规模；
- Circle 的 App Kit Earn 列出的 **Morpho 金库**，按当前可能返还的金额排序。无法返还你资金的金库不会显示，流动性较低的金库会标记出来；
- Merkl 的 **Aero** 流动性活动：标记为**高级**，仅供查看。

系统会在能够返还你这笔金额的来源中，按利率排序，并标记最佳选项。点击 Aave 会打开供应页面；点击金库会打开该金库的 Earn 页面。

## 使用 Morpho 金库赚取收益

说“把 50 美元存起来”，或打开**赚取收益**页面。将 USDC 存入你选择的金库（或当前最佳金库），之后可以取出任意金额。你的**持仓**会从金库实时读取。每次存入或取出都只需进行**一次 Face ID**，并作为一笔交易发送。[自动存款](./automations.mdx#auto-save)也会自动使用相同的金库。

在测试网上，赚取收益功能使用 Arc 测试网上的 Morpho 模拟金库。

## 在 Aave V4 上借款和供应

**借款**页面（主网上从赚取收益页面进入）会先显示你的 Aave V4 持仓：你的欠款（可点击**还款**）、供应的资产（可点击**添加**和**取出**）、**健康度指标**以及剩余可用空间。然后显示你可以借款的资产和利率。

- 可以用 **USDC、cirBTC 或 WETH** 作为抵押，借出 **USDC、EURC、cirBTC 或 WETH**。EURC 不能在 Aave V4 上作为抵押品。Kawase 会从你的钱包中选择抵押品（按抵押系数调整后，价值最高的持有资产），并在**同一笔交易**中将其作为抵押品。
- 你每输入一个数字，健康度指标都会变化。点击“最大”会让健康度保持在安全下限。
- 可能让健康度**低于 1.25 的借款会被拒绝**；低于 **1.5** 时会收到警告。
- 只有一种抵押资产时，页面会显示**触发清算的价格**。
- 可以偿还部分或全部借款。“全部还款”会预留少量利息余量，用于偿还所有欠款，并重置授权。

每项操作都会在你确认时使用最新价格重新检查，从你的钱包模拟，并作为**一笔交易**发送。你可以通过滑动并使用 Face ID 确认。

## 测试网上不可用

Aave V4 仅支持 Arc 主网，因此借款和 Aave 供应也仅支持主网。Morpho 金库在两个网络上都可用。
