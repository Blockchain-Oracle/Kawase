### 哪里可以赚取收益

“我的 200 美元在哪里收益最好？”会根据**实时数据**比较每个接受你资产的来源：**Aave V4** 存款（利率、市场现在能支付多少、规模）、
Circle App Kit Earn 列出的 **Morpho 金库**，以及来自 Merkl 的 **Aero** 流动性活动（标为进阶，只读）。它们在能归还你金额的来源中
按利率排序。

## 自动储蓄

“在钱包里留 100 美元，其余存起来。”**自动储蓄**会留出这笔钱随时可用，把超出的部分转入你自己的金库储蓄；钱包低于这条线时，
它会补回来。它每天检查一次，每次有钱到账时也会检查，它的权限只允许在**你的钱包和你自己的储蓄之间**转移 USDC。见
[自动化](./automations.mdx)。

## 在 Aave V4 上借款和存款

**借款**（主网）先显示你的 Aave V4 仓位：你欠多少（带**还款**）、你存入了什么（带**添加**和**取出**）、**健康度仪表**以及还剩
多少空间；然后是你可以借多少、利率多少。

- 以 **USDC、cirBTC 或 WETH** 为抵押**借入** USDC、EURC、cirBTC 或 WETH。EURC 不能在 Aave V4 上作为抵押品。Kawase 从你的
  钱包中选择抵押品，并在**同一笔交易中**存入。
- 你每输入一位数字，仪表都会变化；**最大**会让你停在安全下限。会让健康度**低于 1.25 的借款会被拒绝**，**低于 1.5** 时会提醒你。
  只有一种抵押资产时，交易单会显示它会在什么价格被强平。
- **还款**可以还一部分或全部。“全部”会连同少量利息余量一并还清，并重置授权。

每个操作在你批准时都会按最新价格重新检查，从你的钱包模拟执行，并作为一笔你滑动确认的交易发出。Aave V4 仅在 Arc 主网上；
Morpho 金库在两个网络上都可用。
