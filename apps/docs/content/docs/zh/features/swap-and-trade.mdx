## 路线竞价

输入金额后，Kawase 会在同一时刻询问 **KyberSwap、Circle App Kit、LI.FI、Uniswap、0x 和 Socket**。每个报价一到就显示；
**扣除费用后**到账最多的那个被选中，其他平台也会列出它们能给多少，或者为什么无法报价。访客也能看到竞价：只需在最后登录。

## 你的资产，每个代币

首页显示**你的地址持有的每个代币**，覆盖 Arc 以及 Ethereum、Base、Arbitrum、OP、Polygon 和 Avalanche，每个都有真实标志和价值。
**冒名代币**（在其他地址或用其他小数位的知名代号）会被隐藏；**没有价格也没有资金池**的代币进入已隐藏；没有价格的代币永远不会计入
你的总额。

## 代币规则

每次买入都先经过你的**代币规则**（设置 → 预算 → 代币规则）：

- 仿冒币、貔貅盘和无法卖出的代币**永远不会**被买入，不论规则如何；
- **哪些代币**：只限已验证的，或已验证和热门的（带警告）；
- **未验证**代币每笔和每天的上限，以及今天的用量；
- 你接受的**价格影响**（1% 到 15%；会损失更多的兑换将被拒绝）。

收紧规则立即生效；放宽规则需要 Face ID，并由你的钱包签署新规则。

## 在测试网上

Arc Testnet 上可以交易 **USDC ↔ EURC**，使用同样的交易单和同样的竞价（Circle App Kit 报价；其他平台回复不在该网络上）。其他所有
代币和 Meme 币仅限主网。
