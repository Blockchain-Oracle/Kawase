**Kawase Margin** 让你用超过本金的资金押注价格上涨（**做多**）或下跌（**做空**）。它运行在 Arc 主网的 **Aave V4** 上，
通过**你自己的** Aave 账户：不需要交易所账户，不用闪电贷，Kawase 不持有任何东西。Aave V4 没有测试网，所以在测试网上页面会
说明这一点并提供切换。

## 仓位是如何构建的

- **做多 X**：你的 USDC 保证金换成 X 并存入作为抵押，然后 Kawase 以它为抵押借入 USDC，再换成更多 X 存入，循环几次。
- **做空 X**：你的 USDC 存入作为抵押，然后 Kawase 借入 X，换成 USDC 存入，循环进行。
- **平仓**反向执行：取出、兑换、还款，剩余部分回到你的钱包。

整个仓位以**一笔交易**从你自己的钱包开仓或平仓（一个 EIP-7702 批处理）。兑换部分来自 KyberSwap，调用数据经过检查。每次循环
只按预言机价格借到安全的健康度，账户开仓时的**健康度不低于 1.10**。在你滑动之前，整批操作会从你的地址**在链上模拟**；会失败的仓位会在这里停下。

## 市场和杠杆

市场来自 Aave V4 在 Arc 上的实时储备：**cirBTC**（Circle 的比特币）和 **WETH**，可做多和做空；**EURC** 只能做空，因为
EURC 不能在 Aave V4 上作为抵押品。杠杆受每种资产的抵押系数限制（目前约为**做多 cirBTC 3.4×**、**做多 WETH 4.1×**、
**做空 2.4×**）。保证金以 **USDC** 支付。

## 你的仓位

每个仓位都有自己的页面：分为**价格**和**借款利息**的**盈亏**、开仓价和标记价、规模、权益、**健康度**仪表和强平价格，以及
**平仓 25% · 50% · 75% · 全部**，会把平仓草拟到同一张交易单里（“滑动平仓”）。当某个未平仓位的健康度低于 1.25，或价格再
变动不到 10% 就会被强平时，首页会提醒你。
