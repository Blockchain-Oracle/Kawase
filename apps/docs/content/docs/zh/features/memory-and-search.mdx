## 记忆

“记住我的房东是 @maria。”Kawase 会保存**你要求它记住的事实**（人物、@用户名和偏好），并在之后使用这些信息。当回答用到了其中一项时，聊天中会显示**来自记忆**，让你始终知道信息的来源。

**设置 → 记忆**会列出所有事实。你可以添加、编辑或删除单条或全部事实，也可以关闭记忆。访客模式下的记忆会在登录后转入你的账户。你没有要求 Kawase 记住的内容，它不会记住。

## 搜索所有对话

历史记录页面会搜索 Kawase 服务器上的**所有**对话，而不只是已加载的对话：包括文字、卡片，以及卡片面向的对象（搜索“Maria”，给她的转账就会显示出来）。支持搜索部分词语，也支持中文、日文和韩文。结果会按对话分组，并显示匹配内容前后的文字。点击结果即可打开对话。你也可以直接问：“我上个月给房东转了什么？”

## 长对话

长对话会始终保持连贯：每轮对话后，较早的内容会折叠成摘要，最新消息则逐字保留。摘要不会重新写出记忆中的金额或结果；卡片自身的结果会原样保留。Kawase 在使用某项结果前，也会再次通过工具进行检查。

## 为你推荐

**首页**会根据当前网络上的真实余额，显示几张值得关注的卡片：

- 闲置的 USDC 超过你的消费需求，旁边还有一个可能足以全部赚回这笔金额的金库；
- 你的一项收款请求即将过期；
- 跨链交易在预计到账时间过后 15 分钟仍未到账；
- 你持有的某种代币价格大幅变动（一天内变动 5%，货币稳定币变动 0.5%，且持有金额至少为 $10）；
- 你的一个[保证金头寸](./long-short.mdx)的健康度低于 1.25，或距离清算只差 10% 的价格变动。

这些只是事实和选项，不是建议。每张卡片只有一个操作。**不再显示**会将卡片隐藏一周；**不再显示此类内容**会将这一类卡片静音（之后可以恢复）。

## 关于 Arc 的有来源回答

你可以问“Arc 的最终确认速度有多快？”或“转账要花多少钱？”。Kawase 会根据精选笔记回答。这些笔记来自 Arc 和 Circle 的文档以及本文档，并会显示一张**来源**卡片，列出每个来源。只提供事实，不提供投资建议。

## 会解释原因的卡片

- **图表**：查看你的投资组合价值，或任意代币在一天、一周、一个月或一年内的价格。
- **为什么是这个？**：解释某条跨链路线、兑换平台或金库为何胜出（询问了哪些服务商、每个服务商能提供什么、费用和用时，以及其他服务商为何落选或无法报价）。
- **设置变更**：以“现在 → 之后”的形式显示，并应用到你的设备上（开启或关闭记忆、回复语言和主题）。
- **状态**：显示 Kawase、Arc（每个网络）、Circle 和价格服务是否正常、变慢或中断。

## 外部文本只是数据

Kawase 从外部读取的任何内容（市场回答、代币和金库名称、链上备注、联系人备注、过往消息）都会被标记为不可信。隐藏其中的指令会被标记出来，并且永远不会被执行。
