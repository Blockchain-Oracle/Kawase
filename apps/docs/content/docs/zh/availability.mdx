本页面**由代码生成**。Kawase 维护着一个功能注册表（`packages/config/src/capabilities.ts`）：应用会读取它来决定提供哪些功能，智能代理也会在提出建议前读取它。网站构建时会导入同一个注册表，因此文档不会承诺应用尚未提供的功能。

- **可用**：已上线，并在该网络上提供。
- **即将推出**：属于产品计划，但尚未上线。注册表目前还未列出的计划内容，也会显示为即将推出。
- **不支持此网络**：这是有意设计的结果（例如，测试币仅存在于测试网上）。

## 各项功能包含什么

某项功能可用，并不代表它的所有形式都能使用。注册表还会准确说明目前哪些功能可以运行、哪些还不行——智能代理也会使用相同的说明，诚实地回答“可以……吗？”。
