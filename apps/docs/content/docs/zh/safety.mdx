Kawase 可以让 AI 帮你转账。前提是，它**能做的事**必须少、清晰，并由网络强制执行，而不是依赖对 AI 或 Kawase 服务器的信任。本页会介绍具体方式。

## 你的钱包

- 当你登录时（邮箱验证码、Apple 或 Google），Kawase 会创建一个普通的以太坊账户（**EOA**）。账户密钥由 **Turnkey** 保存在安全硬件中，位于专属于你的子组织内。没有 PIN，也没有密码。**两条网络上都是同一个地址**。
- 接着，Kawase 使用 **EIP-7702** 原地升级这个账户，让它指向 MetaMask 审计过的 `EIP7702StatelessDeleGator`。你只需签署一份授权；Kawase 的中继器会发送交易并支付手续费，因此设置完全免费。
- 升级后，你的账户可以授予**委托权限**（ERC-7710，来自 MetaMask 的 Delegation Framework）。这些权限范围有限，并内置了各种限制，且需要签名确认。智能代理只有通过这种方式，才能在没有你逐笔确认的情况下转移资金。

## 两种付款授权方式

| | 每日额度内 | 其他所有情况 |
|---|---|---|
| 适用范围 | 使用今天剩余额度支付 USDC，收款对象必须是你之前付过的人，或是你在本次请求中指定的人 | 超出额度、任何 EURC 付款、首次向新地址付款且金额超过阈值、相似地址、所有兑换、跨链和金库操作，以及任何额度变更 |
| 你需要做什么 | **什么都不用。** Kawase 会发送并通知你。 | **Face ID**（Android 上使用指纹或屏幕锁；网页版使用邮箱验证码） |
| 谁来强制执行 | **链**：你签署的每日额度委托 | **你的签名**：签署完整且准确的交易 |

### 每日额度

设置时，你只需使用 Face ID 接受一次。这是一份从你的账户授予 Kawase 智能代理钱包的委托，其中写入了以下限制——系统会从签署的字节中**解码**这些内容，并在你签名之前以收据形式展示：

- **代币**：仅限 USDC，并且只能调用其 `transfer` 函数。
- **金额**：每个 24 小时周期内，最多使用每日额度（链上周期上限）。
- **谁可以使用**：仅限 Kawase 的智能代理钱包（使用者锁定）。其他人即使复制了权限也无法使用。
- **有效期**：90 天。到期后权限失效，你需要接受新的委托。
- **不包含原生币**：其中不允许发送网络的 gas 代币。

链会拒绝超出这些限制的任何操作——例如金额更大、使用其他代币、调用其他函数、权限过期，或你已撤销权限。我们在 Arc 测试网上进行了测试，也测试了智能代理密钥泄露后的操作；链最终都回滚了这些操作。

### 额度以上需要 Face ID

对于超过额度的操作，Kawase 会构建完整且准确的交易，向你展示金额、币种、收款人和网络，并要求你的钱包签署**这笔**交易。服务器随后会检查签署的字节是否与卡片上的信息完全一致，包括发送方、收款人、金额、网络和手续费，然后才会广播交易。任何不匹配都会冻结付款。

目前，签名来自你的登录会话，并由设备自身的生物识别检查保护。**Passkeys 即将推出**（需要使用 Kawase 自己的域名）：添加 Passkey 后，Turnkey 本身会要求每次钱包签名都使用它。这样，即使登录会话被盗，或有人控制了 Kawase 自己的服务器，也无法代替你签名。

## 自动化：固定在链上

每个自动化都有**自己的授权**。启用时，你需要使用一次 Face ID 签署该授权：

- **定时付款**：只能转账，**固定到一个收款人**，每个周期最多转账指定金额，并在自动化结束时失效。
- **自动存钱**：只能在你的钱包和你自己的金库储蓄之间转移 USDC。
- **跨链规则**：只能将 USDC 跨链到**你自己的**地址，并且会限制跨链路线的手续费。

取消自动化时，会在同一步操作中**撤销其链上授权**。

## 智能代理永远无法执行的操作

- 一天内转移超过你的额度，或将额度用于 USDC 转账以外的任何操作。
- 向自动化授权固定的收款人以外的其他人转账。
- 在没有你的 Face ID 的情况下兑换、跨链、使用 EURC 付款、向相似地址付款，或提高你的额度。
- 仅因为你口头说了“是”就批准付款：语音付款始终需要等待你点击确认。
- 凭空编造地址：地址只能来自你的联系人，或来自你自己逐字发送的消息。
- 选择网络：网络属于服务器上的会话信息，每笔付款都会进行核对。
- 没有凭证就标记付款成功：只有包含准确转账信息的收据才算完成。如果结果不明确，系统会显示“仍在检查”，并且**绝不会自动重试**，因此不会重复付款。

## 撤销和暂停

- **撤销每日额度**：钱包和限额 → 撤销（长按确认）。这是一笔从你的钱包发出的普通交易，会在链上停用该委托；之后智能代理无法在没有你的 Face ID 的情况下发送任何资金。
- 在自动化页面或聊天中，**暂停、跳过或取消**任何自动化；取消操作会撤销其授权。
- **一次暂停全部功能**（所有自动化和智能代理转账）已经由服务器强制执行；设置中的开关**即将推出**。
- **完全退出**：请参阅[不使用 Kawase 提现](./withdraw-without-kawase.mdx)。
