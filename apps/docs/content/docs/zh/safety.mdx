Kawase 可以让 AI 帮你转账。前提是它**能做的事**必须少、清晰，并由网络强制执行，而不是依赖对 AI 或 Kawase 服务器的信任。本页介绍具体方式。

## 你的钱包

- 你登录后（邮箱验证码、Apple 或 Google），Kawase 会创建一个普通的以太坊风格账户（**EOA**）。账户密钥由 **Privy** 保管，拆分后存放在安全隔离区中，任何一方都不会持有完整的密钥。没有 PIN，也没有密码。**两条网络使用同一个地址**。
- 接着，Kawase 使用 **EIP-7702** 就地升级这个账户，让它指向 MetaMask 审计过的
  `EIP7702StatelessDeleGator`。你只需签署一次授权；Kawase 的中继器会发送授权并支付手续费，因此设置不花钱。
- 升级后，你的账户可以授予**委托权限**（来自 MetaMask Delegation Framework 的 ERC-7710）。这些权限范围有限，并内置各种限制，且都需要签名。代理只有通过这种方式，才能在没有你操作的情况下转移资金。

## 两种付款授权方式

| | 在日常额度内 | 其他所有情况 |
|---|---|---|
| 覆盖范围 | 不超过今日剩余额度的 USDC 付款，收款人必须是你之前付过的人，或是你在本次收款请求中指定的人 | 超出额度、任何 EURC 付款、向新地址进行超过阈值的首次付款、相似地址、所有兑换、跨链和金库操作，以及任何限额变更 |
| 你要做什么 | **什么都不用做**。Kawase 会发送并通知你。 | **Face ID**（Android 上使用指纹或屏幕锁；网页上使用邮箱验证码） |
| 由什么强制执行 | **链上规则**：你签署的额度委托 | **你对准确交易的签名** |

### 日常额度

设置期间，你只需使用一次 Face ID 接受它。这是从你的账户授予 Kawase 代理钱包的委托，以下限制都会写入其中——系统会**从签名字节中解码**这些限制，并在你签名前以回执形式展示：

- **代币**：仅限 USDC，且只能调用它的 `transfer` 函数。
- **金额**：每 24 小时内，最多不超过每日额度（链上周期上限）。
- **谁可以使用**：仅限 Kawase 的代理钱包（兑换者锁定）。其他人拿到权限副本也无法使用。
- **有效期**：90 天，之后权限失效，你需要接受新的授权。
- **不包含原生币**：其中不允许发送网络的 gas 代币。

链上规则会拒绝任何超出这些限制的操作——例如金额更大、使用其他代币、调用其他函数、授权过期，或你已撤销授权。我们已在 Arc 测试网上进行测试，包括使用泄露的代理密钥尝试操作；链上交易会回滚。

### 额度以上需要 Face ID

对于超出额度的操作，Kawase 会构建准确的交易，向你展示金额、货币、收款人和网络，然后让你的钱包签署**这笔**交易。服务器会在广播前检查签名字节是否与卡片上的信息一致——发送方、收款人、金额、网络和手续费都必须匹配。信息不一致时，付款会被冻结。

签名来自你自己的钱包，并经过持有人验证：手机上用 Face ID（或设备密码），网页上用 Kawase 发送到你已验证邮箱的六位数验证码。Kawase 的服务器从不持有你的密钥，因此无法代你签名。

## 自动化：固定在链上

每个自动化都有**自己的授权**。启用自动化时，你需要使用一次 Face ID 签署该授权：

- **定时付款**：只能转账，**固定到一个收款人**，每个周期最多转出指定金额，并在自动化结束时失效。
- **自动存钱**：只能在你的钱包和你自己的金库储蓄账户之间转移 USDC。
- **跨链规则**：只能将 USDC 跨链到**你自己的**地址，并限制跨链路线的手续费。

取消自动化时，会在同一步**在链上撤销其授权**。

## 代理永远无法执行的操作

- 一天内转出超过你的额度，或将额度用于 USDC 转账以外的任何操作。
- 向自动化授权固定的收款人以外的其他人转账。
- 在没有 Face ID 的情况下兑换、跨链、使用 EURC 付款、向相似地址付款，或提高你的限额。
- 仅因为你说了“是”就批准付款：语音付款始终需要你点击确认。
- 编造地址：地址只能来自你的联系人，或来自你逐字提供的消息。
- 选择网络：网络属于服务器上的会话信息，每笔付款都会与该网络进行核对。
- 没有凭证就标记为已付款：只有包含准确转账信息的回执才算付款成功。如果结果不明确，系统会显示“仍在检查”，并且**绝不会自动重试**，因此不会重复付款。

## 撤销和暂停

- **撤销额度**：钱包与限额 → 撤销（长按确认）。这是一笔由你钱包发起的普通交易，会在链上停用该委托；之后代理无法在没有 Face ID 的情况下发送任何资金。
- 在自动化页面或聊天中**暂停、跳过或取消**任何自动化；取消会撤销其授权。
- 在“钱包与限额”中选择**暂停全部**，即可关闭代理执行的所有操作，且不会再询问；你自己使用 Face ID 发起的付款仍可正常进行。**退出工具包**会暂停并在一笔交易中撤销所有权限，同时帮助你转出资金。请参阅
  [限额与控制](./features/limits-and-control.mdx)。
- **彻底离开**：请参阅[不使用 Kawase 也能提现吗](./withdraw-without-kawase.mdx)。
