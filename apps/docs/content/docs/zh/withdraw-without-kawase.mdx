Kawase 从不持有你的资金。你的代币在 Arc 上的**个人账户**中，你授予代理的权限范围很小，而且会自动过期。本指南会带你一步步完成退出：先借助 Kawase，然后完全不使用 Kawase。

<Status ids="export_wallet" />

## 开始前

先处理钱包中还不是普通资金的部分：

- 金库中的**储蓄**：在“赚取收益”页面提现。
- **Aave V4** 中的供应或贷款：在“借款与出借”页面还款并提现。
- **做多和做空**仓位：在每个仓位的页面选择（Close · All）关闭。
- **代理钱包**：设置 → 代理钱包 → **退回到我的钱包**。
- 其他代币可以在 Arc 上直接以该代币提现，也可以先兑换成 USDC，再跨链到其他网络。

## 第 1 部分：使用 Kawase（退出工具）

<Steps>
<Step>
### 暂停代理
设置 → **钱包与限额** → **全部暂停**。代理执行的所有操作都会立即停止，不再询问你。你自己通过 Face ID
发起的付款仍然可以正常进行。
</Step>
<Step>
### 撤销所有权限
在退出工具中，**长按撤销**。通过一次 Face ID 操作，就能发送一笔交易，撤销该网络上的所有授权：你的
额度，以及每个自动化的授权。自动化会结束。如果你使用了另一个网络，也要在那里重复操作。
</Step>
<Step>
### 提现全部资金
在退出工具中，选择**转出资金**，会打开[提现](./features/bridge-and-withdraw.mdx#withdraw)页面，并默认选中所有资金（或者说“把所有资金提现到我的 Kraken”）。选择资金去向：**交易所**（Kraken、Bybit、OKX、Binance、
Bitget、KuCoin，或通过 Base 使用 Coinbase）、Arc 或其他网络上的**个人钱包**，或者通过交易所转入你的银行账户。
Kawase 会为每种代币规划路径（直接转账、跨链，或先兑换成 USDC），提醒你目标平台不会入账的资产，然后你只需通过 Face ID 确认一次。
</Step>
<Step>
### 检查区块浏览器
在区块浏览器中打开你的地址（见下文），确认资金余额已经到达你指定的位置。
</Step>
</Steps>

## 第 2 部分：不使用 Kawase（导出钱包）

你钱包的密钥由 **Privy** 为你保管，拆分后存放在安全隔离区中。导出后，你会得到一份自己的**私钥**副本，可以在任何钱包中使用同一个账户。

<Steps>
<Step>
### 导出
设置 → **账户** → **导出钱包**。阅读警告并按住按钮：Privy 会在它自己的安全窗口中显示你的**私钥**，Kawase 永远看不到。在手机上，导出会在网页版中打开，你需要用同一个邮箱登录。把私钥离线安全保存。任何拥有它的人都可以控制你的资金。
</Step>
<Step>
### 导入到其他钱包
在 MetaMask、Rabby 或其他支持自定义网络的钱包中，选择导入私钥。你会得到与 Kawase 中**相同的地址**。
</Step>
<Step>
### 添加 Arc
使用下表中的信息添加网络。你的余额会显示为链上的实际余额。
</Step>
<Step>
### 转出资金
像使用其他钱包一样，从该钱包发起转账。金库、Aave 和保证金仓位都在这些协议中的个人账户里，因此 Arc 上支持这些协议的任何界面都可以管理它们。
</Step>
</Steps>

如果你想保留一份自己控制的副本，可以在 Kawase 运行期间导出钱包：导出操作会通过应用完成。

## 在区块浏览器上检查所有信息

不需要 Kawase，你也能查看资金。在 Arc 的区块浏览器中打开你的地址：

- 主网：`https://explorer.arc.io/address/<your address>`
- 测试网：`https://testnet.arcscan.app/address/<your address>`

你可以在那里查看：

- 你的余额（在 Arc 上，USDC 同时也是网络的 Gas 代币：这是一个余额，但会同时显示为原生币和 USDC
  代币）；
- 每笔交易，包括代理在你的额度范围内执行的付款；
- 你账户的**代码**：完成设置后，代码为 `0xef0100`，后面跟着 `EIP7702StatelessDeleGator` 地址。这表示
  EIP-7702 升级；你的账户仍然可以像普通账户一样使用。

Kawase 的交易回执会链接到相同的页面。

## 如果 Kawase 消失

- **代理权限将无法继续使用。** 你的额度和自动化授权只能由 Kawase 自己的代理钱包使用，而且它们会过期：额度在 90 天后过期，每个自动化会在其结束日期过期。
- **你的资金仍在账户中。** 这是 Arc 上的普通账户。
- **如果你导出了私钥**（第 2 部分），就可以从任何支持 Arc 的钱包中转出全部资金。

## 将 Arc 添加到其他钱包

| | 主网 | 测试网 |
|---|---|---|
| 网络名称 | Arc | Arc Testnet |
| 链 ID | `5042` | `5042002` |
| RPC | `https://rpc.mainnet.arc.io` | `https://rpc.testnet.arc.io` |
| 货币符号 | USDC | USDC |
| 区块浏览器 | `https://explorer.arc.io` | `https://testnet.arcscan.app` |

有些钱包会在自定义网络中把 Gas 余额标为“ETH”；但在 Arc 上，它是 USDC。两个网络上的 USDC 代币地址都是
`0x3600000000000000000000000000000000000000`；主网上的 EURC 地址是
`0xbEf5f6d51CB62b58e6A8f77868681825C6fe21c1`，测试网上的地址是 `0x89B50855Aa3bE2F677cD6303Cec089B5F319D72a`。

## 移除 EIP-7702 升级（可选）

你不需要撤销升级，就可以转出资金。如果导出钱包后，你想恢复为普通账户，可以签署一份指向零地址的
EIP-7702 授权，并从账户本身发送该授权，例如使用 viem：

```ts
import { zeroAddress } from "viem";

const authorization = await walletClient.signAuthorization({ contractAddress: zeroAddress, executor: "self" });
await walletClient.sendTransaction({ to: walletClient.account.address, authorizationList: [authorization] });
```

完成后，区块浏览器中你的地址不会再显示代码。
