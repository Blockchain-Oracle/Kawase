Kawase 从不持有你的资金。你的代币在 Arc 上的**个人账户**中，授予代理的权限范围很小，并且会自动过期。本指南会一步步带你取出资金：先借助 Kawase，再完全不使用 Kawase。

<Status ids="export_wallet" />

## 开始前

先处理钱包中还不是普通资金的部分：

- 金库中的**储蓄**：在赚取收益页面提取。
- **Aave V4** 中的供应或贷款：在借款与出借页面还款并提取。
- **做多或做空**仓位：在每个仓位的页面关闭（关闭 · 全部）。
- **代理钱包**：设置 → 代理钱包 → **退回到我的钱包**。
- USDC 和 EURC 以外的代币：将它们交易为 USDC，或导出钱包（第 2 部分），再从任意钱包转出。

## 第 1 部分：使用 Kawase（退出工具）

<Steps>
<Step>
### 暂停代理
设置 → **钱包与限额** → **全部暂停**。代理执行的所有操作都会立即停止，不再询问。你自己的 Face ID
付款仍可正常使用。
</Step>
<Step>
### 撤销所有权限
在退出工具中，**按住以撤销**。通过一次 Face ID 就能发送一笔交易，撤销该网络上的所有授权：你的
额度权限和每个自动化的授权都会被撤销。自动化会停止。如果你使用了另一个网络，也要在那里重复操作。
</Step>
<Step>
### 选择资金去向
选择你在另一个钱包中控制的地址（MetaMask、Rabby、……），并确保已添加 **Arc**；也可以使用交易所的
**Arc** 充值地址。确认网络是 Arc；另一个网络上的地址不是同一个地址。
</Step>
<Step>
### 转出全部资金
说“把我的所有 USDC 转到 0x……”（在同一条消息中粘贴地址），或使用转账页面，然后用 Face ID 确认。
EURC 也要重复操作。如果想转到另一个网络，请将 USDC [跨链](./features/bridge-and-withdraw.mdx) 到你在 Base、Ethereum、Arbitrum、Optimism、Polygon 或 Avalanche 上的自有地址。
</Step>
<Step>
### 检查区块浏览器
在区块浏览器中打开你的地址（见下文），确认余额已到达目标地址。
</Step>
</Steps>

## 第 2 部分：不使用 Kawase（导出钱包）

你的钱包密钥由 **Turnkey** 代你保管。导出钱包后，你会得到一份自己的副本，可以在任何钱包中使用同一个账户。

<Steps>
<Step>
### 导出
设置 → **账户** → **导出钱包**。阅读警告，用 Face ID 确认后，Turnkey 会在你的设备上解密你的**恢复短语**。
显示恢复短语时，系统会禁止截图和录屏；离开此页面后，恢复短语会自动隐藏。把它抄写下来，并离线安全保存。任何拥有恢复短语的人都能控制你的资金。
</Step>
<Step>
### 导入到另一个钱包
在 MetaMask、Rabby 或其他支持自定义网络的钱包中，选择导入恢复短语。你会得到与 Kawase 中**相同的地址**。
</Step>
<Step>
### 添加 Arc
使用下表中的详细信息添加网络。你的余额会按照链上的状态显示。
</Step>
<Step>
### 转出资金
像使用其他钱包一样，从这个钱包转出资金。金库、Aave 和保证金仓位都属于你在相应协议中的账户，因此 Arc 上支持这些协议的任何界面都可以管理它们。
</Step>
</Steps>

如果你想保留一份自己控制的副本，请在 Kawase 正常运行时导出：导出操作会通过应用完成。

## 在区块浏览器上检查所有记录

不需要 Kawase，你也能查看资金。请在 Arc 的区块浏览器中打开你的地址：

- 主网：`https://explorer.arc.io/address/<your address>`
- 测试网：`https://testnet.arcscan.app/address/<your address>`

你可以在那里查看：

- 你的余额（在 Arc 上，USDC 同时也是网络的 gas 代币：这是一个余额，会同时显示为原生币和 USDC
  代币）；
- 每一笔交易，包括代理在你的额度权限下执行的付款；
- 账户的**代码**：完成设置后，代码为 `0xef0100`，后面跟着 `EIP7702StatelessDeleGator` 地址。这就是
  EIP-7702 升级；你的账户仍可像普通账户一样使用。

Kawase 的交易回执会链接到这些相同的页面。

## 如果 Kawase 停止服务

- **代理权限将无法继续使用。** 你的额度权限和自动化授权只能由 Kawase 自己的代理钱包使用，而且它们会过期：
  额度权限在 90 天后过期，每个自动化会在自己的结束日期过期。
- **你的资金仍在账户中。** 这是 Arc 上的普通账户。
- **如果你已导出恢复短语**（第 2 部分），就可以从任何支持 Arc 的钱包中转出全部资金。

## 将 Arc 添加到另一个钱包

| | 主网 | 测试网 |
|---|---|---|
| 网络名称 | Arc | Arc Testnet |
| Chain ID | `5042` | `5042002` |
| RPC | `https://rpc.mainnet.arc.io` | `https://rpc.testnet.arc.io` |
| 货币符号 | USDC | USDC |
| 区块浏览器 | `https://explorer.arc.io` | `https://testnet.arcscan.app` |

一些钱包会在自定义网络中将 gas 余额标记为“ETH”；但在 Arc 上，它是 USDC。两个网络上的 USDC 代币地址都是
`0x3600000000000000000000000000000000000000`；主网上的 EURC 地址是
`0xbEf5f6d51CB62b58e6A8f77868681825C6fe21c1`，测试网上的地址是 `0x89B50855Aa3bE2F677cD6303Cec089B5F319D72a`。

## 移除 EIP-7702 升级（可选）

你不需要撤销升级就能转出资金。如果导出钱包后想恢复为普通账户，可以签署一份指向零地址的
EIP-7702 授权，然后从账户本身发送该授权，例如使用 viem：

```ts
import { zeroAddress } from "viem";

const authorization = await walletClient.signAuthorization({ contractAddress: zeroAddress, executor: "self" });
await walletClient.sendTransaction({ to: walletClient.account.address, authorizationList: [authorization] });
```

之后，区块浏览器中你的地址将不再显示代码。
