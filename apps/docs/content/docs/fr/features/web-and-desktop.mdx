## Confirmer sur le web

Là où un téléphone demande Face ID, l’app web envoie un **code par email** : vous tapez les six chiffres et le paiement part.
La voix marche aussi : autorisez le micro quand le navigateur le demande. Si vous refusez, Kawase explique comment l’autoriser,
et le clavier est juste là.

## L’installer

Kawase est une app web installable. Dans Chrome ou Edge, utilisez **Installer** ; dans Safari, **Ajouter au Dock** (Mac) ou
**Sur l’écran d’accueil** (iPhone). Si le réseau tombe, une page hors ligne le dit au lieu d’un écran cassé. Kawase ne met
jamais les soldes en cache, donc rien d’ancien n’est jamais affiché comme de l’argent actuel.
