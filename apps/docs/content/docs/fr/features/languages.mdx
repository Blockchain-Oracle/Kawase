Kawase parle les langues les plus parlées au monde, partout dans l'application :

| Langue | Nom dans la langue | Sens de lecture |
|---|---|---|
| Anglais | English | de gauche à droite |
| Chinois | 中文 | de gauche à droite |
| Hindi | हिन्दी | de gauche à droite |
| Espagnol | Español | de gauche à droite |
| Français | Français | de gauche à droite |
| Arabe | العربية | **de droite à gauche** |
| Bengali | বাংলা | de gauche à droite |
| Portugais | Português | de gauche à droite |
| Russe | Русский | de gauche à droite |
| Ourdou | اردو | **de droite à gauche** |

- **Dès le premier écran.** Le sélecteur de langue se trouve sur le premier panneau d'intégration, puis sur tous les écrans suivants. Le changement est
  instantané, y compris le sens de lecture.
- **Chaque texte dans chaque langue.** Les dix catalogues de l'application sont complets. L'agent répond dans votre langue et la
  [voix](./voice.mdx) reconnaît et parle les dix langues.
- **Les montants restent exacts.** Les nombres sont formatés selon votre langue, tandis que les montants, les adresses et les codes restent de gauche à droite
  pour pouvoir être vérifiés caractère par caractère.
- **Cette documentation** est disponible dans les mêmes dix langues (utilisez le sélecteur de langue dans la barre latérale).
