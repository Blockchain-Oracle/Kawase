Kawase fonctionne sur deux réseaux : **le réseau principal Arc**, où l'argent est réel, et **le réseau de test Arc**, où il ne l'est pas. La **pastille du réseau** dans l'en-tête permet de passer de l'un à l'autre en un geste, dans les deux sens, comme pour le mode sombre.

- **Les nouveaux comptes commencent sur le réseau de test**, et tout élément manquant ou illisible revient par défaut au réseau de test : l'option la plus sûre.
- **Le premier passage au réseau principal** affiche un court message de consentement « Argent réel » ; les passages suivants sont instantanés.
- **Toujours visible, jamais indiqué par la couleur seule.** Sur le réseau de test, une bande indique « Réseau de test · pas d'argent réel » ; sur le réseau principal, les cartes d'argent portent la mention **ARGENT RÉEL**. La pastille indique le réseau, et l'orbe vocale change de couleur (vert citron sur le réseau principal, bleu ciel sur le réseau de test).
- **Votre portefeuille est le même** sur les deux réseaux : une seule adresse, les mêmes contacts et les mêmes réglages. Les soldes et l'activité sont propres à chaque réseau.
- **Le serveur décide.** Le réseau fait partie de votre session sur le serveur. Il n'est jamais choisi par le modèle d'IA ; chaque paiement indique le réseau pour lequel il a été préparé, et toute incompatibilité bloque le paiement.

Lorsqu'un élément n'existe que sur un seul réseau — le faucet sur le réseau de test, la marketplace x402 sur le réseau principal — Kawase vous le signale et vous propose de changer de réseau au lieu d'échouer. Consultez la page [réseaux](../networks.mdx) pour la comparaison complète.
