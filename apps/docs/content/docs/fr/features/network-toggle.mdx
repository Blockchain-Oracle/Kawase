Kawase fonctionne sur deux réseaux : le **réseau principal Arc**, où l’argent est réel, et le **réseau de test Arc**, où il ne
l’est pas. Le **bouton de réseau** en haut de l’Accueil passe de l’un à l’autre en un geste, dans les deux sens, comme le mode
sombre.

<Flow>
  <FlowStep icon="toggle" title="Touchez le bouton">Test ⇄ Principal, dans les deux sens.</FlowStep>
  <FlowFork>

  <FlowStep icon="eye" title="Toujours affiché" tone="ink">Le bouton, un bandeau ou une pastille Argent réel.</FlowStep>
</Flow>

## Toujours visible, jamais par la seule couleur

- **Le bouton** nomme le réseau sur l’Accueil, et dans Réglages → Réseau.
- **Sur le réseau de test**, les écrans ouverts portent un bandeau : **« Réseau de test · pas d'argent réel »** (voir
  [Envoyer](./send-receive-request.mdx)).
- **Sur le réseau principal**, les écrans d’argent portent une pastille **Argent réel** :

## Comment il se comporte

- **Les nouveaux comptes démarrent sur le réseau de test**, et tout ce qui manque ou est illisible revient au réseau de test :
  le sens sûr.
- **Le premier passage au réseau principal** vous demande de confirmer que l’argent y est réel ; ensuite c’est instantané. Les
  invités peuvent explorer les deux réseaux ; l’argent du réseau principal demande un compte.
- **Votre portefeuille est le même** sur les deux : une adresse, les mêmes contacts et réglages. Les soldes et l’activité sont
  propres à chaque réseau.
- **Les brouillons restent là où ils ont été créés.** Ce que vous êtes en train de vérifier reste sur son réseau d’origine ;
  revenez-y pour l’approuver.
- **Le serveur décide.** Le réseau fait partie de votre session sur le serveur, jamais choisi par le modèle d’IA ; chaque
  paiement porte le réseau pour lequel il a été préparé, et une différence l’arrête.

Quand quelque chose n’existe que sur un réseau (le robinet sur le réseau de test, long et court sur le principal), Kawase le
dit et propose de changer plutôt que d’échouer. Voir [réseaux](../networks.mdx) pour la comparaison complète.
