L'achat est prévu avec **l'Onramp Kit de Circle** : payez avec une carte de débit, Apple Pay ou Google Pay et recevez des USDC ou des EURC
directement dans votre portefeuille Kawase sur Arc. La session est créée par le serveur de Kawase et ouverte dans une fenêtre sécurisée du navigateur ;
Kawase confirme l'achat uniquement lorsque l'argent est confirmé sur la blockchain.

Pour acheter n'importe quel autre token avec Apple Pay, l'idée est d'acheter d'abord des USDC, puis de les échanger en une seule autorisation. Les deux frais sont affichés
avant le paiement.

Cette fonctionnalité **arrive bientôt** : elle n'est pas encore disponible dans l'application. En attendant, sur le réseau de test, vous pouvez utiliser le
[distributeur](../getting-started.mdx#4-get-test-money) gratuit ; sur le réseau principal, vous pouvez recevoir des USDC depuis n'importe quel portefeuille ou exchange qui envoie des fonds vers
Arc.
