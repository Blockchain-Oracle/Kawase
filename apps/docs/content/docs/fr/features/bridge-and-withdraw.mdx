Demandez à Kawase (« envoie 20 dollars à Alex sur Base », « transfère mes USDC de Base vers Arc ») et une **carte de transfert**
s'affiche. Elle s'ouvre aussi en plein écran sous le nom **Transférer vers une autre chaîne**. Elle transfère des USDC entre
Arc et **Base, Ethereum, Arbitrum, Optimism, Polygon ou Avalanche**.

## Depuis Arc, vers n'importe qui

Le destinataire peut être **vous**, un **contact**, un **@handle** ou n'importe quelle **adresse 0x**. Kawase demande un
cours en temps réel à trois prestataires :

- **Circle CCTP** : Circle brûle les USDC sur Arc et les crée sur l'autre réseau ;
- **Across** et **Relay** : un solveur paie sur l'autre réseau, puis est remboursé avec votre dépôt.

Ils sont classés selon **le montant reçu après les frais**. En cas d'égalité, le plus rapide est favorisé. Jusqu'à trois routes
s'affichent avec le logo du prestataire, le montant reçu, les frais et le délai prévu. La meilleure route est sélectionnée pour
vous, mais vous pouvez en choisir une autre.

Avant de vous demander l'autorisation dans votre portefeuille, Kawase prépare la transaction du prestataire sélectionné et la
**vérifie** : pour Across, il décode le dépôt (qui paie, qui reçoit, quel jeton, le montant, le minimum, la destination, sans
message supplémentaire) ; pour Relay, il vérifie l'autorisation et le dépôt dans le dépositaire indiqué par Relay ; pour CCTP,
il vérifie l'appel de Circle. La transaction est simulée depuis votre portefeuille, puis envoyée en **une seule transaction**
après que vous avez fait glisser le bouton et confirmé avec Face ID.

## Transférer vers Arc

Si vous détenez des USDC à la même adresse sur un autre réseau, Kawase les trouve (les soldes s'affichent et le plus important
est sélectionné) et les transfère vers Arc avec le **permit de Relay** : une signature, et **aucuns frais de gas nécessaires
sur ce réseau**. Le permit est vérifié (votre adresse, le montant, le contrat de Relay et les USDC de ce réseau) avant votre
signature.

## Suivre un transfert

Chaque transfert est suivi : **Signé → Envoyé → En cours d'arrivée → Livré**, avec des liens vers les explorateurs. Kawase
vérifie le montant sorti de votre portefeuille dans le reçu, puis le transfert effectué grâce au statut du prestataire
(statut du dépôt Across, statut de la demande Relay ou attestation de Circle). Si un prestataire **rembourse** les fonds, la
carte l'indique clairement. Rien n'est jamais envoyé deux fois.

## Sur le réseau de test

Arc Testnet utilise **CCTP uniquement** ; Across et Relay servent le réseau principal Arc. Le transfert vers Arc est disponible
uniquement sur le réseau principal.

## Retirer partout (bientôt disponible)

Aujourd'hui, vous pouvez envoyer des USDC ou des EURC à **n'importe quelle adresse sur Arc**, y compris l'adresse de dépôt
Arc d'une plateforme d'échange, ainsi que des USDC à n'importe qui sur les six réseaux ci-dessus. Un écran **Retirer** unique
pour tous les actifs et toutes les destinations est en cours de développement.

Pour retirer votre argent sans utiliser Kawase, consultez [Retirer sans Kawase](../withdraw-without-kawase.mdx).
