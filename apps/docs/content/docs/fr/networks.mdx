**Arc** est le réseau de stablecoins de Circle : USDC sert de jeton de gas, les frais sont donc payés en dollars et les transactions sont finalisées en moins d'une seconde. Kawase prend exactement en charge deux réseaux Arc.

| | Arc réseau principal | Arc réseau de test |
|---|---|---|
| Argent | Argent réel | Argent de test sans valeur |
| Chain ID | `5042` | `5042002` |
| Explorateur | `explorer.arc.io` | `testnet.arcscan.app` |
| Recevoir de l'argent | Acheter par carte avec l'Onramp de Circle ; recevoir de n'importe quel portefeuille ou exchange qui envoie vers Arc | Le faucet intégré à l'app (environ 20 USDC + 20 EURC par jour) ; le sandbox Onramp de Circle avec des cartes de test |
| Trading | N'importe quel jeton, y compris les meme coins, au meilleur prix parmi KyberSwap, App Kit et LI.FI | USDC ↔ EURC uniquement |
| Long et short | Kawase Margin sur Aave V4 | Non disponible (Aave V4 est uniquement disponible sur le réseau principal) |
| Rendement et emprunt | Fourniture et emprunt sur Aave V4 ; coffres Morpho proposés par Circle's App Kit Earn | Coffres Morpho fictifs du réseau de test Arc |
| Ponts | Vers n'importe qui sur Base, Ethereum, Arbitrum, Optimism, Polygon et Avalanche avec CCTP, Across ou Relay ; transférer vers Arc | CCTP vers leurs réseaux de test (Base Sepolia, Ethereum Sepolia, …) |
| Marketplace x402 | Le catalogue de Circle | Le vendeur de démonstration de Kawase (le catalogue de Circle est uniquement disponible sur le réseau principal) |
| Limites par défaut | Plus basses | Dix fois plus élevées (aucun argent réel en jeu) |
| Où commencent les nouveaux comptes | | ✓ |

## Comment Kawase les sépare

- **Un seul geste pour basculer**, dans les deux sens : consultez [le bouton de changement de réseau](./features/network-toggle.mdx).
- **Le réseau est indiqué de trois façons** : le badge dans l'en-tête, la bande du réseau de test ou le libellé ARGENT RÉEL, et la couleur de l'orbe.
- **Le serveur contrôle le choix.** Chaque paiement est préparé pour un seul réseau et y reste jusqu'à la fin ; si le réseau change entre-temps, le paiement s'arrête au lieu de passer sur l'autre réseau.
- **Une seule adresse de portefeuille sur les deux réseaux**, avec les soldes, l'activité et les limites gérés séparément pour chaque réseau.
