Kawase ne détient jamais votre argent. Vos USDC et EURC se trouvent sur **votre propre compte** sur Arc, et les autorisations que vous avez données à l'agent sont limitées et expirent automatiquement. Cette page explique comment récupérer votre argent, avec l'aide de Kawase ou sans elle.

<Status ids="export_wallet" />

## Pendant que Kawase fonctionne : envoyez votre argent

Le moyen le plus rapide est d'effectuer un paiement classique :

<Steps>
<Step>
### Choisissez la destination
Une adresse que vous contrôlez dans un autre portefeuille (MetaMask, Rabby, …) sur lequel **Arc** est ajouté, ou l'adresse de dépôt **Arc** d'une plateforme d'échange. Vérifiez que le réseau est bien Arc : envoyer des fonds à une adresse sur un autre réseau ne produit pas le même résultat.
</Step>
<Step>
### Envoyez tout
Dites « envoie tous mes USDC à 0x… » (collez l'adresse dans le même message) ou utilisez l'écran Envoyer. Les montants importants nécessitent votre Face ID. Répétez l'opération pour les EURC.
</Step>
<Step>
### Révoquez l'agent
Portefeuille et limites → **Révoquer** (maintenez le bouton appuyé). Annulez toutes les automatisations ; chaque annulation révoque son autorisation sur la chaîne.
</Step>
</Steps>

Vous pouvez aussi envoyer vos USDC directement à **votre propre adresse** sur Base, Ethereum, Arbitrum, Optimism, Polygon ou Avalanche avec un [pont](./features/bridge-and-withdraw.mdx).

## Vérifiez tout sur l'explorateur

Vous n'avez pas besoin de Kawase pour voir votre argent. Ouvrez votre adresse sur l'explorateur de blocs d'Arc :

- Réseau principal : `https://explorer.arc.io/address/<your address>`
- Réseau de test : `https://testnet.arcscan.app/address/<your address>`

Vous pourrez y voir :

- vos soldes en **USDC** et **EURC** (sur Arc, les USDC servent aussi de jeton de gaz du réseau : il n'y a qu'un seul solde, affiché à la fois comme monnaie native et comme jeton USDC) ;
- chaque transaction, y compris les paiements effectués par l'agent dans le cadre de votre autorisation ;
- le **code** de votre compte : après la configuration, il s'agit de `0xef0100` suivi de l'adresse `EIP7702StatelessDeleGator`. Il s'agit de la mise à niveau EIP-7702 ; votre compte fonctionne toujours comme un compte normal.

Les reçus de Kawase renvoient vers ces mêmes pages.

## Si Kawase disparaît

- **Les autorisations de l'agent cessent d'être utiles.** Votre autorisation et les autorisations des automatisations ne peuvent être utilisées que par le portefeuille de l'agent de Kawase. Elles expirent également (l'autorisation après 90 jours et chaque automatisation à sa date de fin).
- **Votre argent reste sur votre compte.** Il s'agit d'un compte classique sur Arc, dont la clé est conservée pour vous par Turnkey.
- **Exporter le portefeuille (bientôt disponible).** Réglages → Compte → Exporter le portefeuille affichera la clé de votre portefeuille grâce à l'export sécurisé de Turnkey, après votre Face ID et l'affichage d'avertissements clairs. Vous pourrez alors importer le compte dans n'importe quel portefeuille compatible avec Arc et transférer votre argent sans Kawase. Cette option **n'est pas encore disponible** ; en attendant, suivez les étapes ci-dessus.

## Ajouter Arc à un autre portefeuille

| | Réseau principal | Réseau de test |
|---|---|---|
| Nom du réseau | Arc | Arc Testnet |
| ID de chaîne | `5042` | `5042002` |
| RPC | `https://rpc.mainnet.arc.io` | `https://rpc.testnet.arc.io` |
| Symbole de la monnaie | USDC | USDC |
| Explorateur | `https://explorer.arc.io` | `https://explorer.testnet.arc.io` |

Sur certains portefeuilles, le solde de gaz est affiché comme « ETH » sur les réseaux personnalisés ; sur Arc, il s'agit d'USDC. L'adresse du jeton USDC est
`0x3600000000000000000000000000000000000000` sur les deux réseaux ; celle d'EURC est
`0xbEf5f6d51CB62b58e6A8f77868681825C6fe21c1` sur le réseau principal et `0x89B50855Aa3bE2F677cD6303Cec089B5F319D72a` sur le réseau de test.

## Supprimer la mise à niveau EIP-7702 (facultatif)

Vous n'avez pas besoin d'annuler la mise à niveau pour transférer votre argent. Si vous souhaitez retrouver un compte classique après l'avoir exporté, signez une autorisation EIP-7702 pointant vers l'adresse zéro et envoyez-la depuis le compte lui-même, par exemple avec viem :

```ts
import { zeroAddress } from "viem";

const authorization = await walletClient.signAuthorization({ contractAddress: zeroAddress, executor: "self" });
await walletClient.sendTransaction({ to: walletClient.account.address, authorizationList: [authorization] });
```

Ensuite, l'explorateur n'affiche plus de code sur votre adresse.
