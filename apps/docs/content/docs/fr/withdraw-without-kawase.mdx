Kawase ne détient jamais votre argent. Vos jetons se trouvent sur **votre propre compte** sur Arc, et les autorisations que vous avez données à l’agent sont
limitées et expirent automatiquement. Ce guide vous explique comment tout retirer, étape par étape : d’abord avec l’aide de Kawase, puis sans elle.

<Status ids="export_wallet" />

## Avant de commencer

Rassemblez ce qui n’est pas encore de l’argent disponible dans votre portefeuille :

- **Épargne** dans un coffre : retirez-la depuis l’écran Rendement.
- Une fourniture **Aave V4** ou un prêt : remboursez et retirez les fonds depuis l’écran Emprunter.
- Des positions **Long ou short** : fermez-les (Fermer · Tout) depuis la page de chaque position.
- **Le portefeuille de l’agent** : Settings → Agent wallet → **Return to my wallet**.
- Les jetons autres que USDC et EURC : échangez-les contre USDC, ou exportez votre portefeuille (partie 2) et déplacez-les depuis n’importe quel portefeuille.

## Partie 1 : avec Kawase (le kit de sortie)

<Steps>
<Step>
### Mettre l’agent en pause
Settings → **Wallet & limits** → **Pause all**. Toutes les actions de l’agent qui ne demandent pas votre confirmation s’arrêtent immédiatement. Vos paiements Face ID
fonctionnent toujours.
</Step>
<Step>
### Révoquer toutes les autorisations
Dans le kit de sortie, **maintenez le bouton appuyé pour révoquer**. Une confirmation Face ID envoie une transaction qui révoque toutes les autorisations sur ce réseau : votre
allocation et les autorisations de toutes les automatisations. Les automatisations prennent fin. Répétez l’opération sur l’autre réseau si vous l’avez utilisé.
</Step>
<Step>
### Choisir où envoyer l’argent
Une adresse que vous contrôlez dans un autre portefeuille (MetaMask, Rabby, …), avec **Arc** ajouté, ou l’adresse de dépôt **Arc** d’une plateforme d’échange.
Vérifiez que le réseau est Arc : une adresse sur un autre réseau n’est pas la même chose.
</Step>
<Step>
### Tout envoyer
Dites « envoie tous mes USDC à 0x… » (collez l’adresse dans le même message) ou utilisez l’écran Envoyer de l'argent, puis confirmez avec Face ID.
Répétez l’opération pour EURC. Pour recevoir les fonds sur un autre réseau, [faites un pont](./features/bridge-and-withdraw.mdx) avec vos USDC vers votre propre
adresse sur Base, Ethereum, Arbitrum, Optimism, Polygon ou Avalanche.
</Step>
<Step>
### Vérifier sur l’explorateur
Ouvrez votre adresse dans l’explorateur (ci-dessous) et vérifiez que les soldes se trouvent bien à l’endroit où vous les avez envoyés.
</Step>
</Steps>

## Partie 2 : sans Kawase (exporter votre portefeuille)

La clé de votre portefeuille est conservée pour vous par **Turnkey**. L’exportation vous permet d’en obtenir votre propre copie et d’utiliser le même compte dans n’importe quel
portefeuille.

<Steps>
<Step>
### Exporter
Settings → **Account** → **Export wallet**. Lisez les avertissements, confirmez avec Face ID, puis Turnkey déchiffre votre **phrase de récupération**
sur votre appareil. Les captures d’écran et les enregistrements d’écran sont bloqués pendant son affichage, et elle est masquée lorsque vous quittez cet écran. Notez-la
dans un endroit sûr, hors ligne. Toute personne qui la possède contrôle votre argent.
</Step>
<Step>
### L’importer dans un autre portefeuille
Dans MetaMask, Rabby ou un autre portefeuille qui autorise les réseaux personnalisés, choisissez d’importer une phrase de récupération. Vous obtenez **la même
adresse** que dans Kawase.
</Step>
<Step>
### Ajouter Arc
Ajoutez le réseau avec les informations du tableau ci-dessous. Vos soldes apparaissent tels qu’ils sont sur la blockchain.
</Step>
<Step>
### Déplacer votre argent
Envoyez des fonds depuis ce portefeuille comme depuis n’importe quel autre. Les positions dans les coffres, Aave et les positions sur marge se trouvent dans votre propre compte auprès de ces
protocoles. Toute interface compatible avec ces protocoles sur Arc peut donc les gérer.
</Step>
</Steps>

Exportez votre portefeuille pendant que Kawase fonctionne si vous voulez conserver une copie que vous contrôlez : l’exportation passe par l’application.

## Tout vérifier sur l’explorateur

Vous n’avez pas besoin de Kawase pour voir votre argent. Ouvrez votre adresse dans l’explorateur de blocs d’Arc :

- Réseau principal : `https://explorer.arc.io/address/<your address>`
- Réseau de test : `https://testnet.arcscan.app/address/<your address>`

Vous pourrez y voir :

- vos soldes (sur Arc, USDC est aussi le jeton de gaz du réseau : un seul solde, affiché à la fois comme la pièce native et comme le
  jeton USDC) ;
- chaque transaction, y compris les paiements effectués par l’agent dans le cadre de votre allocation ;
- le **code** de votre compte : après la configuration, il s’agit de `0xef0100` suivi de l’adresse `EIP7702StatelessDeleGator`. Il s’agit de la
  mise à niveau EIP-7702 ; votre compte fonctionne toujours comme un compte classique.

Les reçus de Kawase renvoient vers ces mêmes pages.

## Si Kawase disparaît

- **Les autorisations de l’agent cessent d’être utiles.** Votre allocation et les autorisations des automatisations ne peuvent être utilisées que par le
  portefeuille de l’agent de Kawase, et elles expirent : l’allocation après 90 jours, et chaque automatisation à sa date de fin.
- **Votre argent reste sur votre compte.** Il s’agit d’un compte classique sur Arc.
- **Avec une phrase de récupération exportée** (partie 2), vous pouvez tout déplacer depuis n’importe quel portefeuille compatible avec Arc.

## Ajouter Arc à un autre portefeuille

| | Réseau principal | Réseau de test |
|---|---|---|
| Nom du réseau | Arc | Arc Testnet |
| Identifiant de chaîne | `5042` | `5042002` |
| RPC | `https://rpc.mainnet.arc.io` | `https://rpc.testnet.arc.io` |
| Symbole de la devise | USDC | USDC |
| Explorateur | `https://explorer.arc.io` | `https://testnet.arcscan.app` |

Certains portefeuilles affichent le solde de gaz sous le nom « ETH » sur les réseaux personnalisés ; sur Arc, il s’agit de USDC. L’adresse du jeton USDC est
`0x3600000000000000000000000000000000000000` sur les deux réseaux ; celle d’EURC est
`0xbEf5f6d51CB62b58e6A8f77868681825C6fe21c1` sur le réseau principal et `0x89B50855Aa3bE2F677cD6303Cec089B5F319D72a` sur le réseau de test.

## Supprimer la mise à niveau EIP-7702 (facultatif)

Vous n’avez pas besoin d’annuler la mise à niveau pour déplacer votre argent. Si vous voulez retrouver un compte classique après l’avoir exporté, signez une
autorisation EIP-7702 pointant vers l’adresse zéro et envoyez-la depuis le compte lui-même, par exemple avec viem :

```ts
import { zeroAddress } from "viem";

const authorization = await walletClient.signAuthorization({ contractAddress: zeroAddress, executor: "self" });
await walletClient.sendTransaction({ to: walletClient.account.address, authorizationList: [authorization] });
```

Ensuite, l’explorateur n’affiche plus de code sur votre adresse.
