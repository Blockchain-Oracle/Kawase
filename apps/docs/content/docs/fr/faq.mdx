## Kawase est-il une banque ou un dépositaire ?

Non. Votre argent se trouve sur **votre propre compte** sur Arc. Kawase détient les autorisations que vous avez signées : un plafond quotidien et une autorisation par automatisation. La blockchain en fait respecter les limites. Consultez le [modèle de sécurité](./safety.mdx).

## Dois-je m'y connaître en crypto ?

Non. Vous parlez à Kawase comme à une personne : « envoie 20 dollars à Alex ». Il n'y a pas de phrase secrète, de réglage de frais de réseau ni de code PIN. Connectez-vous avec un code envoyé par e-mail, Apple ou Google.

## L'IA décide-t-elle où va mon argent ?

Elle fait des propositions ; le code décide et la blockchain fait respecter les règles. Le modèle ne peut pas choisir le réseau, inventer une adresse ou approuver un paiement. Dans les limites de votre plafond, il envoie de l'argent aux personnes que vous avez déjà payées ou nommées. Pour toute autre action, votre Face ID est nécessaire.

## Que se passe-t-il si l'IA me comprend mal ?

Chaque action s'affiche sous forme de carte avec le montant exact, la devise, le destinataire et le réseau avant tout transfert. Ce qui a été entendu par la voix est toujours affiché en toutes lettres. Une nouvelle demande dans la même conversation annule une ancienne carte ouverte. Une ancienne carte ne peut donc pas être approuvée par erreur.

## Combien ça coûte ?

Kawase paie les frais de réseau pour configurer votre portefeuille et pour les paiements effectués dans les limites de votre plafond. Pour les paiements que vous signez vous-même, de petits frais de réseau en USDC s'affichent sur la carte. Les ponts affichent les frais du prestataire avant votre confirmation. Les échanges affichent le taux et les frais.

## Quels pays et quelles devises ?

Kawase est conçu autour de **USDC** (dollars) et d'**EURC** (euros) sur Arc, dans dix langues. Sur le Réseau principal, vous pouvez aussi détenir et échanger **n'importe quel jeton sur Arc**, et Acheter par carte si le service Onramp de Circle est disponible dans votre pays. Consultez [ce qui fonctionne aujourd'hui](./availability.mdx).

## Que devient un paiement si mon téléphone s'éteint en cours de route ?

Rien n'est perdu et aucun paiement n'est effectué deux fois. Chaque paiement est enregistré avant d'être envoyé. Kawase vérifie le réseau jusqu'à connaître le résultat. Seul un reçu contenant le transfert exact permet de le marquer comme payé. Les automatisations ne sont exécutées qu'une fois par exécution et sont récupérées après un redémarrage.

## Puis-je un jour l'utiliser sans Kawase ?

Oui. Votre compte est un compte ordinaire sur Arc. Dans Réglages → Compte → Exporter le portefeuille, vous pouvez obtenir sa phrase de récupération. Consultez [Retirer de l'argent sans Kawase](./withdraw-without-kawase.mdx).

## Pourquoi le Réseau de test existe-t-il dans l'application ?

Pour que vous puissiez tout essayer — Envoyer de l'argent, échanger, utiliser des ponts, créer des automatisations et utiliser la voix — avec de l'Argent de test gratuit avant de passer à l'Argent réel. Le bouton dans l'en-tête permet de changer de réseau en un geste.

## Le code est-il open source ?

Le dépôt [Blockchain-Oracle/kawase](https://github.com/Blockchain-Oracle/kawase) est disponible sur GitHub. Il est rendu public pour la participation au hackathon.
