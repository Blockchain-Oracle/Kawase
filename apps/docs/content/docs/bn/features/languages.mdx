Kawase অ্যাপের সর্বত্র বিশ্বের সবচেয়ে বেশি ব্যবহৃত ভাষাগুলোতে কথা বলে:

| ভাষা | ভাষাটিতে নাম | দিক |
|---|---|---|
| ইংরেজি | English | বাম থেকে ডানে |
| চীনা | 中文 | বাম থেকে ডানে |
| হিন্দি | हिन्दी | বাম থেকে ডানে |
| স্প্যানিশ | Español | বাম থেকে ডানে |
| ফরাসি | Français | বাম থেকে ডানে |
| আরবি | العربية | **ডান থেকে বামে** |
| বাংলা | বাংলা | বাম থেকে ডানে |
| পর্তুগিজ | Português | বাম থেকে ডানে |
| রুশ | Русский | বাম থেকে ডানে |
| উর্দু | اردو | **ডান থেকে বামে** |

- **প্রথম স্ক্রিন থেকেই।** প্রথম অনবোর্ডিং প্যানেলে এবং এরপরের প্রতিটি স্ক্রিনে ভাষার পিল রয়েছে; ভাষা বদলালে
  দিকসহ সবকিছু সঙ্গে সঙ্গে বদলে যায়।
- **প্রতিটি ভাষায় প্রতিটি লেখা।** অ্যাপের দশটি ভাষার ক্যাটালগ সম্পূর্ণ; এজেন্ট আপনার ভাষায় উত্তর দেয় এবং
  [ভয়েস](./voice.mdx) দশটি ভাষাই শুনতে ও বলতে পারে।
- **পরিমাণ হুবহু থাকে।** সংখ্যাগুলো আপনার ভাষা অনুযায়ী সাজানো হয়, তবে পরিমাণ, ঠিকানা ও কোড বাম থেকে ডানেই থাকে,
  যাতে প্রতিটি অক্ষর মিলিয়ে দেখা যায়।
- **এই ডকুমেন্টগুলোও** একই দশটি ভাষায় পাওয়া যায় (সাইডবারের ভাষা বদলানোর অপশন ব্যবহার করুন)।
