Kawase কখনও আপনার টাকা ধরে রাখে না। আপনার টোকেন Arc-এ **আপনার নিজের অ্যাকাউন্টে** থাকে, আর এজেন্টকে দেওয়া অনুমতিগুলো সীমিত এবং নিজেরাই মেয়াদ শেষ করে। এই গাইডে ধাপে ধাপে টাকা বের করে নেওয়ার পদ্ধতি দেখানো হয়েছে: প্রথমে Kawase-এর সাহায্যে, তারপর Kawase ছাড়া।

<Status ids="export_wallet" />

## শুরু করার আগে

আপনার ওয়ালেটে এখনো নগদ অবস্থায় নেই—এমন সবকিছু গুছিয়ে নিন:

- কোনো ভল্টে থাকা **সঞ্চয়**: Earn স্ক্রিনে গিয়ে তা উত্তোলন করুন।
- **Aave V4**-এ সরবরাহ করা টোকেন বা ঋণ: Borrow স্ক্রিনে ঋণ পরিশোধ করে টাকা উত্তোলন করুন।
- **লং ও শর্ট** পজিশন: প্রতিটি পজিশনের পেজে গিয়ে (Close · All) দিয়ে বন্ধ করুন।
- **এজেন্ট ওয়ালেট**: Settings → Agent wallet → **Return to my wallet**।
- অন্য যেকোনো টোকেন Arc-এ Withdraw ব্যবহার করে সেই টোকেন হিসেবেই বাইরে পাঠাতে পারেন, অথবা USDC-তে রূপান্তর করে অন্য চেইনে পাঠাতে পারেন।

## অংশ ১: Kawase-এর সাহায্যে (exit kit)

<Steps>
<Step>
### এজেন্টকে বিরতি দিন
Settings → **Wallet & limits** → **Pause all**। এজেন্টের করা সব কাজ সঙ্গে সঙ্গে বন্ধ হয়ে যাবে। আপনার নিজের Face ID
দিয়ে করা পেমেন্ট চালু থাকবে।
</Step>
<Step>
### সব অনুমতি বাতিল করুন
exit kit-এ **বাতিল করতে চেপে ধরে রাখুন**। একবার Face ID দিলে একটি লেনদেনের মাধ্যমে ওই নেটওয়ার্কের সব অনুমতি বাতিল হবে: আপনার
allowance এবং প্রতিটি অটোমেশনের grant। অটোমেশন বন্ধ হয়ে যাবে। অন্য নেটওয়ার্ক ব্যবহার করে থাকলে সেখানে আবার একই কাজ করুন।
</Step>
<Step>
### সব টাকা উত্তোলন করুন
exit kit-এ **টাকা বাইরে পাঠান** চাপলে [টাকা উত্তোলন](./features/bridge-and-withdraw.mdx#withdraw) খুলবে এবং সবকিছু
নির্বাচিত থাকবে (অথবা বলুন, "আমার Kraken-এ সব টাকা উত্তোলন করো")। টাকা কোথায় যাবে তা বেছে নিন: কোনো **এক্সচেঞ্জ**
(Kraken, Bybit, OKX, Binance, Bitget, KuCoin, অথবা Base-এর মাধ্যমে Coinbase), Arc বা অন্য চেইনে **আপনার নিজের
ওয়ালেট**, অথবা কোনো এক্সচেঞ্জের মাধ্যমে আপনার ব্যাংক। গন্তব্যে যে টোকেন জমা নাও হতে পারে, সে বিষয়ে সতর্ক করে Kawase
প্রতিটি টোকেনের জন্য পরিকল্পনা করবে (ট্রান্সফার, ব্রিজ, অথবা আগে USDC-তে রূপান্তর), আর আপনি একবার Face ID দিয়ে নিশ্চিত করবেন।
</Step>
<Step>
### explorer-এ যাচাই করুন
নিচের explorer-এ আপনার ঠিকানা খুলে দেখুন এবং নিশ্চিত করুন যে ব্যালান্সগুলো ঠিক যেখানে পাঠিয়েছেন সেখানে আছে।
</Step>
</Steps>

## অংশ ২: Kawase ছাড়া (আপনার ওয়ালেট এক্সপোর্ট করুন)

আপনার ওয়ালেটের key **Turnkey** আপনার হয়ে সংরক্ষণ করে। এক্সপোর্ট করলে আপনি নিজের একটি কপি পাবেন, তাই একই অ্যাকাউন্ট যেকোনো
ওয়ালেটে ব্যবহার করতে পারবেন।

<Steps>
<Step>
### এক্সপোর্ট করুন
Settings → **Account** → **Export wallet**। সতর্কতাগুলো পড়ুন, Face ID দিয়ে নিশ্চিত করুন, এবং Turnkey আপনার ডিভাইসে
**recovery phrase** ডিক্রিপ্ট করবে। এটি দেখানোর সময় স্ক্রিনশট ও স্ক্রিন রেকর্ডিং বন্ধ থাকে, আর আপনি স্ক্রিন ছেড়ে গেলে এটি
লুকিয়ে যায়। এটি অফলাইনে নিরাপদ কোথাও লিখে রাখুন। যার কাছে এটি থাকবে, সে আপনার টাকা নিয়ন্ত্রণ করতে পারবে।
</Step>
<Step>
### অন্য ওয়ালেটে ইমপোর্ট করুন
MetaMask, Rabby বা কাস্টম নেটওয়ার্ক সমর্থন করে এমন অন্য কোনো ওয়ালেটে recovery phrase ইমপোর্ট করার অপশন বেছে নিন। Kawase-এ থাকা
**একই ঠিকানা** আপনি পাবেন।
</Step>
<Step>
### Arc যোগ করুন
নিচের টেবিলে দেওয়া তথ্য দিয়ে নেটওয়ার্কটি যোগ করুন। আপনার ব্যালান্স অন-চেইনে যেমন আছে, তেমনই দেখা যাবে।
</Step>
<Step>
### আপনার টাকা সরান
অন্য যেকোনো ওয়ালেট থেকে যেভাবে পাঠাতেন, এই ওয়ালেট থেকেও সেভাবেই পাঠান। ভল্ট, Aave এবং মার্জিন পজিশনগুলো ওই
প্রোটোকলগুলোতে আপনার নিজের অ্যাকাউন্টে থাকে, তাই Arc-এ সেগুলোর যেকোনো ইন্টারফেস দিয়ে এগুলো পরিচালনা করা যাবে।
</Step>
</Steps>

আপনি নিয়ন্ত্রণে থাকা একটি কপি চাইলে Kawase চালু থাকা অবস্থাতেই এক্সপোর্ট করুন: এক্সপোর্টটি অ্যাপের মাধ্যমে সম্পন্ন হবে।

## explorer-এ সবকিছু যাচাই করুন

আপনার টাকা দেখতে Kawase-এর প্রয়োজন নেই। Arc-এর block explorer-এ আপনার ঠিকানা খুলুন:

- মেইননেট: `https://explorer.arc.io/address/<your address>`
- টেস্টনেট: `https://testnet.arcscan.app/address/<your address>`

সেখানে আপনি দেখতে পারবেন:

- আপনার ব্যালান্স (Arc-এ USDC নেটওয়ার্কের gas token-ও: একটি ব্যালান্স native coin এবং USDC token—দুইভাবেই দেখানো হয়);
- প্রতিটি লেনদেন, যার মধ্যে আপনার allowance-এর অধীনে এজেন্টের করা পেমেন্টও রয়েছে;
- আপনার অ্যাকাউন্টের **code**: সেটআপের পর এটি `0xef0100`, এরপর `EIP7702StatelessDeleGator` ঠিকানা। এটিই
  EIP-7702 upgrade; আপনার অ্যাকাউন্ট স্বাভাবিক অ্যাকাউন্ট হিসেবেই কাজ করে।

Kawase-এর রসিদগুলোও একই পেজে লিংক করে।

## Kawase বন্ধ হয়ে গেলে

- **এজেন্টের অনুমতিগুলো আর কাজে লাগবে না।** আপনার allowance এবং অটোমেশনের grant শুধু Kawase-এর নিজস্ব এজেন্ট
  ওয়ালেট ব্যবহার করতে পারে, আর এগুলোর মেয়াদ শেষ হয়ে যায়: allowance-এর 90 দিন পর, এবং প্রতিটি অটোমেশনের নির্ধারিত
  শেষ তারিখে।
- **আপনার টাকা আপনার অ্যাকাউন্টেই থাকবে।** এটি Arc-এর একটি সাধারণ অ্যাকাউন্ট।
- **এক্সপোর্ট করা recovery phrase** (অংশ ২) থাকলে Arc সমর্থন করে এমন যেকোনো ওয়ালেট থেকে সব টাকা সরাতে পারবেন।

## EIP-7702 upgrade সরিয়ে ফেলা (ঐচ্ছিক)

টাকা সরানোর জন্য upgrade ফিরিয়ে নেওয়ার প্রয়োজন নেই। এক্সপোর্ট করার পর আপনি আবার সাধারণ অ্যাকাউন্ট চাইলে zero address-এ নির্দেশ করা
একটি EIP-7702 authorization সাইন করে সেটি অ্যাকাউন্ট থেকেই পাঠান, যেমন viem দিয়ে:

```ts
import { zeroAddress } from "viem";

const authorization = await walletClient.signAuthorization({ contractAddress: zeroAddress, executor: "self" });
await walletClient.sendTransaction({ to: walletClient.account.address, authorizationList: [authorization] });
```

এরপর explorer-এ আপনার ঠিকানায় কোনো code দেখা যাবে না।
