Kawase কখনও আপনার টাকা নিজের কাছে রাখে না। আপনার টোকেন Arc-এ **আপনার নিজের অ্যাকাউন্টে** থাকে। এজেন্টকে দেওয়া অনুমতিগুলো সীমিত এবং নিজে থেকেই মেয়াদ শেষ হয়ে যায়। এই নির্দেশিকায় ধাপে ধাপে টাকা তোলার পদ্ধতি দেখানো হয়েছে: প্রথমে Kawase-এর সাহায্যে, তারপর Kawase ছাড়াই।

<Status ids="export_wallet" />

## শুরু করার আগে

আপনার ওয়ালেটে এখনও নগদ নয়—এমন জিনিসগুলো গুছিয়ে নিন:

- ভল্টে থাকা **সঞ্চয়**: Earn স্ক্রিন থেকে তুলে নিন।
- **Aave V4**-এ দেওয়া ঋণ বা নেওয়া ঋণ: Borrow স্ক্রিন থেকে ঋণ পরিশোধ করে টাকা তুলে নিন।
- **লং ও শর্ট** পজিশন: প্রতিটি পজিশনের পেজে গিয়ে (Close · All) বন্ধ করুন।
- **এজেন্ট ওয়ালেট**: Settings → Agent wallet → **Return to my wallet**।
- USDC ও EURC ছাড়া অন্য টোকেন: সেগুলো USDC-তে ট্রেড করুন, অথবা আপনার ওয়ালেট এক্সপোর্ট করে (পর্ব ২) যেকোনো ওয়ালেট থেকে সরিয়ে নিন।

## পর্ব ১: Kawase-এর সাহায্যে (এক্সিট কিট)

<Steps>
<Step>
### এজেন্টকে বিরতি দিন
Settings → **Wallet & limits** → **Pause all**। আপনার অনুমতি ছাড়া এজেন্ট যা কিছু করে, তা সঙ্গে সঙ্গে বন্ধ হয়ে যাবে। আপনার নিজের Face ID
দিয়ে করা পেমেন্ট চালু থাকবে।
</Step>
<Step>
### সব অনুমতি বাতিল করুন
এক্সিট কিটে **বাতিল করতে চেপে ধরে রাখুন**। একটি Face ID ব্যবহার করলেই একটি লেনদেনে ওই নেটওয়ার্কের সব অনুমতি বাতিল হবে: আপনার
allowance এবং প্রতিটি অটোমেশনের অনুমতি। অটোমেশন বন্ধ হয়ে যাবে। অন্য নেটওয়ার্ক ব্যবহার করে থাকলে সেখানে আবার করুন।
</Step>
<Step>
### টাকা কোথায় যাবে তা বেছে নিন
অন্য কোনো ওয়ালেটে (MetaMask, Rabby, …) আপনার নিয়ন্ত্রণে থাকা একটি ঠিকানা, যেখানে **Arc** যোগ করা আছে; অথবা কোনো এক্সচেঞ্জের **Arc** ডিপোজিট ঠিকানা।
নেটওয়ার্কটি Arc কি না দেখে নিন। অন্য নেটওয়ার্কের ঠিকানা একই জিনিস নয়।
</Step>
<Step>
### সব টাকা পাঠান
বলুন, "আমার সব USDC 0x…-এ পাঠাও" (একই মেসেজে ঠিকানাটি পেস্ট করুন), অথবা Send স্ক্রিন ব্যবহার করে Face ID দিয়ে নিশ্চিত করুন।
EURC-এর জন্যও একই কাজ করুন। অন্য নেটওয়ার্কে পাঠাতে চাইলে USDC [ব্রিজ](./features/bridge-and-withdraw.mdx) করে Base, Ethereum, Arbitrum, Optimism, Polygon বা Avalanche-এ
আপনার নিজের ঠিকানায় পাঠান।
</Step>
<Step>
### এক্সপ্লোরারে যাচাই করুন
এক্সপ্লোরারে (নিচে দেখুন) আপনার ঠিকানা খুলে দেখুন, যে ব্যালান্সগুলো ঠিক জায়গায় পাঠানো হয়েছে কি না।
</Step>
</Steps>

## পর্ব ২: Kawase ছাড়া (আপনার ওয়ালেট এক্সপোর্ট করুন)

আপনার ওয়ালেটের কী আপনার হয়ে **Turnkey** সংরক্ষণ করে। এক্সপোর্ট করলে আপনার নিজের একটি কপি পাবেন, তাই যেকোনো
ওয়ালেটে একই অ্যাকাউন্ট ব্যবহার করতে পারবেন।

<Steps>
<Step>
### এক্সপোর্ট করুন
Settings → **Account** → **Export wallet**। সতর্কবার্তাগুলো পড়ুন, Face ID দিয়ে নিশ্চিত করুন, তারপর Turnkey আপনার ডিভাইসে **রিকভারি
ফ্রেজ** ডিক্রিপ্ট করবে। এটি দেখানোর সময় স্ক্রিনশট ও স্ক্রিন রেকর্ডিং বন্ধ থাকবে, আর আপনি পেজ ছেড়ে গেলে এটি লুকিয়ে যাবে। এটি অফলাইনে নিরাপদ
কোনো জায়গায় লিখে রাখুন। যার কাছে এটি থাকবে, সে আপনার টাকা নিয়ন্ত্রণ করতে পারবে।
</Step>
<Step>
### অন্য ওয়ালেটে ইমপোর্ট করুন
MetaMask, Rabby বা কাস্টম নেটওয়ার্ক সমর্থন করে—এমন অন্য কোনো ওয়ালেটে রিকভারি ফ্রেজ ইমপোর্ট করার অপশন বেছে নিন। Kawase-এ থাকা **একই
ঠিকানা** পাবেন।
</Step>
<Step>
### Arc যোগ করুন
নিচের টেবিলের তথ্য ব্যবহার করে নেটওয়ার্ক যোগ করুন। আপনার ব্যালান্স অন-চেইনে যেমন আছে, তেমনই দেখা যাবে।
</Step>
<Step>
### আপনার টাকা সরান
অন্য যেকোনো ওয়ালেট থেকে যেভাবে পাঠাতেন, সেভাবেই এই ওয়ালেট থেকে পাঠান। ভল্ট, Aave এবং মার্জিন পজিশনগুলো ওই
প্রোটোকলগুলোতে আপনার নিজের অ্যাকাউন্টে থাকে। তাই Arc-এ সেগুলোর জন্য যেকোনো ইন্টারফেস ব্যবহার করে সেগুলো পরিচালনা করতে পারবেন।
</Step>
</Steps>

আপনি নিয়ন্ত্রণ করেন—এমন একটি কপি চাইলে Kawase চালু থাকা অবস্থায় এক্সপোর্ট করুন: এক্সপোর্টটি অ্যাপের মাধ্যমে সম্পন্ন হয়।

## এক্সপ্লোরারে সবকিছু যাচাই করুন

আপনার টাকা দেখতে Kawase-এর প্রয়োজন নেই। Arc-এর ব্লক এক্সপ্লোরারে আপনার ঠিকানা খুলুন:

- মেইননেট: `https://explorer.arc.io/address/<your address>`
- টেস্টনেট: `https://testnet.arcscan.app/address/<your address>`

সেখানে আপনি দেখতে পারবেন:

- আপনার ব্যালান্স (Arc-এ USDC নেটওয়ার্কের গ্যাস টোকেনও: একটি ব্যালান্সই নেটিভ কয়েন এবং USDC
  টোকেন—দুইভাবেই দেখানো হয়);
- সব লেনদেন, যার মধ্যে আপনার allowance-এর অধীনে এজেন্ট করা পেমেন্টও রয়েছে;
- আপনার অ্যাকাউন্টের **কোড**: সেটআপের পর এটি `0xef0100`, এরপর `EIP7702StatelessDeleGator` ঠিকানা। এটিই
  EIP-7702 আপগ্রেড; আপনার অ্যাকাউন্ট স্বাভাবিক অ্যাকাউন্টের মতোই কাজ করে।

Kawase-এর রসিদগুলোও একই পেজে যাওয়ার লিংক দেয়।

## Kawase আর না থাকলে

- **এজেন্টের অনুমতিগুলো আর কাজে লাগবে না।** আপনার allowance এবং অটোমেশনের অনুমতিগুলো শুধু Kawase-এর নিজস্ব এজেন্ট
  ওয়ালেট ব্যবহার করতে পারে, আর এগুলোর মেয়াদ শেষ হয়ে যায়: allowance-এর 90 দিন পর, এবং প্রতিটি অটোমেশনের নির্ধারিত শেষ তারিখে।
- **আপনার টাকা আপনার অ্যাকাউন্টেই থাকবে।** এটি Arc-এ থাকা একটি সাধারণ অ্যাকাউন্ট।
- **এক্সপোর্ট করা রিকভারি ফ্রেজ** (পর্ব ২) থাকলে Arc সমর্থন করে—এমন যেকোনো ওয়ালেট থেকে সব টাকা সরাতে পারবেন।

## EIP-7702 আপগ্রেড সরানো (ঐচ্ছিক)

আপনার টাকা সরাতে আপগ্রেডটি বাতিল করার প্রয়োজন নেই। এক্সপোর্ট করার পর আবার সাধারণ অ্যাকাউন্ট চাইলে, শূন্য ঠিকানার দিকে নির্দেশ করা একটি
EIP-7702 অনুমতিতে সই করুন এবং অ্যাকাউন্টটি থেকেই সেটি পাঠান, যেমন viem ব্যবহার করে:

```ts
import { zeroAddress } from "viem";

const authorization = await walletClient.signAuthorization({ contractAddress: zeroAddress, executor: "self" });
await walletClient.sendTransaction({ to: walletClient.account.address, authorizationList: [authorization] });
```

এরপর এক্সপ্লোরারে আপনার ঠিকানায় কোনো কোড দেখা যাবে না।
