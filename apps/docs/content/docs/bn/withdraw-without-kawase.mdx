Kawase কখনও আপনার টাকা নিজের কাছে রাখে না। আপনার USDC ও EURC Arc-এ **আপনার নিজের অ্যাকাউন্টে** থাকে। এজেন্টকে দেওয়া অনুমতিগুলো সীমিত এবং নিজে থেকেই মেয়াদ শেষ হয়ে যায়। এই পেজে Kawase-এর সাহায্যে বা সাহায্য ছাড়াই কীভাবে টাকা বের করবেন, তা জানানো হয়েছে।

## Kawase চালু থাকা অবস্থায়: টাকা বাইরে পাঠান

সবচেয়ে দ্রুত টাকা বের করার উপায় হলো সাধারণ পেমেন্ট:

<Steps>
<Step>
### কোথায় যাবে তা বেছে নিন
অন্য কোনো ওয়ালেটে (MetaMask, Rabby, …) থাকা আপনার নিয়ন্ত্রণাধীন ঠিকানা, যেখানে **Arc** যোগ করা আছে। অথবা কোনো এক্সচেঞ্জের **Arc** ডিপোজিট ঠিকানা ব্যবহার করুন। নেটওয়ার্কটি Arc কি না দেখে নিন। অন্য নেটওয়ার্কের ঠিকানায় টাকা পাঠানো একই বিষয় নয়।
</Step>
<Step>
### সব টাকা পাঠান
বলুন, "আমার সব USDC 0x…-এ পাঠাও" (একই মেসেজে ঠিকানাটি পেস্ট করুন) অথবা টাকা পাঠানোর স্ক্রিন ব্যবহার করুন। বেশি পরিমাণের জন্য আপনার
Face ID চাইতে পারে। EURC-এর জন্যও একই কাজ করুন।
</Step>
<Step>
### এজেন্টের অনুমতি বাতিল করুন
ওয়ালেট ও সীমা → **বাতিল করুন** (চেপে ধরে রাখুন)। যেকোনো অটোমেশন বাতিল করুন; প্রতিটি বাতিলের মাধ্যমে চেইনে দেওয়া অনুমতিও বাতিল হয়ে যায়।
</Step>
</Steps>

[ব্রিজ](./features/bridge-and-withdraw.mdx) ব্যবহার করে USDC সরাসরি Base, Ethereum, Arbitrum, Optimism, Polygon বা Avalanche-এ থাকা **আপনার নিজের ঠিকানায়** পাঠানো যায়।

## এক্সপ্লোরারে সবকিছু দেখুন

আপনার টাকা দেখতে Kawase-এর দরকার নেই। Arc-এর ব্লক এক্সপ্লোরারে আপনার ঠিকানা খুলুন:

- মেইননেট: `https://explorer.arc.io/address/<your address>`
- টেস্টনেট: `https://testnet.arcscan.app/address/<your address>`

সেখানে আপনি দেখতে পারবেন:

- আপনার **USDC** ও **EURC** ব্যালান্স (Arc-এ USDC নেটওয়ার্কের গ্যাস টোকেনও। তাই একটি ব্যালান্সই নেটিভ কয়েন এবং USDC টোকেন—দুইভাবেই দেখানো হয়),
- প্রতিটি লেনদেন, যার মধ্যে আপনার অনুমতির আওতায় এজেন্টের করা পেমেন্টও আছে,
- আপনার অ্যাকাউন্টের **কোড**: সেটআপের পর এটি `0xef0100`-এর সঙ্গে `EIP7702StatelessDeleGator` ঠিকানা যুক্ত থাকে। এটিই
  EIP-7702 আপগ্রেড; আপনার অ্যাকাউন্ট স্বাভাবিক অ্যাকাউন্ট হিসেবেই কাজ করে।

Kawase-এর রসিদগুলোও একই পেজের লিংক দেয়।

## Kawase আর না থাকলে

- **এজেন্টের অনুমতিগুলো আর কাজে লাগবে না।** আপনার অনুমতি ও অটোমেশনের অনুমতিগুলো শুধু Kawase-এর নিজের এজেন্ট ওয়ালেট ব্যবহার করতে পারে। এগুলোর মেয়াদও শেষ হয়ে যায় (অনুমতির মেয়াদ 90 দিন পর, আর প্রতিটি অটোমেশনের মেয়াদ তার নির্ধারিত শেষ তারিখে)।
- **আপনার টাকা আপনার অ্যাকাউন্টেই থাকবে।** এটি Arc-এ থাকা একটি সাধারণ অ্যাকাউন্ট, যার কী আপনার হয়ে Turnkey ধরে রাখে।
- **ওয়ালেট এক্সপোর্ট (শিগগিরই আসছে)।** সেটিংস → অ্যাকাউন্ট → ওয়ালেট এক্সপোর্ট অপশনে Face ID এবং স্পষ্ট সতর্কবার্তা দেখার পর Turnkey-এর নিরাপদ এক্সপোর্টের মাধ্যমে আপনার ওয়ালেটের কী দেখানো হবে। এটি ব্যবহার করে Arc সমর্থন করে এমন যেকোনো ওয়ালেটে অ্যাকাউন্ট ইমপোর্ট করে Kawase ছাড়াই টাকা সরাতে পারবেন। এই অপশনটি **এখনও চালু হয়নি**; ততক্ষণ পর্যন্ত উপরের ধাপগুলোই টাকা বের করার উপায়।

## EIP-7702 আপগ্রেড সরানো (ঐচ্ছিক)

টাকা সরাতে আপগ্রেডটি বাতিল করার দরকার নেই। এক্সপোর্ট করার পর আবার সাধারণ অ্যাকাউন্ট ব্যবহার করতে চাইলে, শূন্য ঠিকানার দিকে নির্দেশ করা একটি
EIP-7702 অনুমোদনে সই করুন এবং অ্যাকাউন্টটি থেকেই সেটি পাঠান। উদাহরণস্বরূপ, viem ব্যবহার করে:

```ts
import { zeroAddress } from "viem";

const authorization = await walletClient.signAuthorization({ contractAddress: zeroAddress, executor: "self" });
await walletClient.sendTransaction({ to: walletClient.account.address, authorizationList: [authorization] });
```

এরপর এক্সপ্লোরারে আপনার ঠিকানায় কোনো কোড দেখা যাবে না।
