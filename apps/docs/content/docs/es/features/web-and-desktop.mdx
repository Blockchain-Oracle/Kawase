## Confirmar en la web

Donde un teléfono pide Face ID, la app web envía un **código por email**: escribes los seis dígitos y el pago sale. La voz
también funciona: permite el micrófono cuando el navegador lo pida. Si lo rechazas, Kawase te dice cómo permitirlo, y el
teclado está ahí mismo.

## Instalarla

Kawase es una app web instalable. En Chrome o Edge usa **Instalar**; en Safari, **Añadir al Dock** (Mac) o **Añadir a
pantalla de inicio** (iPhone). Si se cae la red, una página sin conexión lo indica en lugar de una pantalla rota. Kawase nunca
guarda los saldos en caché, así que nunca se muestra nada antiguo como dinero actual.
