**x402** es un estándar abierto para pagar una solicitud web con stablecoins: el servicio responde «402 Payment Required»,
el cliente paga en USDC y recibe el resultado. Kawase lo usa para **comprar respuestas por ti**: búsquedas web y noticias,
cuotas de mercados de predicción, rendimientos y precios de DefiLlama, precios de acciones y enriquecimiento de datos, desde el **catálogo x402 de Circle** en Arc.

## Tu billetera del agente

Las compras nunca salen directamente de tu billetera principal. Kawase tiene una **billetera del agente** separada para ti
y solo puede gastar lo que deposites:

- **Añade fondos** desde tu billetera de Kawase con un importe predeterminado. La primera recarga requiere firmar una **autorización limitada para el marketplace** con Face ID;
  las siguientes no necesitan confirmación, siempre dentro de ese límite. También puedes añadir fondos con **Apple Pay o una tarjeta** mediante Onramp de Circle, directamente
  en la billetera del agente.
- El saldo se divide entre **Circle Gateway** (listo para nanopagos, que aceptan la mayoría de los vendedores) y una parte **disponible**
  para vendedores que aceptan USDC normal (EIP-3009). Cuando una compra con USDC normal necesita más saldo disponible, Kawase lo repone desde
  Gateway.
- **Devolver a mi billetera** envía ambas partes de vuelta en cualquier momento.

Ajustes → **Billetera del agente** muestra el saldo, lo gastado hoy, la dirección y el historial completo de compras
y movimientos.

## Presupuestos que estableces

- un **presupuesto diario** y un **límite por llamada**;
- **preguntarme primero** por encima del límite: la compra espera tu consentimiento en una tarjeta dentro del chat;
- las **categorías** en las que Kawase puede comprar;
- **vendedores bloqueados**: toca cualquier compra para bloquear a su vendedor.

Los límites más estrictos se aplican de inmediato; para ampliarlos, se requiere Face ID. Si una compra se rechaza, se indica la regla que la detuvo.

## Cada compra queda registrada

El chat muestra lo que encontró Kawase (la marca del vendedor, lo que devuelve y el precio). Después de pagar, muestra un recibo: «Pagado 0.002
USDC a …». La respuesta del vendedor aparece marcada como **no verificada**. x402 todavía no tiene un estándar de reembolso: si una llamada falla después del pago,
el recibo indica que el vendedor se quedó con el importe; si Circle informa que un pago falló, aparece marcado como **no cobrado**. Kawase trata el texto externo como datos, nunca como instrucciones, y
lo indica cuando una respuesta intenta decirle qué hacer.

## Redes

- **Red principal**: el catálogo de Circle (unas 2,100 opciones en Arc), con pagos mediante ambos métodos.
- **Red de pruebas**: el catálogo de Circle no tiene opciones en la red de pruebas, así que Kawase usa su propio vendedor de demostración (`seller.getkawase.xyz`) para
  probarlo de principio a fin con Dinero de prueba.
