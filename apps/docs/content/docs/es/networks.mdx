**Arc** es la red de stablecoins de Circle: USDC es su token de gas, así que las comisiones se pagan en dólares y las transacciones se liquidan en menos de un segundo. Kawase admite exactamente dos redes de Arc.

| | Red principal de Arc | Red de pruebas de Arc |

| ID de cadena | `5042` | `5042002` |

| Cómo conseguir dinero | Recibe dinero de cualquier billetera o exchange que envíe a Arc; próximamente podrás comprar con Apple Pay o tarjeta | El faucet integrado (aproximadamente 20 USDC + 20 EURC al día) |

## Cómo Kawase mantiene separadas las redes

- **Puedes cambiar con un toque**, en ambos sentidos: consulta [el selector de red](./features/network-toggle.mdx).
- **La red se muestra de tres formas**: la pastilla del encabezado, la franja de red de pruebas o la etiqueta DINERO REAL, y el color de la esfera.
- **El servidor controla la elección.** Cada pago se prepara para una red y se mantiene en ella hasta el final; si la red cambia mientras tanto, el pago se detiene en lugar de pasar a la otra red.
- **Una sola dirección de billetera en ambas redes**, con saldos, actividad y límites independientes para cada red.
