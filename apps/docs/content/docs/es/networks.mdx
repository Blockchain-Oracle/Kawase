**Arc** es la red de stablecoins de Circle: USDC es su token de gas, así que las comisiones se pagan en dólares y las transacciones se liquidan en menos de
un segundo. Kawase admite exactamente dos redes de Arc.

| | Red principal de Arc | Red de pruebas de Arc |
|---|---|---|
| Dinero | Dinero real | Dinero de prueba sin valor |
| ID de cadena | `5042` | `5042002` |
| Explorador | `explorer.arc.io` | `explorer.testnet.arc.io` |
| Cómo obtener dinero | Comprar con tarjeta mediante el Onramp de Circle; recibir desde cualquier wallet o exchange que envíe a Arc | El faucet integrado en la app (aproximadamente 20 USDC + 20 EURC al día); el sandbox del Onramp de Circle con tarjetas de prueba |

## Cómo Kawase las mantiene separadas

- **Un toque para cambiar**, en ambos sentidos: consulta [el selector de red](./features/network-toggle.mdx).
- **La red se muestra de tres formas**: la etiqueta del encabezado, la franja de la red de pruebas o la etiqueta DINERO REAL, y el color del orbe.
- **El servidor controla la elección.** Cada pago se prepara para una red y la mantiene hasta el final; si la red
  cambia mientras tanto, el pago se detiene en lugar de pasar a la otra red.
- **Una dirección de wallet en ambas redes**, con saldos, actividad y límites independientes para cada red.
