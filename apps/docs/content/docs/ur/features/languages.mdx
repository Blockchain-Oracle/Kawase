Kawase ایپ میں ہر جگہ دنیا کی سب سے زیادہ بولی جانے والی زبانیں پیش کرتا ہے:

| زبان | زبان میں نام | سمت |
|---|---|---|
| انگریزی | English | بائیں سے دائیں |
| چینی | 中文 | بائیں سے دائیں |
| ہندی | हिन्दी | بائیں سے دائیں |
| ہسپانوی | Español | بائیں سے دائیں |
| فرانسیسی | Français | بائیں سے دائیں |
| عربی | العربية | **دائیں سے بائیں** |
| بنگالی | বাংলা | بائیں سے دائیں |
| پرتگالی | Português | بائیں سے دائیں |
| روسی | Русский | بائیں سے دائیں |
| اردو | اردو | **دائیں سے بائیں** |

- **پہلی اسکرین سے۔** زبان کا بٹن پہلے آن بورڈنگ پینل اور اس کے بعد ہر اسکرین پر موجود ہے؛ زبان بدلتے ہی سمت بھی فوراً بدل جاتی ہے۔
- **ہر زبان میں ہر متن۔** ایپ کی دسوں زبانوں کی فہرستیں مکمل ہیں؛ ایجنٹ آپ کی زبان میں جواب دیتا ہے اور [آواز](./voice.mdx) دسوں زبانیں سنتی اور بولتی ہے۔
- **رقمیں بالکل درست رہتی ہیں۔** اعداد آپ کی زبان کے مطابق دکھائے جاتے ہیں، جبکہ رقمیں، پتے اور کوڈز بائیں سے دائیں ہی رہتے ہیں تاکہ انہیں ایک ایک حرف دیکھ کر جانچا جا سکے۔
- **یہ دستاویزات** بھی انہی دس زبانوں میں دستیاب ہیں (سائیڈبار میں زبان بدلنے کا آپشن استعمال کریں)۔
