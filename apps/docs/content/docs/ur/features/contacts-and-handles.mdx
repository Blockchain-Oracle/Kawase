## رابطے

رابطہ ایک نام (اور عرفی ناموں) کے ساتھ ایک یا زیادہ پتے ہوتا ہے۔ Kawase رابطوں کی مدد سے "Alex کو پیسے بھیجنا" سمجھتا ہے اور آپ کی حفاظت کرتا ہے:

- **پتے کی تبدیلی روک دی جاتی ہے۔** جب کسی رابطے کا پتہ تبدیل ہوتا ہے، تو نئے پتے پر پیسے بھیجنے سے پہلے **24 گھنٹے** انتظار کرنا پڑتا ہے، اور اس دوران رابطہ منجمد رہتا ہے۔ تبدیل شدہ پتہ ادائیگی چرانے کا عام طریقہ ہے۔
- **مشابہ پتوں کی نشان دہی کی جاتی ہے۔** جس پتے کے پہلے اور آخری چار حروف آپ کے کسی رابطے کے پتے سے ملتے ہوں، اسے مشابہ پتہ سمجھا جاتا ہے: Kawase رک کر Face ID مانگتا ہے۔
- **ادائیگی کی تاریخ** ہر پتے اور نیٹ ورک کے لیے اعتماد بناتی ہے: کسی پتے پر پہلی ادائیگی کو دہرائی گئی ادائیگی کے مقابلے میں زیادہ احتیاط سے دیکھا جاتا ہے۔

اگر آپ کسی ایسے شخص کا ذکر کریں جسے Kawase نہیں جانتا، تو وہ آپ سے اسے محفوظ کرنے کو کہتا ہے اور پھر اسی ادائیگی کو جاری رکھتا ہے — آپ کو دوبارہ شروع کرنے کی ضرورت نہیں ہوتی۔

## @handles

`@handle` ایک اختیاری عوامی نام ہے جس کے ذریعے آپ کو پیسے بھیجے جا سکتے ہیں: "‏@abu کو 10 بھیجیں"۔ اصول:

- 3 سے 20 حروف: صرف چھوٹے حروف، ہندسے اور انڈر اسکور۔
- بڑے یا چھوٹے حروف سے فرق نہیں پڑتا؛ ایسے نام محفوظ ہیں جو Kawase، Arc، Circle یا عملے کی نقالی کر سکتے ہوں۔
- آپ اسے آن بورڈنگ کے دوران منتخب کر سکتے ہیں (یا چھوڑ سکتے ہیں) اور Settings میں اسے تبدیل کر سکتے ہیں۔

ہینڈل اس شخص کے Kawase والیٹ پتے سے منسلک ہوتا ہے۔ اگر اس شخص نے ابھی والیٹ سیٹ اپ نہیں کیا، تو Kawase اندازہ لگانے کے بجائے آپ کو بتا دیتا ہے۔
