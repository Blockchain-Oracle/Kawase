## ایک دماغ

`packages/agent` میں موجود `agentTurn()` **چیٹ** اور **آواز** دونوں کے لیے کام کرتا ہے: وائس ورکر جو کچھ سنتا ہے، اسے اسی ٹرن کو بھیجتا ہے،
اور وہی ٹولز، حدود اور تھریڈ استعمال ہوتے ہیں۔ ماڈل (بطور ڈیفالٹ OpenAI کا `gpt-5.6-luna`، جسے ماڈل رجسٹری کے ذریعے منتخب کیا جاتا ہے) صرف
**تجویز** کرتا ہے: کوئی ٹول نیٹ ورک، ایڈریس یا "approve" فلیگ خود نہیں لیتا۔ کوڈ وصول کنندہ کا تعین کرتا ہے، پالیسی چلاتا ہے، ٹرانزیکشن بناتا ہے اور اسے مکمل کرتا ہے۔

## خالص پالیسی، واضح ارادے

- `packages/policy` حقائق سے نتائج تک ایک خالص فنکشن ہے۔ نتائج میں غلطیاں، انکار، پیشگی شرائط، وضاحتیں اور انتباہات شامل ہیں،
  ساتھ ہی **طریقہ** بھی: الاؤنس یا والیٹ سگنیچر۔ یہ کارڈ کا ڈرافٹ بناتے وقت، تازہ حقائق کے ساتھ منظوری کے وقت، اور عمل درآمد کے وقت دوبارہ چلتا ہے۔
- `packages/intents` ہر کارروائی کو ورژن والے، EIP-712 سے ہیش کیے گئے **ڈرافٹ** کے طور پر بیان کرتا ہے (`SendDraft`، `SwapDraft`، `BridgeDraft`،
  `EarnDraft`)۔ منظوری میں اسی درست ورژن کا نام ہوتا ہے جس کی منظوری دی گئی ہے؛ تبدیلی سے نیا ورژن بنتا ہے۔
- **تعین کریں اور دوبارہ جاری رکھیں**: جب کوئی چیز موجود نہ ہو، جیسے رابطہ، کرنسی یا سائن اِن، تو اسے ٹھیک کرنے کے بعد وہی ارادہ جاری رہتا ہے،
  دوبارہ شروع نہیں ہوتا۔

## پیسوں کے راستے

- **الاؤنس کے ذریعے بھیجنا**: ہر صارف کے لاک کے تحت خرچ کے لیجر میں رقم ریزرو کی جاتی ہے، پھر Kawase کا ایجنٹ والیٹ (Circle کا
  ڈویلپر کے زیرِ کنٹرول والیٹ) آپ کی اجازت استعمال کرتا ہے؛ رسید کے `Transfer` لاگ کا ڈرافٹ سے موازنہ کیا جاتا ہے۔
- **والیٹ سے سائن کی گئی کارروائیاں** (اوپر دی گئی الاؤنس حد سے زیادہ رقم، سویپس، برج اور منافع): api درست ٹرانزیکشن بناتا ہے — App
  Kit کی کارروائیوں کے لیے kit کی کالز محفوظ اور چیک کی جاتی ہیں، پھر انہیں ایک EIP-7702 سیلف بیچ میں شامل کیا جاتا ہے — ڈیوائس اسے
  Face ID سے سائن کرتی ہے، اور api براڈکاسٹ کرنے سے پہلے سائن کیے گئے بائٹس کا ڈرافٹ سے موازنہ کرتا ہے۔
- **برجز** کو تین مراحل میں ٹریک کیا جاتا ہے: Arc پر برن، Circle کی تصدیق، اور منزل کی چین پر منٹ۔
- **آٹومیشن** api کے رنر میں ہر 30 سیکنڈ بعد چلتی ہیں: ہر بار کی کارروائی صرف ایک مرتبہ کلیم کی جاتی ہے، تازہ حقائق کے ساتھ دوبارہ چیک ہوتی ہے
  اور آٹومیشن کی اپنی گرانٹ کے تحت اسی پیسے بھیجنے، منافع یا برج کے راستے سے ادا ہوتی ہے۔
- **ہر جگہ آئیڈیمپوٹنسی**: Circle کو کال کرنے سے پہلے Circle کی آئیڈیمپوٹنسی کی محفوظ کی محفوظ کی جاتی ہے؛ خام ٹرانزیکشنز کا ہیش براڈکاسٹ سے پہلے محفوظ کیا جاتا ہے؛
  غیر واضح نتائج `unknown_outcome` بن جاتے ہیں اور صرف دوبارہ چیک کیے جاتے ہیں، دوبارہ نہیں بھیجے جاتے۔

## ڈیٹا

**Drizzle کے ساتھ Postgres 17** واحد اسٹور اور واحد میسج بس ہے: ہر تبدیلی کے ساتھ اسی ٹرانزیکشن میں ایک آؤٹ باکس لکھا جاتا ہے،
`pg_notify` کے ذریعے سرور سے بھیجے گئے ایونٹس پھیلائے جاتے ہیں، اور نوٹیفکیشنز کے لیے ان باکس ٹیبل اصل ماخذ ہے۔ رقم درست بنیادی یونٹس
(`numeric(78,0)`، TypeScript میں `bigint`) میں محفوظ ہوتی ہے؛ آئی ڈیز UUIDv7 ہوتی ہیں۔

## مونو ریپو

| حصہ | یہ کیا ہے |
|---|---|
| `apps/api` | Hono API: تصدیق، ایجنٹ چیٹ اسٹریم، ارادے اور منظوری، رنرز، ویب ہُکس |
| `apps/mobile` | Expo 57 / React Native 0.86: iOS، Android اور ویب ایپ |
| `apps/voice-agent` | LiveKit Agents worker (Node) |
| `apps/docs` | یہ سائٹ (Fumadocs 16، Next 16) |
| `apps/landing` | شوکیس اور جج کِٹ |
| `packages/config` | ہر مستقل قدر: حدود، صلاحیتوں کی رجسٹری، لوکیلز، آواز، ٹائم آؤٹس |
| `packages/policy`, `packages/intents` | خالص پالیسی انجن اور EIP-712 ڈرافٹس |
| `packages/integrations/*` | ڈیلیگیشنز (MetaMask Delegation Framework)، Circle App Kit |
| `packages/networks`, `packages/money` | Arc کے دونوں نیٹ ورکس اور تصدیق شدہ ایڈریس؛ رقم کی درست اقسام |
| `packages/identity` | ماخذ کے ثبوت کے ساتھ اصل لوگوز |

## پبلک API

api `https://api.getkawase.xyz` پر موجود ہے۔ عوامی، بغیر تصدیق والے اینڈ پوائنٹس:

| اینڈ پوائنٹ | کیا واپس کرتا ہے |
|---|---|
| `GET /health` | `{ ok, networks }` |
| `GET /capabilities` | ہر نیٹ ورک کے لیے رن ٹائم اووررائیڈز کے ساتھ صلاحیتوں کی رجسٹری |
| `GET /public/stats` | صرف مجموعی تعدادیں (مکمل بھیجائیاں، سویپس، برجز، منافع کی کارروائیاں، آٹومیشن رنز، اکاؤنٹس) |

باقی ہر چیز کے لیے سیشن ضروری ہے (ایپ کا bearer token یا ویب پر cookie)۔

## ہوسٹنگ

سب کچھ Traefik اور Let's Encrypt کے پیچھے ایک **Coolify** سرور پر چلتا ہے: api، ویب ایپ، وائس ورکر، یہ دستاویزات،
شوکیس اور Postgres۔ ہر سروس مونو ریپو کے روٹ سے بنائے گئے Dockerfile پر مشتمل ہے؛ سروسز `::` پر سنتی ہیں
(Coolify کے ہیلتھ چیکس `localhost` کو IPv6 پر حل کرتے ہیں)۔

## ایسے ٹیسٹس جو ثابت کرتے ہیں

Arc ٹیسٹ نیٹ پر اصلی ٹرانزیکشنز کے ساتھ چلائیں (`pnpm --filter @kawase/api test`): پیسے بھیجنا (الاؤنس اور والیٹ سے سائن شدہ،
ڈبل ٹیپ → ایک بار بھیجنا، تبدیل شدہ سگنیچرز کا انکار)، سویپس، برجز (برن → تصدیق → منٹ)، منافع کے ڈپازٹس اور
رقم نکلوانا، شیڈول شدہ آٹومیشن، آٹو سیو، قواعد، اور رکا ہوا رن دوبارہ جاری ہونے کے بعد بحالی۔ ڈیلیگیشن پیکیج
آن چین حدود کو خود ثابت کرتا ہے (`pnpm --filter @kawase/integrations-delegation test:arc-testnet`)۔
