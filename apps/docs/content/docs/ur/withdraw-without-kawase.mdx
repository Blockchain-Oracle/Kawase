Kawase کبھی بھی آپ کی رقم اپنے پاس نہیں رکھتا۔ آپ کے ٹوکنز Arc پر **آپ کے اپنے اکاؤنٹ** میں رہتے ہیں، اور آپ نے ایجنٹ کو جو اجازتیں دی ہیں وہ
محدود ہوتی ہیں اور خود بخود ختم ہو جاتی ہیں۔ یہ رہنمائی آپ کو مرحلہ وار رقم نکالنے کا طریقہ بتاتی ہے: پہلے Kawase کی مدد سے، پھر اس کے بغیر۔

<Status ids="export_wallet" />

## شروع کرنے سے پہلے

اپنے والیٹ میں موجود وہ چیزیں پہلے سنبھال لیں جو ابھی عام رقم نہیں ہیں:

- **سیونگز** کسی والٹ میں ہیں: انہیں Earn اسکرین سے نکالیں۔
- **Aave V4** میں سپلائی یا قرض ہے: Borrow اسکرین سے قرض واپس کریں اور رقم نکالیں۔
- **لانگ یا شارٹ** پوزیشنز: ہر پوزیشن کے صفحے پر انہیں بند کریں (Close · All)۔
- **ایجنٹ والیٹ**: Settings → Agent wallet → **Return to my wallet**۔
- USDC اور EURC کے علاوہ ٹوکنز: انہیں USDC میں ٹریڈ کریں، یا اپنا والیٹ ایکسپورٹ کریں (حصہ 2) اور کسی بھی والیٹ سے منتقل کریں۔

## حصہ 1: Kawase کے ساتھ (ایگزٹ کٹ)

<Steps>
<Step>
### ایجنٹ کو روکیں
Settings → **Wallet & limits** → **Pause all**۔ ایجنٹ کی طرف سے بغیر پوچھے ہونے والے تمام کام فوراً رک جاتے ہیں۔ آپ کی اپنی Face ID
سے ہونے والی ادائیگیاں پھر بھی کام کرتی رہیں گی۔
</Step>
<Step>
### ہر اجازت واپس لیں
ایگزٹ کٹ میں **واپس لینے کے لیے دبائے رکھیں**۔ ایک Face ID سے ایک ٹرانزیکشن بھیجی جاتی ہے جو اس نیٹ ورک پر دی گئی ہر اجازت واپس لے لیتی ہے: آپ کی
الاؤنس اور ہر آٹومیشن کی اجازت۔ آٹومیشن ختم ہو جاتی ہیں۔ اگر آپ نے دوسرا نیٹ ورک بھی استعمال کیا ہے تو وہاں بھی یہ عمل دہرائیں۔
</Step>
<Step>
### رقم بھیجنے کی جگہ منتخب کریں
کسی دوسرے والیٹ (MetaMask، Rabby، …) میں موجود ایسا پتہ جسے آپ کنٹرول کرتے ہوں اور جس میں **Arc** شامل ہو، یا کسی ایکسچینج کا **Arc** ڈپازٹ پتہ۔
یقین کریں کہ نیٹ ورک Arc ہے؛ کسی دوسرے نیٹ ورک کا پتہ وہی چیز نہیں ہے۔
</Step>
<Step>
### سب کچھ بھیجیں
کہیں: "میرے تمام USDC کو 0x… پر بھیجیں" (پتہ اسی پیغام میں پیسٹ کریں)، یا پیسے بھیجنے کی اسکرین استعمال کریں اور Face ID سے تصدیق کریں۔
EURC کے لیے بھی یہی عمل دہرائیں۔ اگر رقم کسی دوسرے نیٹ ورک پر بھیجنی ہو تو USDC کو Base، Ethereum، Arbitrum، Optimism، Polygon یا Avalanche پر اپنے
پتے پر [برج کریں](./features/bridge-and-withdraw.mdx)۔
</Step>
<Step>
### ایکسپلورر چیک کریں
اپنا پتہ ایکسپلورر پر کھولیں (نیچے دیا گیا ہے) اور تصدیق کریں کہ بیلنس اسی جگہ موجود ہیں جہاں آپ نے بھیجے تھے۔
</Step>
</Steps>

## حصہ 2: Kawase کے بغیر (اپنا والیٹ ایکسپورٹ کریں)

آپ کے والیٹ کی کلید **Turnkey** آپ کی طرف سے محفوظ رکھتا ہے۔ ایکسپورٹ کرنے سے آپ کے پاس اس کی اپنی کاپی آ جاتی ہے، اس لیے آپ یہی اکاؤنٹ کسی بھی
والیٹ میں استعمال کر سکتے ہیں۔

<Steps>
<Step>
### ایکسپورٹ کریں
Settings → **Account** → **Export wallet**۔ انتباہات پڑھیں، Face ID سے تصدیق کریں، اور Turnkey آپ کے آلے پر آپ کا **ریکوری
فریز** ڈی کرپٹ کر دے گا۔ اسے دکھاتے وقت اسکرین شاٹس اور اسکرین ریکارڈنگ بند رہتی ہے، اور آپ کے وہاں سے نکلتے ہی یہ چھپ جاتا ہے۔ اسے محفوظ جگہ پر
آف لائن لکھ کر رکھیں۔ جس کے پاس یہ ہو، وہ آپ کی رقم کنٹرول کر سکتا ہے۔
</Step>
<Step>
### اسے کسی دوسرے والیٹ میں امپورٹ کریں
MetaMask، Rabby یا کسی ایسے دوسرے والیٹ میں جو کسٹم نیٹ ورکس کی اجازت دیتا ہو، ریکوری فریز امپورٹ کرنے کا اختیار منتخب کریں۔ آپ کو Kawase والا **وہی
پتہ** ملے گا۔
</Step>
<Step>
### Arc شامل کریں
نیچے دی گئی جدول میں موجود تفصیلات کے ساتھ نیٹ ورک شامل کریں۔ آپ کے بیلنس ویسے ہی دکھائی دیں گے جیسے وہ بلاک چین پر ہیں۔
</Step>
<Step>
### اپنی رقم منتقل کریں
اس والیٹ سے اسی طرح رقم بھیجیں جیسے کسی دوسرے والیٹ سے بھیجتے ہیں۔ والٹ، Aave اور مارجن پوزیشنز ان پروٹوکولز میں آپ کے اپنے اکاؤنٹ میں موجود ہوتی ہیں، اس لیے
Arc پر ان کے لیے موجود کوئی بھی انٹرفیس انہیں مینیج کر سکتا ہے۔
</Step>
</Steps>

اگر آپ اپنے کنٹرول میں ایک کاپی رکھنا چاہتے ہیں تو Kawase کے چلتے ہوئے والیٹ ایکسپورٹ کریں: ایکسپورٹ ایپ کے ذریعے ہوتا ہے۔

## ایکسپلورر پر سب کچھ چیک کریں

اپنی رقم دیکھنے کے لیے آپ کو Kawase کی ضرورت نہیں ہے۔ اپنا پتہ Arc کے بلاک ایکسپلورر پر کھولیں:

- مین نیٹ: `https://explorer.arc.io/address/<your address>`
- ٹیسٹ نیٹ: `https://testnet.arcscan.app/address/<your address>`

وہاں آپ یہ چیزیں دیکھ سکتے ہیں:

- اپنے بیلنس (Arc پر USDC نیٹ ورک کا گیس ٹوکن بھی ہے: ایک ہی بیلنس مقامی کوائن اور USDC ٹوکن، دونوں کے طور پر دکھایا جاتا ہے)؛
- ہر ٹرانزیکشن، بشمول وہ ادائیگیاں جو ایجنٹ نے آپ کی الاؤنس کے تحت کیں؛
- اپنے اکاؤنٹ کا **کوڈ**: سیٹ اپ کے بعد یہ `0xef0100` کے بعد `EIP7702StatelessDeleGator` کا پتہ ہوتا ہے۔ یہ
  EIP-7702 اپ گریڈ ہے؛ آپ کا اکاؤنٹ اب بھی عام اکاؤنٹ کی طرح کام کرتا ہے۔

Kawase کی رسیدوں میں بھی انہی صفحات کے لنکس ہوتے ہیں۔

## اگر Kawase ختم ہو جائے

- **ایجنٹ کی اجازتیں بےکار ہو جاتی ہیں۔** آپ کی الاؤنس اور آٹومیشن کی اجازتیں صرف Kawase کے اپنے ایجنٹ والیٹ کے ذریعے استعمال ہو سکتی ہیں، اور یہ ختم ہو جاتی ہیں:
  الاؤنس 90 دن بعد، اور ہر آٹومیشن اپنی اختتامی تاریخ پر۔
- **آپ کی رقم آپ کے اکاؤنٹ میں رہتی ہے۔** یہ Arc پر ایک عام اکاؤنٹ ہے۔
- **ایکسپورٹ کیے گئے ریکوری فریز** (حصہ 2) کے ساتھ آپ Arc کو سپورٹ کرنے والے کسی بھی والیٹ سے سب کچھ منتقل کر سکتے ہیں۔

## EIP-7702 اپ گریڈ ہٹانا (اختیاری)

اپنی رقم منتقل کرنے کے لیے اپ گریڈ واپس کرنا ضروری نہیں ہے۔ اگر آپ والیٹ ایکسپورٹ کرنے کے بعد دوبارہ ایک عام اکاؤنٹ چاہتے ہیں تو زیرو ایڈریس کی طرف اشارہ کرنے والی
EIP-7702 اجازت پر دستخط کریں اور اسے خود اکاؤنٹ سے بھیجیں، مثلاً viem کے ذریعے:

```ts
import { zeroAddress } from "viem";

const authorization = await walletClient.signAuthorization({ contractAddress: zeroAddress, executor: "self" });
await walletClient.sendTransaction({ to: walletClient.account.address, authorizationList: [authorization] });
```

اس کے بعد ایکسپلورر آپ کے پتے پر کوئی کوڈ نہیں دکھائے گا۔
