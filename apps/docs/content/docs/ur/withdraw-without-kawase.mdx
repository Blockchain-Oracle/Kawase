Kawase آپ کی رقم کبھی اپنے پاس نہیں رکھتا۔ آپ کے USDC اور EURC **آپ کے اپنے اکاؤنٹ** میں Arc پر موجود رہتے ہیں، اور ایجنٹ کو دی گئی
اجازتیں محدود ہوتی ہیں اور خود ختم ہو جاتی ہیں۔ یہ صفحہ بتاتا ہے کہ اپنی رقم کیسے نکالیں — Kawase کی مدد سے بھی، اور اس کے بغیر بھی۔

## جب Kawase چل رہا ہو: رقم باہر بھیجیں

سب سے تیز طریقہ عام ادائیگی ہے:

<Steps>
<Step>
### رقم کہاں بھیجنی ہے، منتخب کریں
کسی دوسرے والیٹ (MetaMask، Rabby، …) میں موجود ایسا ایڈریس جسے آپ کنٹرول کرتے ہوں اور جس میں **Arc** شامل ہو، یا کسی ایکسچینج کا **Arc** ڈپازٹ
ایڈریس۔ چیک کریں کہ نیٹ ورک Arc ہے؛ کسی دوسرے نیٹ ورک کے ایڈریس پر رقم بھیجنا الگ بات ہے۔
</Step>
<Step>
### سب کچھ بھیجیں
کہیں: "میرے تمام USDC کو 0x… پر بھیج دو" (اسی پیغام میں ایڈریس پیسٹ کریں) یا پیسے بھیجنے والی اسکرین استعمال کریں۔ زیادہ رقم کے لیے
Face ID مانگی جا سکتی ہے۔ EURC کے لیے بھی یہی عمل دہرائیں۔
</Step>
<Step>
### ایجنٹ کی اجازت منسوخ کریں
والیٹ اور حدود → **منسوخ کریں** (دبا کر رکھیں)۔ تمام آٹومیشن منسوخ کریں؛ ہر منسوخی آن چین اس کی اجازت ختم کر دیتی ہے۔
</Step>
</Steps>

USDC کو Base، Ethereum، Arbitrum، Optimism، Polygon یا Avalanche پر **اپنے ہی ایڈریس** پر بھی براہِ راست ایک
[برج](./features/bridge-and-withdraw.mdx) کے ذریعے بھیجا جا سکتا ہے۔

## ایکسپلورر پر سب کچھ چیک کریں

اپنی رقم دیکھنے کے لیے آپ کو Kawase کی ضرورت نہیں۔ Arc کے بلاک ایکسپلورر پر اپنا ایڈریس کھولیں:

- مین نیٹ: `https://explorer.arc.io/address/<your address>`
- ٹیسٹ نیٹ: `https://testnet.arcscan.app/address/<your address>`

وہاں آپ یہ چیزیں دیکھ سکتے ہیں:

- اپنے **USDC** اور **EURC** کے بیلنس (Arc پر USDC نیٹ ورک کا گیس ٹوکن بھی ہے: ایک ہی بیلنس مقامی
  کوائن اور USDC ٹوکن، دونوں کے طور پر دکھایا جاتا ہے)،
- ہر ٹرانزیکشن، بشمول وہ ادائیگیاں جو ایجنٹ نے آپ کی مقرر کردہ حد کے اندر کی ہوں،
- آپ کے اکاؤنٹ کا **کوڈ**: سیٹ اپ کے بعد یہ `0xef0100` اور اس کے بعد `EIP7702StatelessDeleGator` ایڈریس ہوتا ہے۔ یہ
  EIP-7702 اپ گریڈ ہے؛ آپ کا اکاؤنٹ اب بھی عام اکاؤنٹ کی طرح کام کرتا ہے۔

Kawase کی رسیدوں میں بھی انہی صفحات کے لنکس ہوتے ہیں۔

## اگر Kawase دستیاب نہ رہے

- **ایجنٹ کی اجازتیں بےکار ہو جائیں گی۔** آپ کی مقرر کردہ حد اور آٹومیشن کی اجازتیں صرف Kawase کے اپنے ایجنٹ
  والیٹ کے ذریعے استعمال ہو سکتی ہیں، اور یہ ختم ہو جاتی ہیں (حد 90 دن بعد، اور ہر آٹومیشن اپنی اختتامی تاریخ پر)۔
- **آپ کی رقم آپ کے اکاؤنٹ میں رہے گی۔** یہ Arc پر ایک عام اکاؤنٹ ہے، جس کی کلید Turnkey آپ کی طرف سے محفوظ رکھتا ہے۔
- **والیٹ ایکسپورٹ کریں (جلد دستیاب ہوگا)۔** Settings → Account → Export wallet میں Face ID اور واضح انتباہات کے بعد
  Turnkey کے محفوظ ایکسپورٹ کے ذریعے آپ کے والیٹ کی کلید دکھائی جائے گی۔ اس کلید سے آپ اکاؤنٹ کو Arc کو سپورٹ کرنے والے کسی بھی
  والیٹ میں درآمد کر کے اپنی رقم Kawase کے بغیر منتقل کر سکتے ہیں۔ یہ آپشن **ابھی دستیاب نہیں**؛ اس وقت تک اوپر دیے گئے طریقے ہی رقم نکالنے کا راستہ ہیں۔

| | مین نیٹ | ٹیسٹ نیٹ |
|---|---|---|
| نیٹ ورک کا نام | Arc | Arc ٹیسٹ نیٹ |
| چین ID | `5042` | `5042002` |
| RPC | `https://rpc.mainnet.arc.io` | `https://rpc.testnet.arc.io` |
| کرنسی کی علامت | USDC | USDC |
| ایکسپلورر | `https://explorer.arc.io` | `https://explorer.testnet.arc.io` |

کچھ والیٹ کسٹم نیٹ ورکس پر گیس بیلنس کو "ETH" کے نام سے دکھاتے ہیں؛ Arc پر یہ USDC ہے۔ USDC ٹوکن کا ایڈریس
دونوں نیٹ ورکس پر `0x3600000000000000000000000000000000000000` ہے؛ مین نیٹ پر EURC کا ایڈریس
`0xbEf5f6d51CB62b58e6A8f77868681825C6fe21c1` اور ٹیسٹ نیٹ پر
`0x89B50855Aa3bE2F677cD6303Cec089B5F319D72a` ہے۔

## EIP-7702 اپ گریڈ ہٹانا (اختیاری)

اپنی رقم منتقل کرنے کے لیے اپ گریڈ واپس کرنا ضروری نہیں۔ اگر ایکسپورٹ کرنے کے بعد آپ دوبارہ عام اکاؤنٹ چاہتے ہیں تو صفر ایڈریس کی طرف اشارہ کرنے والی
EIP-7702 اجازت پر دستخط کریں اور اسے خود اکاؤنٹ سے بھیجیں، مثلاً viem کے ذریعے:

```ts
import { zeroAddress } from "viem";

const authorization = await walletClient.signAuthorization({ contractAddress: zeroAddress, executor: "self" });
await walletClient.sendTransaction({ to: walletClient.account.address, authorizationList: [authorization] });
```

اس کے بعد ایکسپلورر آپ کے ایڈریس پر کوئی کوڈ نہیں دکھائے گا۔
