Kawase کبھی بھی آپ کی رقم اپنے پاس نہیں رکھتا۔ آپ کے ٹوکن Arc پر **آپ کے اپنے اکاؤنٹ** میں رہتے ہیں، اور ایجنٹ کو دی گئی اجازتیں
محدود ہوتی ہیں اور خود ختم ہو جاتی ہیں۔ یہ رہنمائی آپ کو قدم بہ قدم رقم نکالنے کا طریقہ بتاتی ہے: پہلے Kawase کی مدد سے، پھر اس کے بغیر۔

<Status ids="export_wallet" />

## شروع کرنے سے پہلے

اپنے والٹ میں موجود وہ چیزیں تیار کریں جو ابھی عام رقم نہیں ہیں:

- **سیونگز** کسی والٹ میں ہیں: Earn اسکرین پر جا کر انہیں نکلوائیں۔
- **Aave V4** میں سپلائی یا قرض: Borrow اسکرین پر قرض واپس کریں اور رقم نکلوائیں۔
- **لانگ یا شارٹ** پوزیشنز: ہر پوزیشن کے صفحے پر انہیں بند کریں (Close · All)۔
- **ایجنٹ والٹ**: Settings → Agent wallet → **میرے والٹ میں واپس کریں**۔
- کوئی بھی دوسرا ٹوکن Arc پر Withdraw کے ذریعے اسی شکل میں باہر بھیجا جا سکتا ہے، یا کسی دوسری چین پر بھیجنے کے لیے USDC میں تبدیل کیا جا سکتا ہے۔

## حصہ 1: Kawase کے ساتھ (ایگزٹ کٹ)

<Steps>
<Step>
### ایجنٹ کو روکیں
Settings → **والٹ اور حدود** → **سب کو روکیں**۔ ایجنٹ کی طرف سے بغیر پوچھے ہونے والا ہر کام فوراً رک جاتا ہے۔ آپ کی اپنی Face ID
سے ہونے والی ادائیگیاں پھر بھی جاری رہتی ہیں۔
</Step>
<Step>
### ہر اجازت منسوخ کریں
ایگزٹ کٹ میں **منسوخ کرنے کے لیے دبائے رکھیں**۔ ایک Face ID سے ایک ٹرانزیکشن بھیجی جاتی ہے جو اس نیٹ ورک پر دی گئی ہر اجازت منسوخ کر دیتی ہے: آپ کی
الاؤنس اور ہر آٹومیشن کی اجازت۔ آٹومیشن ختم ہو جاتی ہیں۔ اگر آپ نے دوسرا نیٹ ورک بھی استعمال کیا ہے تو وہاں بھی یہی عمل دہرائیں۔
</Step>
<Step>
### سب کچھ نکلوائیں
ایگزٹ کٹ میں **رقم باہر منتقل کریں** پر ٹیپ کرنے سے [رقم نکلوائیں](./features/bridge-and-withdraw.mdx#withdraw) کھلتا ہے اور سب کچھ
منتخب ہوتا ہے (یا کہیں: "میری ساری رقم Kraken میں نکال دو")۔ رقم بھیجنے کی جگہ منتخب کریں: کوئی **ایکسچینج** (Kraken، Bybit، OKX، Binance،
Bitget، KuCoin، یا Base کے ذریعے Coinbase)، Arc یا کسی دوسری چین پر **آپ کا اپنا والٹ**، یا ایکسچینج کے ذریعے آپ کا بینک۔
Kawase ہر ٹوکن کے لیے طریقہ منتخب کرتا ہے (منتقلی، برج، یا پہلے USDC میں تبدیلی)، آپ کو ایسی چیز کے بارے میں خبردار کرتا ہے جسے منزل
کریڈٹ نہیں کرے گی، اور آپ Face ID سے ایک بار تصدیق کرتے ہیں۔
</Step>
<Step>
### ایکسپلورر چیک کریں
ایکسپلورر پر اپنا ایڈریس کھولیں (نیچے دیا گیا ہے) اور تصدیق کریں کہ بیلنس وہاں موجود ہیں جہاں آپ نے انہیں بھیجا تھا۔
</Step>
</Steps>

## حصہ 2: Kawase کے بغیر (اپنا والٹ ایکسپورٹ کریں)

آپ کے والٹ کی کلید **Privy** آپ کی طرف سے محفوظ رکھتا ہے، محفوظ انکلیوز میں ٹکڑوں میں بانٹ کر۔ ایکسپورٹ کرنے سے **پرائیویٹ کلید** کی ایک کاپی آپ کو مل جاتی ہے، جسے آپ کسی بھی والٹ میں اسی اکاؤنٹ کے ساتھ استعمال کر سکتے ہیں۔

<Steps>
<Step>
### ایکسپورٹ کریں
Settings → **اکاؤنٹ** → **والٹ ایکسپورٹ کریں**۔ انتباہات پڑھیں اور بٹن دبائے رکھیں: Privy اپنی محفوظ ونڈو میں آپ کی **پرائیویٹ کلید** دکھاتا ہے، جسے Kawase کبھی نہیں دیکھتا۔ فون پر ایکسپورٹ ویب ایپ میں کھلتا ہے، جہاں آپ اسی ای میل سے سائن اِن کرتے ہیں۔ کلید کو کسی محفوظ آف لائن جگہ پر رکھیں۔ جس کے پاس یہ ہو، وہ آپ کی رقم کنٹرول کر سکتا ہے۔
</Step>
<Step>
### اسے کسی دوسرے والٹ میں امپورٹ کریں
MetaMask، Rabby یا ایسے کسی دوسرے والٹ میں جو کسٹم نیٹ ورکس کی اجازت دیتا ہو، پرائیویٹ کلید امپورٹ کرنے کا انتخاب کریں۔ آپ کو Kawase والا **وہی
ایڈریس** ملے گا۔
</Step>
<Step>
### Arc شامل کریں
نیچے دی گئی جدول میں موجود تفصیلات سے نیٹ ورک شامل کریں۔ آپ کے بیلنس اسی طرح نظر آئیں گے جیسے وہ چین پر ہیں۔
</Step>
<Step>
### اپنی رقم منتقل کریں
اس والٹ سے اسی طرح رقم بھیجیں جیسے کسی دوسرے والٹ سے بھیجتے ہیں۔ والٹ، Aave اور مارجن پوزیشنز ان پروٹوکولز میں آپ کے اپنے اکاؤنٹ میں رہتی ہیں،
اس لیے Arc پر ان کے لیے موجود کوئی بھی انٹرفیس انہیں مینیج کر سکتا ہے۔
</Step>
</Steps>

اگر آپ اپنے کنٹرول میں ایک کاپی رکھنا چاہتے ہیں تو Kawase کے چلتے ہوئے ایکسپورٹ کریں: ایکسپورٹ ایپ کے ذریعے ہو گا۔

## ایکسپلورر پر سب کچھ چیک کریں

اپنی رقم دیکھنے کے لیے آپ کو Kawase کی ضرورت نہیں۔ Arc کے بلاک ایکسپلورر پر اپنا ایڈریس کھولیں:

- مین نیٹ: `https://explorer.arc.io/address/<your address>`
- ٹیسٹ نیٹ: `https://explorer.testnet.arc.io/address/<your address>`

وہاں آپ یہ چیزیں دیکھ سکتے ہیں:

- اپنے بیلنس (Arc پر USDC نیٹ ورک کا گیس ٹوکن بھی ہے: ایک ہی بیلنس مقامی کوائن اور USDC
  ٹوکن، دونوں کے طور پر دکھایا جاتا ہے)؛
- ہر ٹرانزیکشن، بشمول وہ ادائیگیاں جو ایجنٹ نے آپ کی الاؤنس کے تحت کی ہیں؛
- آپ کے اکاؤنٹ کا **کوڈ**: سیٹ اپ کے بعد یہ `0xef0100` اور اس کے بعد `EIP7702StatelessDeleGator` ایڈریس ہوتا ہے۔ یہی
  EIP-7702 اپ گریڈ ہے؛ آپ کا اکاؤنٹ اب بھی عام اکاؤنٹ کی طرح کام کرتا ہے۔

Kawase کی رسیدوں میں انہی صفحات کے لنکس ہوتے ہیں۔

## اگر Kawase غائب ہو جائے

- **ایجنٹ کی اجازتیں بے کار ہو جاتی ہیں۔** آپ کی الاؤنس اور آٹومیشن کی اجازتیں صرف Kawase کے اپنے ایجنٹ
  والٹ سے استعمال کی جا سکتی ہیں، اور یہ ختم ہو جاتی ہیں: الاؤنس 90 دن بعد، اور ہر آٹومیشن اپنی اختتامی تاریخ پر۔
- **آپ کی رقم آپ کے اکاؤنٹ میں رہتی ہے۔** یہ Arc پر ایک عام اکاؤنٹ ہے۔
- **ایکسپورٹ کی گئی پرائیویٹ کلید** (حصہ 2) کے ساتھ آپ Arc کو سپورٹ کرنے والے کسی بھی والٹ سے اپنی ساری رقم منتقل کر سکتے ہیں۔

کچھ والٹس کسٹم نیٹ ورکس پر گیس بیلنس کو "ETH" کا نام دیتے ہیں؛ Arc پر یہ USDC ہے۔ USDC ٹوکن کا ایڈریس دونوں نیٹ ورکس پر
`0x3600000000000000000000000000000000000000` ہے؛ مین نیٹ پر EURC کا ایڈریس
`0xbEf5f6d51CB62b58e6A8f77868681825C6fe21c1` اور ٹیسٹ نیٹ پر `0x89B50855Aa3bE2F677cD6303Cec089B5F319D72a` ہے۔

## EIP-7702 اپ گریڈ ہٹانا (اختیاری)

رقم منتقل کرنے کے لیے آپ کو یہ اپ گریڈ ختم کرنے کی ضرورت نہیں۔ اگر آپ اسے ایکسپورٹ کرنے کے بعد دوبارہ عام اکاؤنٹ بنانا چاہتے ہیں تو صفر ایڈریس کی طرف
اشارہ کرنے والی EIP-7702 اجازت پر دستخط کریں اور اسے خود اکاؤنٹ سے بھیجیں، مثلاً viem کے ذریعے:

```ts
import { zeroAddress } from "viem";

const authorization = await walletClient.signAuthorization({ contractAddress: zeroAddress, executor: "self" });
await walletClient.sendTransaction({ to: walletClient.account.address, authorizationList: [authorization] });
```

اس کے بعد ایکسپلورر آپ کے ایڈریس پر کوئی کوڈ نہیں دکھائے گا۔
