**Arc**، Circle کا اسٹیبل کوائن نیٹ ورک ہے۔ USDC اس کا گیس ٹوکن ہے، اس لیے فیس ڈالرز میں ادا ہوتی ہے، اور ٹرانزیکشنز ایک سیکنڈ سے بھی کم وقت میں مکمل ہو جاتی ہیں۔ Kawase بالکل دو Arc نیٹ ورکس کو سپورٹ کرتا ہے۔

| | Arc مین نیٹ | Arc ٹیسٹ نیٹ |
|---|---|---|
| پیسہ | اصلی | ٹیسٹ پیسے، جن کی کوئی قدر نہیں |
| چین ID | `5042` | `5042002` |
| ایکسپلورر | `explorer.arc.io` | `testnet.arcscan.app` |
| پیسے حاصل کرنا | کسی بھی ایسے والٹ یا ایکسچینج سے پیسے وصول کریں جو Arc پر بھیجتا ہو؛ Apple Pay یا کارڈ سے خریداری جلد دستیاب ہوگی | اِن ایپ فاسٹ (روزانہ تقریباً 20 USDC + 20 EURC) |

| پہلے سے طے شدہ حدود | کم | دس گنا زیادہ (اصلی پیسے کا کوئی خطرہ نہیں) |
| نئے اکاؤنٹس کہاں سے شروع ہوتے ہیں | | ✓ |

Kawase میں ہر فلو کو **Arc ٹیسٹ نیٹ** پر اصلی ٹرانزیکشنز کے ساتھ شروع سے آخر تک چلایا گیا ہے؛ اس کا ثبوت شوکیس کے ڈیمو پیج سے منسلک ہے۔ نیچے دی گئی دستیابی بتاتی ہے کہ ایپ ہر نیٹ ورک پر کیا پیش کرتی ہے:

<AvailabilityMatrix />

## Kawase انہیں الگ کیسے رکھتا ہے

- **دونوں سمتوں میں ایک ٹیپ سے سوئچ کریں**: [نیٹ ورک ٹوگل](./features/network-toggle.mdx) دیکھیں۔
- **نیٹ ورک تین طریقوں سے دکھایا جاتا ہے**: ہیڈر پِل، ٹیسٹ نیٹ اسٹرپ یا اصلی پیسہ لیبل، اور اورب کے رنگ سے۔
- **انتخاب سرور کے پاس ہوتا ہے۔** ہر ادائیگی ایک نیٹ ورک کے لیے تیار کی جاتی ہے اور آخر تک اسی نیٹ ورک پر رہتی ہے؛ اگر درمیان میں نیٹ ورک بدل جائے تو ادائیگی دوسرے نیٹ ورک پر جانے کے بجائے رک جاتی ہے۔
- **دونوں نیٹ ورکس پر ایک ہی والٹ ایڈریس ہوتا ہے**، جبکہ بیلنس، سرگرمی اور حدود ہر نیٹ ورک کے لیے الگ رکھی جاتی ہیں۔
