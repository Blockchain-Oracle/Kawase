Kawase ऐप में हर जगह दुनिया में सबसे ज़्यादा बोली जाने वाली भाषाओं में जवाब देता है:

| भाषा | भाषा में नाम | दिशा |
|---|---|---|
| अंग्रेज़ी | English | बाएँ से दाएँ |
| चीनी | 中文 | बाएँ से दाएँ |
| हिन्दी | हिन्दी | बाएँ से दाएँ |
| स्पैनिश | Español | बाएँ से दाएँ |
| फ़्रेंच | Français | बाएँ से दाएँ |
| अरबी | العربية | **दाएँ से बाएँ** |
| बांग्ला | বাংলা | बाएँ से दाएँ |
| पुर्तगाली | Português | बाएँ से दाएँ |
| रूसी | Русский | बाएँ से दाएँ |
| उर्दू | اردو | **दाएँ से बाएँ** |

- **पहली स्क्रीन से।** भाषा का विकल्प पहले ऑनबोर्डिंग पैनल और उसके बाद हर स्क्रीन पर दिखता है; इसे बदलने पर भाषा और दिशा, दोनों तुरंत बदल जाते हैं।
- **हर भाषा में हर टेक्स्ट।** ऐप की दसों भाषाओं की पूरी सामग्री उपलब्ध है। एजेंट आपकी भाषा में जवाब देता है और [आवाज़](./voice.mdx) दसों भाषाओं को सुन और बोल सकती है।
- **रकम हमेशा सही रहती है।** नंबर आपकी भाषा के अनुसार फ़ॉर्मैट होते हैं, जबकि रकम, पते और कोड बाएँ से दाएँ ही रहते हैं, ताकि उन्हें एक-एक अक्षर करके जाँचा जा सके।
- **ये दस्तावेज़** भी इन्हीं दस भाषाओं में उपलब्ध हैं (साइडबार में भाषा बदलें)।
