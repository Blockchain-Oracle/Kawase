## Confirming on the web

Where a phone asks for Face ID, the web app sends an **email code**: you type the six digits and the payment goes. Voice
works too: allow the microphone when the browser asks. If you refuse it, Kawase says how to allow it, and typing is
right there.

## Install it

Kawase is an installable web app. In Chrome or Edge use **Install**, in Safari **Add to Dock** (Mac) or **Add to Home
Screen** (iPhone). If the network drops, an offline page says so instead of a broken screen. Kawase never caches
balances, so nothing old is ever shown as current money.
